# AI 工作流：实施变更

输入：明确目标、授权范围、项目事实和验收条件。

1. 读取项目入口与相关模块，核对已有改动和本次范围。
2. 小任务用对话或现有系统；长任务可用[任务模板](../templates/task.md)。
3. 只读取涉及的接口、UI、配置、事务或权限标准，定位现有公共入口。
4. 完成最小充分变更；重大取舍用 ADR。代码任务不隐含运行服务或发布授权。
5. 执行相关检查和必要回归，保留失败证据，不将未执行算通过。
6. 更新受影响事实，按项目政策提交，报告变化、验证和遗留。

完成条件：验收覆盖真实行为，必要检查有结果，改动不含其他任务内容。详细规则见[工程质量标准](../docs/standards/engineering-quality.md)。

实施完成后，若发现了可迁移的工程问题，按[教训提炼流程](../docs/lessons/README.md)登记；业务事实留在项目任务中。
