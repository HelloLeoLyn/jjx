# leo-loose AI 导航

本文件适用于本资料包子树，遵守当前用户明确指令与所在仓库上层规则，不覆盖它们。这里是工程资料，不是宿主应用代码、生产配置或项目事实。

## 按任务读取

| 任务 | 入口 |
|---|---|
| 启动新项目 | [启动流程](workflows/bootstrap.md) |
| 已授权的功能或修复 | [实施流程](workflows/implement.md) |
| 报错与原因排查 | [诊断流程](workflows/diagnose.md) |
| 代码与架构评审 | [审查流程](workflows/review.md) |
| 恢复与交接 | [交接流程](workflows/handoff.md) |

先读取新项目根入口、项目约定和相关模块事实，再读取本次需要的标准，不默认加载全部文档。讨论只给判断与证据；实施仅在授权范围内进行。

## 修改本资料包

- 保持技术栈无关；平台专属示例标注适用范围。
- 标准放在 docs/standards，工作流引用规则，不复制长篇标准。
- 可迁移教训放在 docs/lessons；每条必须保留来源任务码、证据状态和适用边界。
- 区分既有实践、已采用决定、建议与模板，不把建议写成已验证事实。
- 不加入运行数据、凭据、机器路径与项目专属用户政策。
- 新文档更新 [README 索引](README.md)，保持相对链接可独立复制。
- 新增检查能力时同步用法、依赖、失败行为与检查范围。

从本目录执行：

```sh
python3 checks/check-docs.py
```

检查器只读文件并打印结果，不访问数据库、网络或运行服务。宿主仓库另有门禁时一并执行；新项目应用的测试和构建命令必须从该项目约定读取。
