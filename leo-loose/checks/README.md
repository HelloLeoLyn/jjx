# 文档检查器

依赖：Python 3.9+ 标准库。只读文件、输出结果，不修改资料、不访问网络或数据库、不启动服务。

从资料包根目录运行：

```sh
python3 checks/check-docs.py
```

从其他目录运行时使用脚本实际路径；默认检查脚本所属资料包，不依赖当前工作目录。也可显式指定根目录：

```sh
python3 checks/check-docs.py --root /path/to/copied-kit
```

检查范围：必需入口、Markdown UTF-8 解码、非空文件、围栏代码块闭合、行内相对文件链接、根 README 对所有 Markdown 的索引，以及文件链接是否逃逸资料包。

支持本资料采用的行内链接形式；忽略代码块中的示例链接。外部 URL 不联网校验，页内锚点、HTML 链接、引用式链接和语义正确性不在检查范围。模板中的待填写内容合法，不代表实际项目已配置。

退出码：0 通过，1 检查失败，2 参数错误。新增文件需登记根索引；改路径需修引用。应用编译、接口契约、权限与运行行为由新项目自己的检查负责。

检查器变更时，至少在临时副本中验证正常情况、断链、必需文件缺失和未登记文档。临时副本用后删除，不修改真实资料来制造失败。
