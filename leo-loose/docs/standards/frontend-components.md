# 前端组件与页面组织

性质：组件、composable、API 层和声明式操作列为实践提炼；统一选用与生命周期规则为建议基线。

## 三类职责

| 类型 | 负责 | 不应承担 |
|---|---|---|
| 基础展示组件 | 布局、样式、输入、事件 | 主动请求具体模块接口、读取隐含全局状态 |
| 通用交互组件或 composable | 分页、选择、加载、表单交互 | 决定服务端授权或复制服务端最终校验 |
| 模块组件与页面 | 组合接口、专属交互与路由 | 重复实现已有基础能力 |

UI 库封装应提供稳定价值，例如一致的空态、加载态、操作列和错误反馈。纯粹一对一转发全部属性的包装需要说明维护收益。

## 公共组件只有一个推荐入口

每种公共能力登记：名称、导入路径、职责、必要属性、事件、适用场景、维护者、替代关系。同名组件不使用不同路径表达隐含的新旧版本；弃用入口应有明确标记与迁移计划。

样式颜色、间距、字号和尺寸由统一 token 管理；模块可以组合，不应复制一套近似 token。页面骨架负责布局，查询表格组件负责交互，二者可以组合但要说明边界。

## 页面推荐组织

```text
modules/example/
  pages/ListPage.vue           组装视图与路由参数
  components/EditDialog.vue    模块局部表单
  composables/useList.ts       请求状态与交互
  types.ts                    模块展示模型
api/example.ts                明确类型的 HTTP 调用
```

仅跨页面共享且需要统一生命周期的数据进入 store。临时弹窗状态和单页查询条件留在页面或 composable；缓存需要说明失效时机，不能把 store 当作永久数据真源。

## 表格操作列的声明方式

可复用操作定义包含 key、label、permission、visible、disabled、disabledReason、loading、confirm、order。展示组件负责一致渲染，页面处理动作事件。

权限提示改善交互，服务端必须再次授权。隐藏代表不适用或不可见；禁用代表当前不能执行，并提供原因。不要将这两者混成一个不可解释的布尔表达式。

## 异步交互约定

- 搜索、翻页和路由切换时，取消过期请求或使用请求序号防止旧响应覆盖新结果。
- loading 在成功与失败路径都能结束；并行请求的加载状态分别管理。
- 重置恢复明确的默认值，不能仅删除字段后依赖后端猜测。
- 写操作防重复点击；真正的幂等由服务端保证。
- 组件卸载时清理监听、定时器和未完成交互；取消请求不等于服务端操作已回滚。
- 错误、空数据、无权限、加载中分别展示，不用空数组掩盖接口失败。
- 键盘操作、焦点恢复、表单标签与纯图标按钮的可访问名称应可用。

## 验证

组件测试聚焦交互契约，如权限与禁用原因、提交一次、旧响应不会覆盖新响应。端到端测试覆盖少量关键页面组合；不为简单样式包装重复测试底层 UI 库。

来源中的通用 useTable 与状态标签只作为实现参考；采用前应补齐上述异步边界，并选定唯一标签实现。
