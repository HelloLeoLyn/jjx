# ADR-0001：AI 编程与多项目适配

状态：已采用；日期：2026-09-30；任务：dev-20260930-038。

## 背景与决定

用户明确主要由 AI 编程，项目多样化。第一版偏前后端应用，需要增加导航与检查，并减少默认技术栈。

采用短 AGENTS 导航、分类文档、按任务读取的工作流、填写模板和独立检查器。原标准归入 docs，Web 分层保留为可选示例。新项目事实与资料包分开维护。

参考关系见[公开规范映射](../reference/public-practices.md)。这是适配结果，不宣称为统一行业目录标准。

## 代价与限制

每个项目需填写真实命令并选择适用规则，资料包不自动生成应用代码。检查器只验证文档结构，各代理的入口发现方式可能需要配置。

宿主项目政策不变；工作流引用标准，不复制规则。小任务可使用对话或现有任务系统，避免过度文档化。

## 验证与重新评估

验证独立复制、链接、索引、代码块和必需入口；注入断链与缺失入口确认失败。实际使用后复核资料定位、命令可执行性和交接恢复能力。多个项目出现稳定重复实现时，再考虑语言专属脚手架。
