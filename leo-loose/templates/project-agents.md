# 项目根 AGENTS.md 模板

复制下方内容到新项目根入口并填写。已有入口先合并，不覆盖用户规则。示例假设资料包在 docs/engineering，位置变化时调整。

```markdown
# [项目名] AI 工作入口

## 项目事实
- 类型、目标与边界：[填写]
- 项目约定及架构文档：[实际路径]
- 源码、测试、生成目录：[路径及职责]
- 任务和交接入口：[实际路径或系统]

## 工作规则
- 当前用户明确要求与已有规则优先。
- 讨论与诊断默认只读，实施只覆盖授权范围。
- 先核对工作区，不覆盖其他任务改动。
- 技术选择依据本项目事实，不照搬资料包示例。
- 服务、数据、提交和发布操作遵循本项目明确政策。

## 真实命令
逐项填写执行目录、命令、依赖和副作用；不适用注明原因。
- 安装：[填写]
- 静态或类型检查：[填写]
- 相关测试：[填写]
- 构建：[填写]
- 完成条件：[填写]

## 按需读取
- 通用资料：docs/engineering/README.md
- 任务流程：docs/engineering/workflows/
- 规则真源：docs/engineering/docs/standards/
只读取本次涉及内容，标准不重复维护。

## 汇报与交接
报告改动、验证、未执行原因与遗留。
提交推送政策：[填写，不默认自动发布]
长任务交接位置：[填写]
```
