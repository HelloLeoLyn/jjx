## [采购] TC-400: 采购收货自动联动入库（DEV-624）

### 前置条件
- 有已审批的采购单（含物料/数量），供应商可收货
- 原链路：采购收货后需人工去库存模块点「从采购单生成」，本次验证自动触发

### 测试步骤
1. 采购收货页 → 对采购单执行确认收货（PurchaseReceipt confirm）
2. 直接切到库存模块 → 入库单列表
3. 入库单确认 → 查看库存数量与流水

### 验证点

#### ✅ 操作验证
- [ ] 收货确认后无需人工操作，入库单已自动生成（关联采购单号，createFromPurchase 触发）
- [ ] 入库单确认加库存流程正常，无报错

#### ✅ 数据验证
- [ ] inventory_inbound_order 出现新入库单，来源=采购单（source_no=采购单号）
- [ ] 确认后对应物料库存增加，数量=收货数量
- [ ] inventory_transaction 有入库流水（before/after 有值）

#### ✅ 截图
- [ ] 收货前采购单/库存快照；收货后入库单列表+库存变化各 1 张
