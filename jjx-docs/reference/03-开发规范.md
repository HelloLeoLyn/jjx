# 开发规范

## 依赖注入
- 构造器注入 + `@RequiredArgsConstructor`，禁止 `@Autowired` 字段注入

## 对象转换
- Entity → VO 用 MapStruct，Converter 接口放在 `.converter` 包
- 配置：`@Mapper(componentModel = "spring")`

## 后端包结构
```
com.jjx.{module}/
├── controller/     # REST API
├── service/        # 业务逻辑 + impl
├── mapper/         # MyBatis-Plus
├── domain/
│   ├── entity/     # 数据库实体
│   ├── dto/        # 传输对象
│   └── vo/         # 视图对象
├── converter/      # MapStruct
└── enums/          # 业务枚举
```

## 命名规范
- RESTful：`GET /resource` `POST /resource` `PUT /resource/{id}` `DELETE /resource/{ids}`
- 方法名：list / getInfo / add / edit / del / export / import
- 数据库字段：下划线命名，Java 驼峰（MyBatis-Plus 自动映射）

## 前端规范
- API 封装：`const api = { list() {}, getInfo() {} }` 对象导出
- 类型定义：`src/types/{module}/`，每个模块独立文件
- 页面组件：`index.vue` + `components/` + `composables/`
- 枚举定义：`src/enums/{module}/`，统一管理
- 避免 `any`，使用具体类型或 `Record<string, unknown>`

## Git 规范

- 提交前缀：`feat:` / `fix:` / `opt:` / `clean:` / `docs:`
