# JJX ERP 内网 HTTPS 手机证书安装指引

> 部署日期：2026-09-01 ｜ 服务器：192.168.1.176（WSL2 + docker nginx）
> 访问地址：`https://192.168.1.176/m/scan`（移动端扫码入口）

## 为什么需要装证书

服务器用的是**自签 CA 证书**（内网环境，无法申请公网证书）。手机默认不信任它，访问会提示"连接不安全/证书无效"。把 CA 证书（JJX-CA.crt）装进手机并信任后，浏览器就会正常打开，同时解锁**摄像头扫码**能力。

## 证书获取

- 文件：`jjx-docs/assets/certs/JJX-CA.crt`（或从服务器拷 `~/nginx-certs/ca.crt`）
- 传到手机的方式：微信/QQ 文件传输、U 盘、或手机浏览器直接访问服务器下载
  - 用浏览器下载：先访问 `http://192.168.1.176:8899/`（文档中心，HTTP 可访问）把证书放到可下载位置，或直接通过数据线拷贝

## Android 安装步骤

### 方式 A：Android 11+ 系统 CA（推荐，摄像头扫码必须）
Android 7+ 起，App 默认不信任用户 CA，但**浏览器访问 HTTPS 只需要用户 CA 即可**。步骤：

1. 把 `JJX-CA.crt` 传到手机（微信/数据线/下载）
2. 打开"设置 → 安全 → 加密与凭据 → 安装证书"（不同品牌路径略有差异：小米"设置-更多设置-安全-加密与凭据"、华为"设置-安全-更多设置-加密与凭据"、三星"设置-生物识别与安全-其他安全设置-安装证书"）
3. 选择"CA 证书"→ 选择 `JJX-CA.crt` 文件 → 确认安装（可能要求锁屏密码）
4. 完成后，用 **Chrome/Edge 浏览器**打开 `https://192.168.1.176/m/scan`，应能正常访问

> 注意：个别国产浏览器可能忽略用户证书，建议用 Chrome 或系统浏览器。

### 方式 B：直接访问（不装证书，仅看提示）
不装证书也能访问，但每次都有"继续访问"警告页（点"高级→继续前往"），且**摄像头扫码不可用**。建议按方式 A 装。

## iPhone / iPad 安装步骤

1. 把 `JJX-CA.crt` 传到手机（微信传输后"用其他应用打开"→ Safari 打开，或用 AirDrop/邮件附件）
2. **Safari 打开证书文件** → 会提示"此网站正尝试下载一个配置描述文件" → 允许
3. 打开"设置 → 通用 → VPN与设备管理"→ 找到 **JJX CA** → 点击"安装"（输入锁屏密码）→ 安装完成
4. **关键一步**：打开"设置 → 通用 → 关于本机 → 证书信任设置"→ 找到 **JJX CA** → 打开"完全信任"开关
5. Safari 打开 `https://192.168.1.176/m/scan`，正常访问即可

> ⚠️ 第 4 步（完全信任）必须做，否则 Safari 仍会拦截。

## 验证是否成功

- 地址栏**无警告图标**（或点开显示"连接是安全的"）→ 成功
- `/m/scan` 页面能打开且**扫码框可用**（摄像头权限弹窗 → 允许）→ 摄像头扫码可用

## 常见问题

| 问题 | 解决 |
|---|---|
| 装完证书仍提示不安全 | 检查证书信任开关（尤其 iPhone 第4步）；或用 Chrome 而非国产浏览器 |
| 摄像头打不开 | 确认走的是 HTTPS（http 不行）；确认浏览器给了摄像头权限 |
| 无法连接 | 手机和电脑在同一 Wi-Fi；电脑 IP 变为 192.168.1.176（变了就重签证书） |
| 服务器 IP 变了 | 需要重新生成证书（改 SAN 里的 IP）+ 重启 nginx 容器 |

## 技术备忘（服务器侧）

- 证书目录：`~/nginx-certs/`（ca.crt / server.crt / server.key）
- nginx 配置：`~/nginx-conf/nginx.conf`
- 容器管理：
  ```bash
  docker start jjx-nginx     # 启动
  docker stop jjx-nginx      # 停止
  docker restart jjx-nginx   # 重启
  docker exec jjx-nginx nginx -s reload   # 热重载配置
  ```
- 证书轮换（IP 变更后）：
  ```bash
  cd ~/nginx-certs && rm -f server.key server.csr server.crt
  # 重新执行生成脚本（改 san.cnf 里的 IP）→ docker restart jjx-nginx
  ```
