• 当前仓库推荐的本地开发启动方式是分别运行现有脚本。

  1. 后端启动命令

  在仓库根目录执行：

  ./services/orchestrator/scripts/start-backend.sh

  该脚本实际执行 Maven Wrapper：

  ./mvnw spring-boot:run \
    -Dspring-boot.run.arguments="--server.port=18080 --spring.profiles.active=local"

  配置见 services/orchestrator/scripts/start-backend.sh。

  2. 前端启动命令

  另开一个终端，在仓库根目录执行：

  ./services/orchestrator/scripts/start-frontend.sh

  该脚本实际执行：

  npm run dev -- --host 127.0.0.1 --port 15174 --strictPort

  如果尚未安装前端依赖，需要先执行：

  cd services/orchestrator/frontend
  npm install

  配置见 services/orchestrator/scripts/start-frontend.sh 和 services/orchestrator/frontend/package.json。

  也可以用仓库提供的统一命令同时启动：

  ./services/orchestrator/scripts/start-all.sh

  3. PostgreSQL / Docker 依赖

  本地开发脚本使用：

  spring.profiles.active=local
  aidevos.persistence.type=in-memory

  因此：

  - 查看和操作 Backlog Center 不强制需要 PostgreSQL
  - 不需要 Docker
  - 数据仅保存在内存中，后端重启后消失
  - OpenClaw 不影响 Backlog Center 基本访问

  本地启动需要：

  - Java 21
  - 仓库内 Maven Wrapper
  - Node.js
  - npm
  - 已安装的前端依赖

  如果使用：

  docker compose up --build

  则会启动 PostgreSQL 17、后端和生产前端；这种方式需要 Docker。Docker 模式端口与开发模式前端端口不同。

  4. 后端实际端口

  18080

  后端地址：

  http://127.0.0.1:18080

  5. 前端实际端口

  本地开发脚本：

  15174

  Docker Compose 生产前端：

  8080

  6. 浏览器访问地址

  使用本地开发脚本时：

  http://127.0.0.1:15174

  使用 Docker Compose 时：

  http://127.0.0.1:8080

  Vite 会把 /api 请求代理到后端 http://localhost:18080，见 services/orchestrator/frontend/vite.config.ts。

  7. Backlog Center 实际路由

  /backlog

  本地开发完整地址：

  http://127.0.0.1:15174/backlog

  Docker Compose 完整地址：

  http://127.0.0.1:8080/backlog

  路由定义见 services/orchestrator/frontend/src/router/index.ts。
