# 1. 项目概述

## 1.1 项目名称

项目文件中心（Project File Center）

---

## 1.2 项目背景

在软件项目开发过程中，大量项目资料分散在不同位置：

- Git 仓库
- 本地电脑
- 企业网盘
- 邮件附件
- 即时通讯工具

随着项目规模增加，会产生以下问题：

- 项目资料难以统一管理
- 文件查找效率低
- 新成员无法快速了解项目
- 历史资料无法沉淀
- 项目经验无法复用

因此建设一个轻量级项目文件管理系统，用于统一管理项目开发过程中的各种资料。

---

# 2. 项目定位

项目文件中心不是传统企业网盘。

定位：

> 面向开发团队的项目资料管理平台。

核心思想：

```
代码        -> Git管理

项目文件    -> 文件中心管理

技术文档    -> Markdown管理

知识查询    -> 后续AI增强
```

---

# 3. 项目目标

## 3.1 第一阶段目标

- 文件审批流程

保持系统简单可靠。

# 7. 数据库设计

数据库：

MySQL 8

---

# 7.1 项目表

表：

```
project
```

字段：

| 字段        | 类型     | 说明     |
| ----------- | -------- | -------- |
| id          | bigint   | 主键     |
| name        | varchar  | 项目名称 |
| description | text     | 描述     |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

---

# 7.2 文件表

表：

```
file
```

字段：

| 字段        | 类型     | 说明     |
| ----------- | -------- | -------- |
| id          | bigint   | 主键     |
| project_id  | bigint   | 项目ID   |
| parent_id   | bigint   | 父目录   |
| name        | varchar  | 文件名   |
| path        | varchar  | 存储路径 |
| type        | varchar  | 文件类型 |
| size        | bigint   | 文件大小 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

---

## 文件树设计

通过 parent_id 实现目录结构。

例如：

```
id=1

name=技术方案

parent_id=0


id=2

name=架构设计.md

parent_id=1

```

结构：

```
技术方案

└── 架构设计.md

```
