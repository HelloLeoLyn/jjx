# 单据金额口径规范

> - 状态：**现行**（v1，2026-10-09 立）
> - 适用范围：销售报价单 / 销售订单 / 采购订单 / 样品单，及其转单链路
> - 维护：金额相关改动须同步本规范；文末记变更
> - 来源：dev-20261009-007（报价单补运费，对齐销售订单口径）
> - 说明：本文是「为什么、按什么口径算」的规矩；各单据当前字段以库表/实体为准（`modules/` 记现状）

---

## 1. 统一原则

1. **明细金额 = 未税单价 × 数量**（单价一律按未税口径存）。
2. **税额 = 未税小计 × 税率 ÷ 100**（税率按**百分数**存，如 `13` 表示 13%）。
3. **运费单列、不计税**（若某场景需对运费计税，另立规则，不默认）。
4. **折扣只从「含税总额」扣一次**（不在未税小计上扣）。
5. **客户最终应付 = 未税小计 + 税额 + 运费 − 折扣**。

---

## 2. 四类单据对照

| 维度 | 报价单 `sales_quotation` | 销售订单 `sales_order` | 采购订单 `purchase_order` | 样品单 `sales_sample_order` |
|---|---|---|---|---|
| 明细单价口径 | 未税 | 未税 | 未税 | 未税 |
| 税率字段 | `tax_rate`（百分数） | `tax_rate`（百分数） | 无税率字段，只有税额 `order_tax` | — |
| 运费 | `shipping_fee`（2026-10-09 起） | `shipping_fee` | **不单列**（含在供应商单价，合同口径） | — |
| 折扣 | `discount_amount` | `discount_rate` + `discount_amount` | 无 | — |
| 含税总额 | `total_amount` | `total_amount`（=`total_amount_with_tax`） | `order_total_amount`（价税合计） | 无单头汇总 |
| 最终应付 | `final_amount` | `final_amount`（+`paid_amount`/`unpaid_amount`） | 无（价税合计即应付） | 无 |

---

## 3. 各单据公式与字段

### 3.1 报价单（sales_quotation）
```
subtotal_amount = Σ 明细 amount                     （未税小计）
tax_amount      = subtotal_amount × tax_rate ÷ 100  （税率存百分数）
total_amount    = subtotal_amount + tax_amount + shipping_fee   （含税，含运费）
final_amount    = total_amount − discount_amount                 （≥ 0，客户最终应付）
```
- 计算真源：`QuotationServiceImpl.recalcQuotationAmounts`
- 字段：`subtotal_amount` / `tax_rate` / `tax_amount` / `shipping_fee` / `discount_amount` / `total_amount` / `final_amount`
- 费率换算等口径历史：`buildQuotationExcel`、`print.vue`、`QuotationDetailDialog` 展示同源。

### 3.2 销售订单（sales_order）
```
未税小计        = Σ (unit_price × quantity)
tax_amount      = 未税小计 × tax_rate ÷ 100
total_amount    = 未税小计 + tax_amount + shipping_fee   （含税含运费；= total_amount_with_tax）
discount_amount = 显式值，否则 = total_amount × discount_rate
final_amount    = total_amount − discount_amount          （应付）
unpaid_amount   = max(final_amount − paid_amount, 0)
```
- 计算真源：`SalesOrderCalculator.fillFromItems` / `fillOrderAmounts`
- ⚠️ **保护态**：历史单 `shipping_fee = NULL` 视为「金额组成未确认」，编辑时禁止静默重算/改价（见 dev-20261008-002 / dev-20261008-015）。

### 3.3 采购订单（purchase_order）
```
order_amount       = Σ 明细 amount            （不含税合计）
order_tax          = 税额
order_total_amount = order_amount + order_tax （价税合计 = 应付）
```
- 计算真源：`PurchaseOrderServiceImpl`；行金额不含税，**税在单头汇总**（2026-09-07 口径）。
- **不单列运费**：采购合同条款「供方负责送达，运费由供方承担」（`purchase/order/print.vue`）→ 运费已含在供应商单价。

### 3.4 样品单（sales_sample_order）
- 只有明细 `unit_price` / `amount`，另有 `sample_cost`（打样成本）、`sample_work_hours`。
- **无单头金额汇总**（现状；如需对外报价汇总，另立规则）。

## 4. 展示标签（建议统一，尚未统一）

| 含义 | 建议标签 | 现状差异 |
|---|---|---|
| 未税商品小计 | 未税小计 | 报价叫「小计金额」、订单叫「未税小计」 |
| 含税总额 | 含税总额 | 报价叫「总金额」；订单不单列该中间量 |
| 客户最终应付 | 应付总额 | 报价叫「最终金额」、采购叫「价税合计」 |
