# 文件管理方案（附件存储 · 备份预警 · 链路显示）

> 版本：v1.0（2026-08-07）
> 范围：业务单据附件（报价确认单/询价文档等）+ 工程部产品文件（客供稿/承认书/模具/确认图/菲林/规范）
> 原则：**全部本地存储**（不引第三方对象存储），**数据库只存元数据**（路径/名称/大小），**备份机制 + 容量预警**兜底。

---

## 一、总体架构

```
┌─────────────────────────────────────────────────────────┐
│                     用户 / 浏览器                          │
│        上传 ──▶ 下载 ──▶ 预览 ──▶ 链路查看                  │
└──────────────────────────┬──────────────────────────────┘
                           │ HTTP
┌──────────────────────────▼──────────────────────────────┐
│                  Spring Boot（ERP 后端）                   │
│   SysAttachmentController（现有）                         │
│   上传/下载/列表/删除/按trace查询                          │
│   ┌──────────────────────────────────────────────┐       │
│   │ 备份调度器（新增）                             │       │
│   │ 每日备份 · 增量复制 · 容量统计 · 预警触发      │       │
│   └──────────────────────────────────────────────┘       │
└──────────────────────────┬──────────────────────────────┘
                           │ 读写
┌──────────────────────────▼──────────────────────────────┐
│              本地文件存储（磁盘/NAS/共享盘）                │
│  ┌────────────────────────────────────────────────┐      │
│  │  upload/                                      │      │
│  │  ├── business/  业务单据附件（报价/询价/订单…）  │      │
│  │  ├── product/   产品工程文件（客供/模具/菲林…）  │      │
│  │  └── backup/    备份目录（每日增量+每周全量）     │      │
│  └────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────┘
```

**关键决策**：
- 文件**不进数据库**（cdr/dwg 几十 MB），数据库 `sys_attachment` 只存元数据
- 存储根目录通过配置 `file.upload.path` 指定，可指向共享盘/NAS，未来可平滑迁移
- 业务附件与产品文件**分区存放**，互不干扰

## 二、目录架构（详细）

### 2.2 产品工程文件（对应工程部目录习惯）

```
upload/product/
└── JST-263MEMC/              # 按产品编码
    ├── 客供稿/
    │   └── 2026-08-07/       # 按日期（沿用现有习惯）

### 2.3 备份目录

```

│   │   └── product/
│   └── ...
├── weekly/                    # 每周全量

## 三、命名规则

| 场景 | 规则 | 示例 |
|---|---|---|
| 业务附件（存储） | `{uuid}.{ext}`（防重名） | `b5204bcd-14d5-4969-a7fb-10d346b55e47.pdf` |
| 业务附件（展示） | 保留原始文件名 | `客户确认单.pdf` |
| 产品工程文件（存储） | 保留原始文件名（工程部习惯） | `JST-263MEMC(7600-005-Rev 004).cdr` |
| 产品文件（版本标注） | `{产品编码}-{类别}-{版本}-{说明}.{ext}` | `JST-263MEMC-确认图-Rev003-已确认OK.pdf` |
| 备份文件 | `{类型}_{日期}` | `daily_2026-08-07` / `weekly_2026-08-10_full` |

**核心原则**：存储名唯一（UUID 或原文件名+日期目录），展示名永远用原始文件名（`file_name` 字段）。

## 四、备份与预警机制（重点）

### 4.1 备份策略（配置化）

| 项 | 默认值 | 说明 |
|---|---|---|
| 备份频率 | 每日 1 次（如 23:30） | 定时任务，增量备份当日新增/变更文件 |
| 备份方式 | 当日文件复制到 `backup/daily/{日期}/` | 简单可靠，目录结构镜像 |
| 全量备份 | 每周日 1 次 | `backup/weekly/`，整目录复制 |
| 保留策略 | 日备份保留 14 天 / 周备份保留 8 周 | 自动清理过期 |
| 备份目标 | 同盘另一目录 或 共享盘 | 配置 `file.backup.path`，可与存储盘分离 |

### 4.2 容量预警（人工介入触发点）

**两个预警阈值**（配置在 sys_config）：
1. **单次备份数据量阈值**：如单日新增 > 500MB → 预警"今日文件增长异常，疑似大文件批量上传"
2. **存储总量阈值**：如 upload 目录总占用 > 80%（或 > 50GB）→ 预警"存储空间不足，请到 ERP 清理或迁移"

**预警触发后**：
- 系统写入 `sys_notification` + 发送通知（现有通知体系）
- 页面弹出预警卡片（仪表盘/文件管理页）
- **人工到 ERP 操作**：
  - 「文件管理」页查看大文件 TopN、按日期/类型统计
  - 选择清理（软删除→回收站→彻底删除）或迁移（标记归档到 backup/archive）

### 4.3 备份任务执行

```
每日 23:30 定时任务：
1. 统计当日新增附件（sys_attachment.create_time >= 今日0点）
2. 计算当日新增总字节 → 若 > 阈值 → 触发容量预警通知
3. 按 sys_attachment.file_path 逐个复制到 backup/daily/{日期}/
4. 写 backup 日志（成功数/失败数/总字节）
5. 清理 14 天前的 daily 备份
每周日：整目录复制 upload/business + upload/product → backup/weekly/{日期}_full/
```

## 五、链路显示（TraceTimeline 组件扩展）

### 5.1 现状

系统已有 `TraceTimeline` 组件（按 trace_id 查询各模块操作日志，平铺时间线）。**附件挂在业务操作上**（如报价确认时传的附件），但当前组件**不显示附件**。

### 5.2 扩展设计

**数据层**：`sys_attachment` 已有 `trace_id` 字段——附件天然可挂链路。

**组件层**：TraceTimeline 的每个节点增加「附件」展示：

```
┌─────────────────────────────────────────┐
│ 链路追踪: JST-263MEMC 产品全流程          │
│─────────────────────────────────────────│
│ ● 2026-08-01 报价单 QUOT-001 创建        │
│     📎 客户确认单.pdf  报价确认单.pdf      │  ← 附件行
│ ● 2026-08-02 报价确认（含附件）           │
│     📎 报价确认单.pdf（客户签章）          │
│ ● 2026-08-03 询价单 INQ-001              │
│     📎 7600-005下订单图纸.pdf             │
│ ● 2026-08-05 订单 SO-001 确认            │
│     📎 订单附件.jpg                       │
│ ● 2026-08-07 产品工程文件（文件库）        │
│     📎 客供稿/7600-005面板.pdf            │
│      模具/JST-263MEMC.dwg  菲林/xxx.cdr  │
└─────────────────────────────────────────┘
```

**实现方式**：
1. TraceTimeline 加载节点时，同时调 `GET /system/attachment/by-trace/{traceId}` 获取该链路所有附件
2. 附件按 `create_time` 插入对应时间线位置（或按 bizType 归到对应节点）
3. 每个附件显示：文件名 + 大小 + 下载按钮（`download/{id}`）
4. 产品文件（bizType=product）在链路末尾聚合展示（按类别分组）

### 5.3 关联入口

| 入口 | 显示内容 |
|---|---|
| 报价单详情 | 报价确认单附件（现有） |
| 询价单详情 | 客户图纸附件 |
| 订单详情 | 订单/合同附件 |
| 产品档案页（新增「文件库」Tab） | 客供稿/承认书/模具/确认图/菲林/规范 |
| 任意业务页「链路追踪」按钮 | TraceTimeline 全链路 + 附件 |

## 六、需要补的功能清单（实施拆分）

### 阶段一：基础设施补齐（P1）
1. **sys_attachment 加列**：`category`（产品文件类别：客供稿/模具/菲林…）、`version`（版本号）——工程文件用；业务附件可空
2. **产品文件上传接口**：`POST /system/attachment/upload-product`（带 productCode + category + version），校验产品存在
3. **产品文件列表接口**：`GET /system/attachment/product/{productCode}`（按类别分组）
4. **产品档案页「文件库」Tab**：上传/下载/删除/按类别分组展示
5. **TraceTimeline 附件显示**：节点挂附件 + 下载

### 阶段二：备份与预警（P1）
6. **备份调度器**：每日增量 + 每周全量（Spring @Scheduled 或 xxl-job）
7. **容量统计**：定时统计 upload 总大小/当日新增大小
8. **预警触发**：超过阈值 → sys_notification + 页面预警卡片
9. **文件管理页**：大文件 TopN / 按日期类型统计 / 清理（软删+回收站）/ 归档迁移

### 阶段三：工程文件迁移与收尾（P2）
10. **迁移工具**：扫描桌面 `jjx/JST-*/` 目录 → 复制到 upload/product/ → 生成 sys_attachment 记录
11. **预览支持**：pdf/jpg 在线预览（浏览器原生），cdr/dwg 仅下载（无预览）
12. **回收站**：软删除文件进回收站，30 天自动清理

## 七、风险与注意事项

1. **单点存储风险**：本地磁盘故障 → 依赖备份策略兜底；建议 backup 目录放不同磁盘/共享盘
2. **大文件上传**：cdr 可能几十 MB，需调大 Spring 上传限制（`spring.servlet.multipart.max-file-size`）
3. **文件一致性**：数据库记录与磁盘文件可能不一致（手动删了文件/记录丢失）→ 备份日志 + 定期对账任务（可选）
4. **权限**：文件访问要校验（现有 @SaCheckPermission），产品文件按产品权限控制
5. **命名冲突**：产品文件保留原文件名，同目录同名 → 自动加序号（`xxx (1).cdr`）
6. **备份性能**：全量备份在周末低峰执行，增量用复制而非移动（源文件不动）
