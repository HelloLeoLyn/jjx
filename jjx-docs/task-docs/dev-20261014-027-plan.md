## 1）目标

1）**先给结论**：这个图标属于"业务附件（挂在单据/主数据上）"还是"资产（图标库，会被多处引用）"？
   - 若属**业务附件** → 新增来源（如 `engineering_jjx_icon` 或 `process_icon`，照 018/022 先例：权限前缀、单号 SQL 取工序编号/task 化）→ 换公共附件组件；
   - 若属**资产** → **不要迁**到公共附件（公共附件是"引用+解绑"语义，与"图标被多处引用"冲突），改为只把上传通道收口到受控入口，另立卡说明。
2）结论定了再动手；换的话删除语义改为"解除引用"。
