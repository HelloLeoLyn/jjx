## B. `036` 草稿键按实例（询价 / 样品单 / 销售订单 / 报价单 各走一遍）

以询价为例：

1. **销售管理 → 询价管理 → 点「新增」** → 弹出"新增询价"。

**B1 新建隔离**
- 在附件区上传 1 个文件 → **不保存**，点窗口左下角「**关 闭**」（或右上角 X）。
- 再点「**新增**」→ **期望：附件区是空的**（待绑定列表里没有刚才那个文件）。

**B2 刷新恢复**
- 点「新增」→ 上传 1 个文件 → **按 F5 刷新整个页面**。
- **期望：刷新后自动重新弹出"新增询价"，且附件还在"待绑定"列表。**

**B3 显式恢复**
- 先制造一条未保存草稿（新增→上传→关闭）。
- 再点「**新增**」→ 附件区**上方**会出现「**恢复未保存草稿**」按钮。
- 点它 → 选一条 → **期望：那张草稿的表单内容 + 附件一起恢复**。

**B4 同文件独立**
- 新增 A → 上传文件 X → 关闭；再新增 B → 上传**同一个 X**。
- **期望：B 的待绑定区只有 B 自己那条**（不显示 A 的）。

> 到 **样品单管理 / 销售订单 / 报价管理** 各重复 B1–B4。
