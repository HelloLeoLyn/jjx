## 卷材跳距：先明确计量对象

跳距表示相邻加工节拍的送料距离，不能默认等于成品净长。确认一个卷材定额至少需要：产出计量单位、每跳产出数、送料跳距、实际参与耗用的卷宽、投入计量单位，以及损耗是否已包含在跳距或定额内。多排、多列或多联排版必须明确每跳实际产出数；不能只根据宽度和成品尺寸猜排版。

允许继续使用人工确认的模数/基数。是否增加“跳距辅助试算后由用户确认形成定额”的入口，仍待产品方向确认；这不是本轮已授权实现的自动公式。两种表达不能各存一套独立权威耗用值。跳距辅助只给建议值及依据，不能静默改动既有 BOM。

下表全部是隔离验收算例，未写入真实物料或 BOM。假设卷宽 W=195mm、送料跳距 P=80mm、每跳产出 N=1PCS，未另计起机、接头、边料或报废；投入按长度或面积计量。若实际还有损耗，需另给确认规则，不能将“未计损耗”解释为现场没有损耗。

| 量 | 算例及预期 |
|---|---|
| 每件理论用长 | P ÷ 1000 ÷ N = 0.08M/PCS |
| 每件理论用面积 | W ÷ 1000 × P ÷ 1000 ÷ N = 0.0156M2/PCS |
| 需求 300PCS、可分配半成品 140PCS | 本轮只制造 160PCS；展开原料 12.8M，即 2.496M2 |
| 每跳产出改为 2PCS，制造 160PCS | 80 跳，6.4M，即 1.248M2；不能仍按每件一跳 |
| 净长 80mm、实际跳距 100mm、每跳 1PCS | 按已确认送料距离计算每件 0.1M，即 0.0195M2；不得用净长低估耗用 |
| 仅有“195×80”规格文本，缺送料/排版依据 | 保留原人工定额；不从规格自动生成或重写跳距耗用 |

定额表达必须保留原语义：例如本层产出模数 1PCS、投入基数 0.08M，或产出模数 100PCS、投入基数 8M。两者等价，但不能把模数和基数倒置。6模1基数、需求300件时，精确结果为50份投入；这与卷材按M/M2的小数计量可同时成立。

## 从需求到余料的完整验收

| 场景 | 必须成立的行为 | 证据与反例 |
|---|---|---|
| 有足够半成品库存 | 直接分配该半成品；不展开制造原料 | 需求、分配、净制造量能对账；原料需求为0 |
| 半成品部分有货 | 仅净缺口展开；按合适制造方案形成待制造需求 | 上述300/140算例只能为160件展开；不能300件再次全展开 |
| 两条上层路径共用半成品 | 汇总同一计划范围的需求并统一分配库存 | 需求100+80、可分配120，则净制造60；不能两个分支分别占用120 |
| 跨层重复使用同一物料 | 按依赖顺序汇总、净算；供给只能占用一次 | 给出各层毛需求、已分配、净需求及来源；不能在父层和子层重复扣同一批 |
| 原料按 M2 库存、BOM 按 M 投入 | 有明确宽度与来源后进行换算 | 195mm宽、12.8M=2.496M2；无宽度或冲突依据应拒绝跨单位计算 |
| 长度随卷变化 | 每卷实发依实际批次/卷的可用数量 | 不从物料档案硬编码50M，也不假定所有卷等长 |
| 整卷实发 | 示例整卷50M，对应9.75M2；发料记录完整卷/批次与实际数量 | 理论2.496M2与实发9.75M2并列；不能把理论量写为整卷实际出库量 |
| 余料退回 | 根据实测/确认退料记录逆向业务与库存流水 | 理论余料37.2M/7.254M2只作对照，不能自动回库。若实际退36M=7.02M2，净发出14M=2.73M2，须保留与理论2.496M2的差异，不能抹平 |
| 实耗与差异 | 记录实耗或明确现场核算依据；实发减实退是净发出 | 有在制、转移、报废时净发出未必等于最终实耗；不能强行等同 |
| 半成品完工与上层领用 | 有效完工/质检规则下形成批次入库，上层领料引用该批次 | 查到完工单、质检判据、入库流水、上层出库与数量链路；只手工入库再领一次不能证明制造闭环 |
| 三层及更多层 | 同一套规则逐层净算；不同方案/版本在上下文中可追溯 | 缺失方案、失效日期、循环、单位无依据都给明确错误，不悄悄降为采购或直接耗用 |
| 版本变动与在途业务 | 查看影响范围，按约定变更或重开；已有业务采用依据可追溯 | 保存下层草稿不能直接改变正在发料的上层已采用版本 |
| 并发和权限 | 普通保存不能批准；旧编辑不能覆盖新数据；无权操作被拒绝 | 审核隔离由015覆盖；并发覆盖018、有效期019仍待统一流程后实施 |
