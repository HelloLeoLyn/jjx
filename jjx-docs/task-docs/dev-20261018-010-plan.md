## 3）公共契约（出卡时冻结）

A) 所有计划、印刷、BOM、备注、轮次和执行状态继续由现有 workbench.vue/useSampleWorkbench 持有。新视图只接收 props/slots、转发事件；不得复制业务状态、另建请求或保存链。三个实施者对共享 composables 全部只读。

C) SampleProcessPlanEditor 保留 controller 与 active-plan-tab 契约，选择器改成可展开/收起的「添加标准工序」区域；折叠时不保留400px空白。拖拽到新卡和现有卡、多选追加、下标、批量、常用材料、物料建档全部保留。
D) BomPanel 新增可选 showTransfer:boolean（默认 true），仅控制现有资料转移区显示，不改变 transfer 事件；009 可传 false 后将同一动作移到公共更多菜单。其他已有调用方行为保持。
E) 新 SampleExecutionView.vue 必填 props：readonly:boolean、orderId:number、roundNo:number、planList:any[]、printList:any[]、formatTime:(t?:string)=>string、parseMaterials:(json?:string|null)=>any[]、saving:boolean。可选回调 props：advancePrint、advancePlan、execBlockReason、printBlockReason，保持 ExecutionTimeline 同名签名。事件：mark-ready、view-files。组合原 ExecutionTimeline 和 DefectRecordPanel，包含查看图纸及标记样品完成入口；不直接调 API。mark-ready 的判断和确认沿用父级 handleMarkReady。
F) ExecutionTimeline 现有 props/推进逻辑不改，只优化当前工序呈现；DefectRecordPanel 可用可选 compact:boolean（默认 false）控制历史记录默认折叠，但新增/删除/权限与样品单级记录归属保持不变。
G) 当前轮两个视图用 v-show 或其他保留实例的方式切换，不能因切换卸载清草稿、触发自动保存、重载覆盖或推进执行。历史轮始终只读，不挂载当前轮的新方案/执行视图；公共复制、清空、资料转移禁用，不能调用当前轮写事件。公共轮次在视图之外；既有历史工序、印刷、BOM快照都要能查看。
H) 顶部公共摘要保留样品单/产品/当前轮/状态；公共操作收敛复制方案（沿用原弹窗全部来源）、查看图纸、历史与更多。清空当前轮移到更多且沿用原确认及「保存后生效」语义；资料转移沿用原弹窗；复制上一轮通过原复制方案入口承接，不删能力。
I) 保存语义不合并：「完成编辑」只结束卡片本地编辑，不代表已保存；「保存工序计划」覆盖组装、印刷及BOM独立材料；「保存工艺参数」仍单独保存。印刷行保存需说明会保存整份工序计划。不得用新「统一保存」按钮掩盖分开的事务。
