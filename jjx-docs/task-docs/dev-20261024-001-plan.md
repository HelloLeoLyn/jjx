## 新模型契约

1）类型：分类根节点 `RAW(R)`、`SEMI(S)`、`FINISHED(F)`；原材料下 `RAW_BASE`、`RAW_AUX`、`RAW_INK`。分类是业务维护真源；物料现存 material_type 仅由根节点派生供接入期间使用，历史编码不重编。
2）材质、颜色、形态、单位、品牌用 `sys_dict/sys_dict_item`，使用既有 dict_code，不新增 dict_type。品牌不放材质；元件类型放模板字段，不伪装成材质。
3）每个可录入末级分类一份属性模板。物料只存 category_id，不单独维护 template_id。模板结构有 version；已有新模型物料引用后，结构修改拒绝，允许在使用前配置。未来版本迁移另行明确，不静默重解释历史值。
4）通用字段：original_name、original_specification、material_meta、material_form、model、color、brand、unit、size、is_customer_supplied、is_sample。size 仅宽或宽×长，单位统一 mm；厚度 thickness_mm、克重 gram_weight_gsm 在 attribute_json 中数值存储，单位由模板固定，不再加 thickness/width_size 同义列。material_grade 是派生展示。
5）原名称是新建必填来源；原规格保持原貌；material_name 使用原名称作为默认业务显示，specification 由结构化属性生成。保留业务补充，原资料不塞 remark。供应商优先关联 supplier_id，不能把括号内容直接认作品牌。
6）is_customer_supplied/is_sample 仅表示档案专用标记，不承担批次所有权或某次打样用途；半成品模板不保存实时工序进度。
7）服务端校验：字典启用值、模板材质候选、属性 key 白名单、类型、单/多选值、必填、数值单位与范围；schema 原子校验并生成规格。默认值不能推断无证据事实。
