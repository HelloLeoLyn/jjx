## 业务结果

1）采购数量/采购单位与只读计价数量/报价单位分别常显；单价4位、金额2位。品名优先供应商品名，内码/内部名称置小字，保留搜索、重新选料及物料详情。税率、卷材/片材尺寸、折合价和采购加工交货说明在行展开区；新增/修改用同一表，失败保草稿，关闭/换料/删行后的迟到响应不回写。
2）物料档案仅沿用基本单位和结构尺寸，不加实物形态或辅助单位。供应商+物料的默认采购/报价单位是采购配置，显式“设为本供应商默认单位”才保存，后续新选料自动带出；不按长宽猜卷材、不硬编码料号，也不把订单数量/单价存为默认。修改旧单只读配置状态，不覆写已存本单单位和尺寸。配置读取失败须重试，不能静默按基本单位保存。
3）采购说明独立于inspection_remark，保存/复制/回读/详情/A4及QR-024打印均承接；说明不重复计价，不自动生成委外工序、多产出收货或库存。供应商分切后的多物料收货仍属后续闭环。
4）原新增、编辑、取消、审批、收货、付款、附件等入口和审核状态机保留。本任务不改库存写入、成本写入、收货容差、物料基本单位或历史账数据。

## 后端唯一计算规则

PurchaseOrderServiceImpl.calculateItemPricing保留原入口，调用PurchaseQuantityPricing。原始purchaseQuantity与单位按本单尺寸精确换算，quantity始终库存基本数量；priceQuantity只读派生不落库，不信客户端金额/计价数量。使用既有ExactQuantity，不用浮点或先舍入的每件量反乘。
卷材沿用按卷采购、按㎡/米/卷报价及按卷报价不足整卷CEILING；新增固定PCS/张与㎡之间计量，按片长宽换算；反算库存PCS/张必须整数，不静默舍入，换算结果小于库存4位精度拒绝。KG、针、套等同单位可用，无依据的单位组合拒绝，不把PCS/张/针/套当成1:1。
行税额沿用原未提前舍入、单头合计落金额精度的规则；仅把税率补为本单持久信息，前端直接展示后端整单合计，不逐行相加已舍入税额，也不复制税率计算。历史正税额但缺行税率的编辑需明确确认，不能默认0抹税。基本数量4位、计价数量展示12位、单价4位、金额2位；大数/极端指数有边界校验。
