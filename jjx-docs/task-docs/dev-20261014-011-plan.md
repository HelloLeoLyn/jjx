## 0）一屏速览

**一句话**：新增样品单时，「打样产品」原来只能选**已建档**产品，现实里打样常是新品；现在在选择器后加「新建产品」按钮 → 打开产品编码器弹窗生成编码 → 作为打样产品，`productId` 留空，**保存时由后端自动建档**（草稿 `DEVELOPING`）。

| # | 拍板项 | 定论 |
|---|---|---|
| 1 | 入口 | 打样产品选择器旁「新建产品」按钮（`el-select` 无 `#append`，用 flex 行） |
| 2 | 弹窗 | 抽**公共** `ProductCodeGenDialog`（`QuotationCodeGenDialog` 改为其薄封装，两边共用） |
| 3 | 名称 | 弹窗内加「产品名称」输入，**默认预填产品编码**、可改（后端 `productName` 必填） |
| 4 | 建档时机 | **随样品单保存**由后端 `ensureDraftProduct(code,…,"sample",customerId,四选…)` 建档（同询价/报价口径） |
| 5 | 互斥 | 来源=报价单带入产品时隐藏按钮；编辑态禁用新建 |

**禁做**：另建一套编码逻辑（必须复用 `ProductCodeGenerator`/`useProductCode`）；在保存前就建档（保持"随单建档"）。

## 1）背景与证据

- 现状：`views/sales/sample-order/components/SampleForm.vue` 的「打样产品」是 `el-select` 远程搜 `searchProduct(keyword, customerId)` —— 只能选**已建档**产品，且先选客户。现实样品常无档案 → 搜不到。
- 已有能力：`components/ProductCodeGenerator/index.vue` + `composables/useProductCode.ts`（编码=客户简称+序号+面板2位+线路2位）；`views/sales/quotation/components/QuotationCodeGenDialog.vue`（报价明细行已用）；`useProductCode.defaultFetchSerial` → `GET /product/code/next-serial`。
- 后端先例：`ProductServiceImpl.ensureDraftProduct(...)`（询价 `InquiryServiceImpl:213/249`、报价 `QuotationServiceImpl.ensureSampleDraftProducts` 都用它：productId 为空 + 有 code → 建档草稿，参数写 `product.spec_json`；已存在→复用/校验客户归属；缺参数→补写）。

## 2）改动清单（本卡已落地）

**前端**
1. 新增 `jjx-web/src/components/ProductCodeGenDialog/index.vue`：通用编码弹窗（四选自动取号 + 撞号避让 + 可选「产品名称」输入），`confirm` 回 `{params, productName}`。
2. `views/sales/quotation/components/QuotationCodeGenDialog.vue` → 改为其薄封装（对外 props/emits 不变，调用方无感）。
3. `views/sales/sample-order/components/SampleForm.vue`：选择器旁加「新建产品」按钮 + `ProductCodeGenDialog` + 回填「新产品·待建档」态；`productId` 留空、携带编码参数。
4. `views/sales/sample-order/components/types.ts`：`CustomerOption` 补 `customerShortName`；`SampleProductItem` 补编码参数。
5. `types/sales/sampleOrder.ts`：`SampleOrderItemInput` 补编码参数。

**后端**
6. `SampleOrderCreateDTO.Item`：加 `serialNo/panelType/panelFeature/circuitType/circuitFeature`。
7. `SampleOrderServiceImpl.createSample`：建明细前，对「`productId` 空 + 有 `productCode`」的行调 `productService.ensureDraftProduct(...,"sample",customerId,四选...)` 回填 `productId`（其余逻辑不变）。

## 3）验收与验证

- 行为：选客户 → 「新建产品」→ 四选（自动取号）→ 改名 → 确定 → 打样产品显示「编码 - 名称 · 新产品」；保存样品单成功；产品档案出现该编码（`DEVELOPING`）；打样工作台能看到该产品。
- 反例：未选客户就能点新建（应禁用/提示）；产品名称留空（后端必填 → 用编码兜底）；编码已存在 → 复用不重复建档。
- 自查：`mvn -o -q compile` 通过；`npx vue-tsc --noEmit` 通过。
- 运行态（建档→样品单→工作台）属用户验证；本卡未开浏览器。
