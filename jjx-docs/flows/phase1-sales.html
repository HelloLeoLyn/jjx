📊 询价→报价→销售接单

阶段一完整链路：询价 → 报价 → 报价审核/发送/确认 → 转订单 → 订单审核/客户确认 → 提交生产
阶段一：从询价到提交生产
A — 询价单 SalesInquiry
📩 创建询价单 → 客户/产品描述/数量/规格 → 状态选择: draft/pending/sent → 💾 保存
状态机: draft→pending→sent→accepted/rejected→converted → 🔄 询价转报价 convertToQuotation()
B — 报价单 SalesQuotation · 7状态
📋 创建报价单 → 选客户/产品/价格/数量 → 币种/汇率/折扣 → 💾 草稿(DRAFT)
⬇
📤 提交审核 → 通过？ 通过 → ✅ 已审核(APPROVED) → 📤 发送给客户 → 状态→SENT
驳回 → 退回修改
📤 直接发送(跳过审核) → draft→sent→accepted
🤝 客户接受报价 → 🔄 报价转订单 convertToOrder() → 调用 IOrderService.insertOrder()
C — 样品单独立流程 SampleOrder · 10状态
1 已创建→ 2 待审核→ 3 打样中→ 4 待送样→ 5 已送样→ 6 确认→ 7 转量产| 8 关闭
← 9 客户退回 → 回到3重新打样
D — 销售订单 SalesOrder · 12状态
📋 创建订单 → 选择客户/产品/数量/交期 → 自动编号·订单类型(1标准/2样品)
🔴 校验: 产品状态=RELEASED 第136条 → 💾 草稿(DRAFT)
⬇
📤 提交审核 → 校验客户/日期/金额 → ⏳ 待审核(PENDING_REVIEW) → 🔍 审核中(REVIEWING)
⬇
审核
通过？ 通过 → ✅ 已审核(APPROVED) → 📝 操作日志写入
驳回 → ⛔ 退回修改(回到DRAFT)
⬇
🤝 待客户确认(PENDING_CUSTOMER_CONFIRM) → 📄 客户确认订单 → 确认人/方式/时间/备注 → ✅ 已确认(CONFIRMED) 第129条
过期 → 已过期(EXPIRED)
⬇
▶️ 提交生产 → 🔴 校验: BOM已审批 + 路线已审批 第130条 → 创建生产工单 → 🏭 生产中(IN_PRODUCTION)
⬇
📤 已发货(SHIPPED) → ✅ 已完成(COMPLETED) ┃ ❌ 已取消(CANCELLED) 任意状态可取消
📌 审核联动事件
订单审核通过 → 操作流水 + 消息通知 + 任务派送 产品未发布 → 自动派工程任务（阶段二） 创建订单选产品校验 productStatus=6(RELEASED)
◆ 菱形 = 判断分支  |  🔴 = 代码校验点  |  整个流程起点是询价单，终点是提交生产
