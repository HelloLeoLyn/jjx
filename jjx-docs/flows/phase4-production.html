📊 生产执行流程

阶段四：排产 → 生产 → 工序执行 → 完工 → 质检 → 入库 → 工单关闭
生产执行
▶ 从销售阶段进入生产
订单已确认(CONFIRMED/7) → 🔴 校验: BOM已审批 + 路线已审批 + 库存足够 → 📦 提交生产→创建工单 #130
工单关联BOM编码/ID | 工单关联路线编码/ID | 记录当前BOM/路线快照(追溯用)
📅 工单排产→ 计划开始/结束时间→ 状态→待排产→已排产→ 车间看板显示
⬇
🏭 开始生产→ 状态→生产中→ 首道工序激活
⬇
⚙️ 工序执行→ 填完工数量/工时→ 下一道工序激活 ↻ (印刷→冲切→贴合→SMT→装配)
⬇
✅ 生产完工→ 状态→已完成→ 触发质检
⬇
🔬 质量检验
创建质检单(PENDING) → 录入检验结果 → 合格？ 合格 → PASS→ 🏠 完工入库
不合格 → FAIL→返修(REWORK) → 复检 ↻
📦 创建入库单→ 关联工单/产品/数量→ 保存(DRAFT)
⬇
✅ 确认入库→ 成品库存增加→ 库存流水写入
⬇
🔒 工单关闭→ 状态→已关闭→ 不可再操作
📌 成本 & 工单信息关联
💰 BOM成本集成 → ProductionCostController 查BOM计算物料标准成本 📋 工单详情含: BOM编码/路线编码/工序执行/质检/操作日志 🔄 创建工单时记录当时BOM ID和路线ID(历史追溯)
🔴 = 代码校验点  |  质检合格才能入库  |  完工入库后库存可销售发货
