## 入口和使用

发货管理顶部增加“新建合并发货（预览）”。原发货列表和已有操作保持现状。新增弹窗依次展示收货信息、可选订单、本次发货、送货单预览；右侧概览包含订单数、明细数、数量、货品金额及待检项。

默认示例来自用户提供的 QR-026 截图结构：友隆客户，JY260843X / JY260677X 两张订单，每张三条明细，默认数量分别 636 / 900，合计 4608。额外提供同客户不同地址的不可选订单和第二客户，用于体验地址限制、客户切换及空搜索结果。所有地址与业务字段均为演示数据，不查询真实订单。

- 可按销售单号、客户订单号、料号、品名搜索；支持逐行选择、整单加入、加入可发明细。
- 数量口径为订单量减已发减待发占用；每行按来源订单分开。超量、空数量或非合法数量阻止创建并显示行内提示。
- 已选明细后锁定客户和地址，清空后可切换；不同交期可合并并提示。
- 待检明细可先建演示待发货单。质量结果和发货状态复用现有枚举，没有新增本地状态映射。
- 送货单预览逐行显示客户料号、品名、数量、销售单号、客户订单号；支持金额/单重列开关，每六行一页，仅预览。
- 创建后仍保留弹窗显示演示详情，并增加关联订单、质量检验、出库与签收记录页签。列表上方出现独立的演示单据表，可重新打开详情；刷新页面即清空。
- 演示入口及单据明确标识；没有 API 写入、持久化缓存、打印次数或库存变动。mock 单据不进入真实列表。
