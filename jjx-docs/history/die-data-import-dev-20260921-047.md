## 口径与映射（与后端「刀模导入」功能一致）
- 刀模编号 = 客户列（`JST-412`）；`XY` 表用「客户+流水号」→ `XY-001`；统一大写、数字补 3 位
- 状态：`报废→SCRAPPED`；`无刀/空档/只印刷/打样/暂不用→STOPPED`；`委外/送修→MAINTENANCE`；`刀模共用 X→AVAILABLE`
- `数量→quantity`、`入库日期→stock_in_date`、`存放位置→location`、`备注/祥情→remark`（非纯状态词的描述保留原文，「共用 X」写备注前缀）
- 存储位置：**`B-Fb1   003` 是「架位 + 盒号」的一个库位**，不能按空格拆；只有同格出现 ≥2 个库位码（如 `C-Fc2 006  C-Fc2 003`）才拆成多库位用「；」连接（首版脚本按 2+ 空格拆，误拆 4,367 条中的盒号，已修正并重跑）
