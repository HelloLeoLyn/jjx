# BOM 组合序号展示纠正复盘（dev-20261022-023）

日期：2026-10-23  
关联任务：dev-20261022-023、dev-20261022-025

## 原始要求与偏差

原要求是保留 `BomItemEditor` 已有的组合可见样式，并让其他 BOM 页面参照它显示组合关系。编辑器原有样式是 50px「序号」列：同一组合的序号纵向合并，独立材料不显示组合号。

实施时把“让组合关系可见”误解成在编辑器新增宽的「组合 / 独立材料」文字列，并在详情、审核和打印页面展示较长的分组说明。这改变了原有样式，也挤占了表格宽度。用户反馈后确认，编辑器原样式本身已满足要求，目标仅是复制到其他页面。

## 修正内容

- `BomItemEditor` 恢复原 50px「序号」列和组合序号合并显示；保留 026 的物料搜索未确认保护，并移除编辑器行内新增的提示文字，避免撑高表格行。
- BOM 详情和审核表增加窄序号列，按组合关系合并组合号；审核表仍保留「选择本组待审」入口。
- BOM 打印预览在序号格合并显示组号，项目格恢复只显示项目名称和图标。
- 产品作业规范纸张模板 A 显示项目组号；模板 B 保持既有组号显示。
- 共享分组模型增加展示用序号：沿用组合序号样式，空项目的独立材料不占用展示编号；分组仍依据已有保存关系或历史推定规则计算。
