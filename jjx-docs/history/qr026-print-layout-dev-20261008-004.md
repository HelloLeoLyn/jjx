# QR-026 纸版送货单位置与字体优化

任务：dev-20261008-004；日期：2026-10-08。

## 范围与依据

用户授权先优化纸版 QR-026 的位置、字号和打印效果。参照当前工作区 JJX-QR-026送货单.xlsx 的 Sheet「QF 新26年」：A3:I3 公司名居中 20pt、D5:E5 标题 16pt、正文和明细 11pt；表头行高 34.5pt、明细行高 27pt，预留五行；TO/Attm 与 NO/DATE 分别上下排列。

Excel 当前有他人未提交修改，本任务只读取，不修改或提交该文件。Excel paperSize=260 无法直接确认为 A4，按用户批准的建议沿用现有 A4 纸型，实际打印机校准尚需用户试打一页。

原网页公司名 16px 靠左、明细 10px、明细行 23px，与模板字号/高度差距明显；客户和联系人左右并排，标题、地址和单号采用相互独立的绝对定位；明细不足时说明与签字区向上移动。

## 改动

- 新增纸版专用 Qr026DeliverySheet.vue，脱离公共 A4Canvas。页面尺寸 210×297mm，边距按 Excel 近似为上/下 11mm、左 8mm、右 18mm。使用命名 @page qr026Delivery，屏幕和打印分别处理纸张边距。
- 公司名居中 20pt，标题 16pt，正文/明细 11pt；宋体优先，并设中文衬线字体后备。打印前等待 Vue 更新及 document.fonts.ready，减少字体加载造成的位置变化。
- 抬头与表格共用九列栏位；客户、联系人在左侧上下排列，单号、日期在右侧上下排列；公司地址和二维码有独立区域，不覆盖公司名。
- 表头约 12mm、明细基准行高 9.5mm；每组五条、不足补空行，超过五条显式换页并重复抬头/表头。长文本换行，不设置裁剪高度；极长内容由浏览器自然续页。
- 费用、说明、签字区仅在末组显示，作为完整区块避免单独把签字区落到下一页。
- QR-026 存在时才清除应用外壳的打印占位；纸版 CSS 独立。三联纸 HTML 与专属布局 CSS 对比原版本完全一致；其原有通用表格颜色、对齐规则保留。
- 不调整送货单金额/运费业务口径、不增加收货地址等业务栏位，不变更发货、出库或打印留痕接口。这些问题仍归属待开始任务 dev-20261008-003。
