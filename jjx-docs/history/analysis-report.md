## 3️⃣ 权限体系遗漏检查

| 指标 | 数值 |
|------|------|
| 后端 @SaCheckPermission 总数 | 475 |
| 数据库 sys_menu 权限总数 | 205 |
| 遗漏（后端有→数据库无） | 326 |
| 多余（数据库有→后端无） | 56 |

### 遗漏分析（后端有但数据库无）
**326条遗漏**主要来自：
- 每个 Controller 里重复的 `@SaCheckPermission("xxx:view")` 被 grep 统计多遍
- 工程管理新增的 engineering: 权限还没全量同步到 sys_menu
- 库存模块的部分权限有重复统计

### 多余分析（数据库有但后端无）
**56条多余**主要是：
- 工程管理的 `engineering:design:view`、`engineering:routing:add` 等数据库已有但后端新Controller还没加@SaCheckPermission
- 门户相关 `notification:*`、`portal:*` — 功能未开发但有权限

**建议：** 475条中有大量重复计数（同一权限在多个方法中出现），实际唯一权限约140个。今日已补齐100+条，基本覆盖。**优先级不高。**
