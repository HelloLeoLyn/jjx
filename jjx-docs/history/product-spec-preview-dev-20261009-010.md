# 产品电子文档集前端预览与打印版式（dev-20261009-010）

日期：2026-10-09

用户在交接单基础上补充：assets/tmp 的照片是已有电子文档集的实物打印成果；目标是按其版式在线预览并直接打印。随后明确先做前端效果。本次为前端阶段，原任务后端资源查询与完整页签接入留待后续。

## 本次实现

- 作业规范详情的“生成文档集”改为“预览 / 打印文档集”，直接打开大幅纸张预览，左侧为可勾选的目录及具体文件，右侧为分页 A4；支持缩放、跳转、重新加载。
- 作业规范采用截图的材料表、刀模/库位、凹凸条件留白、面板/上线/下线流程、结构图、工时、变更与发行栏和产品页脚。复用工序 SVG 图标；合并工序以子作业链展示。材料或工序过多按行数生成续页，未分类工序单独保留。
- 印刷规范按面板/上线/下线及未分类分区，展示当前路线的印序、色号、油墨编号、网框编号、备注；参数来自 customProcessParams，不复制数据库主数据。暂未建立油墨物料/网版资源库位引用，现有编号以实际保存值展示。
- 附件按真实内容预览：图片通过现有带 token 请求下载并显示，PDF 使用仓库已有 pdfjs 逐页展开。支持逐个文件勾选，图片保持比例；不支持的 DWG/CDR 等格式提示打开原文件，不冒充可打印内容。
- 客供稿、询价/报价附件、客户确认样品在预览/打印的客供资料区归集；样品区只放实物照片。产品图集包含指导图、结构图等工程附件。现有维护页签的类别默认值及归位暂未调整，后续统一处理。
- 原独立打印路由复用同一预览、纸张组件，携带文档/文件选择。弹窗点击打印后，在独立页重新读取当前资料并等待附件/字体加载后打开浏览器打印；打印样式只在独立页存活期间生效。关闭组件回收图片/PDF页面 Blob URL。
- 无结构图、未关联刀模或未维护凹凸数据时保留空态/空栏，不把照片、手写信息或批准章伪装成当前产品资料。原图库照片仅作版式参照，本次不复制进应用资源。

## 验证与部署

按用户“只做代码，测试/编译/重跑交给我”的指示，没有执行 validate、类型检查、编译、测试、浏览器或实际打印验证；仅阅读源码、审阅提交差异。无后端或接口改动、无业务库写入、无配置 SQL、无服务生命周期操作；仅按仓库规则更新本任务登记及待审核元数据。

用户查看路径：产品管理 → 产品列表 → 作业规范 → 预览 / 打印文档集。工程侧共用页面也能进入。

用户需验证：文档/文件勾选与打印对应；工序图标及当前 BOM/路线数据；材料/工序续页、长文本与分页边界；图片/PDF展开；浏览器打印 A4 原比例、关闭浏览器自带页眉页脚；取消勾选失败附件后其他文档可打印。PDF以展开图片打印，图纸清晰度及实物打印需用户确认。

## 后续

本次完成前端阶段，整体资料规范仍待用户确认效果后继续：网版反查的 SCREEN_PLATE 查询、油墨精确关联、维护页签客户确认样品归位与文件库类别默认值、缺失业务字段以及文档版本/发行数据。打样领料沿用既有最多100样品、200出库记录的分页读取限制，本次未扩展后端汇总接口。凹凸条件、分色表、油墨调配表不新增结构化录入。
