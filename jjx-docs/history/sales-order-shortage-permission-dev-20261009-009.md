# 销售订单齐套检查统一专用权限（dev-20261009-009）

日期：2026-10-09

用户要求先按 `sales:inventory:alert:check` 快速修改，权限设计规范后续讨论。

原销售订单列表按钮校验 `sales:order:edit`，确认接口校验 `inventory:alert:edit`，导致按钮可见而确认被拒绝。

本次将列表入口、弹窗确认按钮、只读预览接口、确认生成缺料预警接口统一到 `sales:inventory:alert:check`。保留原计算、预警生成、订单状态条件及其他库存预警接口权限；不调整库存流水或余额。原销售订单编辑或库存预警编辑权限不再单独授予此项能力。

新增 `jjx-docs/sql/migrations/249_sales_order_shortage_check_permission.sql`：在销售订单菜单下幂等新增“齐套检查”权限按钮，显式 icon=NULL，无DDL，无业务数据修订，无自动角色授权。编号取目录最大248与已应用最大245的较大者加1。

按用户要求仅提交代码，不运行测试、编译、重跑或其他验证命令。仅阅读源码和提交差异。未执行配置SQL、未调整角色、未修改服务运行状态。

部署后由用户执行权限SQL，在角色管理中分配“销售订单 / 齐套检查”，重新登录刷新权限，并使后端加载新代码。用户验证：有新权限可预览和确认生成订单缺料预警；无新权限入口及确认按钮隐藏、直接请求接口被拒绝；其他库存预警操作仍受原权限控制。
