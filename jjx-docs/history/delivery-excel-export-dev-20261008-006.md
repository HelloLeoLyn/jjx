# 送货单增加可编辑 Excel 导出

任务：dev-20261008-006；日期：2026-10-08；执行：Codex。

## 背景与范围

用户要求增加 Excel 导出，客户可以自行调整打印格式。入口位于销售发货管理的送货单打印页，纸版和三联纸选项旁新增“导出Excel”；统一下载可编辑的 QR-026 样式工作簿，不增加新的打印模式。

## 实现

- 后端 `GET /sales/deliveries/{deliveryId}/export-excel` 复用 `sales:delivery:view` 权限，使用现有 Apache POI 生成 `.xlsx`，不引入依赖，不变更数据库结构。
- 公司名称、地址来自启用的系统配置。客户、联系人、电话、收货地址、承运商、物流号来自送货单；订单只读取源单号。
- 表格以 `sales_delivery_item` 本次发货快照为依据，包含料号和品名、规格、单位、数量、单价、金额、源订单号、备注。缺少快照时提示核对，不以完整订单代替分批发货明细。
- 数量和金额为数值单元格，金额保留两位小数；电话及单号保持文本。以等号开头的客户文本仍是字符串，不生成公式。
- 预设宋体，正文11pt、公司20pt、标题16pt，边框、换行、最少五行明细、长规格估算行高及签字区。工作表不保护，可调整全部单元格、字号、列宽、行高、分页及打印设置。
- A4竖向，左右15mm、上下12mm，横向一页、纵向自然分页，重复公司/单据信息和表头；较多明细全部导出，不限制五行。Excel/WPS最终渲染与用户字体、打印机有关，允许客户继续调整。
- 以“单据合计金额（原值）”保留存储金额，另列运费、保价费和其他费用，不推算收费合计、不修正原金额。现存 SO261007001 金额口径整改仍由 dev-20261008-003 跟进。
- 前端处理 JSON Blob 业务错误，防止下载损坏文件；下载期间防重复点击，缺少单据时禁用按钮。导出不调用打印留痕，不改变打印次数或业务数据。
- Excel含可编辑表单，不嵌入浏览器打印二维码图片；已有网页纸版二维码和两种打印功能保持原样。
