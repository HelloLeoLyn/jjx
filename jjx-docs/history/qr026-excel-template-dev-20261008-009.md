# QR-026 Excel 改为原模板填充

任务：dev-20261008-009；日期：2026-10-08；执行：Codex。

## 背景与范围

用户反馈重绘的Excel布局与QR-026原模板相差较大，批准改为读取原模板、仅填充数据。本任务保留后端导出接口及前端入口，替换工作簿生成方式。

## 实现

- 使用当前 `jjx-docs/print_template/JJX-QR-026送货单.xlsx` 制作可部署的空模板资源 `jjx-server/src/main/resources/templates/sales/qr026-delivery.xlsx`。原文档模板是在制品，本任务只读取，未修改或提交它。
- 空模板保留原始字体、边框、样式、列宽、行高和合并位置。清除示例客户、料号、规格、订单号、日期、数量及经手人，运行时填入公司配置与本次送货单快照。
- 公司放A3，标题仍在D5:E5、公司地址仍在G5:I5；客户及单号填B6/H6，联系人及日期填A7/H7；明细保持A9:I13五行，每行27pt；说明与签字位置保持第14、15行。
- 品名(料号)栏按模板使用单行料号，缺少料号时使用品名；完整料号、品名及长规格另保留在“发货数据”。文本直接写字符串，不执行公式；数量、价格及金额保持数值。
- 超过五行时，在填值前复制空表单，生成“送货单-1/2/3”等工作表；每张五行，序号连续，尾页空行清空，无重复或漏项。12条数据生成3张表单。长规格保留完整文本，行高不自动改变，客户可自行调整。
- 移除此前重绘的地址/物流行、四行费用及扩大的行高。“发货数据”另存收货地址、承运商、物流号、单据合计原值、运费、保价费、其他费用及完整明细，保留业务信息且不挤占原表单。金额不重新推算，原有金额口径整改仍属于dev-20261008-003。
- 原模板纸型是WPS自定义编号260，导出统一为Excel/WPS可识别的A4竖向；每张表单打印区A1:I16，单张适应一页。页边距沿用此前用户确认的左右15mm、上下12mm。这是有意保留的打印设置调整，未声称原模板页边距完全不变。
- 工作簿从classPath加载，随后端资源打包，不依赖运行机器存在文档仓库。无新依赖、数据库写入、打印留痕或接口权限变化。

## 验证

- 原文档模板与空模板的 `xl/styles.xml`、`xl/theme/theme1.xml` 二进制内容完全一致。
- `mvn -o -Dtest=SalesDeliveryExcelServiceTest test`：3项通过。验证原样式索引、所有主表单元格样式、列宽、行高及合并区域不变；数字及文本类型、前导零、原金额和费用保留；12条明细分页、尾页无上一页残留、长规格全文保留；所有副本A4竖向及一页设置；缺少快照时拒绝导出。
- POI复制工作表会提示其不复制pageSetup，因此导出显式为每个副本重新设定纸型、方向、缩放、打印区及边距，已验证这些设置。
- `npm run check:docs`：通过。
- `git diff --check`：通过。
- 本任务无前端及状态逻辑改动，不重复前端类型校验或扩大状态基线。

## 上线与限制

需后端加载新代码及模板资源后重启生效；按仓库规则，本任务未操作运行服务生命周期。已验证工作簿结构与数据，尚未在真实Excel/WPS界面或打印机验证最终渲染。主表单只打印所选“送货单”工作表；“发货数据”用于核对和编辑。
原工作簿修改与产品测试删除属于其他在制品，未纳入本任务提交。无数据库迁移或备份需求。
