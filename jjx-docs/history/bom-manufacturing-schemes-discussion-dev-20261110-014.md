## 已确认的业务方向

1）BOM支持多层嵌套，不限两层。半成品可以有自己的制造BOM，其投入半成品还可有下一层制造BOM。
2）不限卷材，不限裁切。裁切、组装、贴合等制造场景都能表达。一个制造BOM允许多行投入；多种投入组装成一种产出不是多产出。
3）BOM记录投入、产出及耗用关系；工艺路线负责加工顺序和操作方法；产品作业规范把资料展示给生产。用户不希望把工艺路线编辑和供给方式列塞进BOM主表。
4）固定功能名称为“制造BOM”，不要又改成“原料与耗用”。入口打开独立窗口。产出物料与投入物料要分别展示编码、名称、规格，不能把原料规格覆盖成小片规格。具体页面布局和数据库字段尚未定稿。
5）成品BOM允许直接用大料，也允许用小片半成品。不能强制所有大料行转换为半成品。
6）相同物料可有多种制造方案，有一个是“针对本产品的主方案”。主方案不是半成品全局统一默认。方案关联产品BOM的具体存储位置、版本绑定机制仍需设计，不能把先前建议当成已批准字段。
7）当前仅要求一种产出，数量可以为6或其他值。用户原话：“目前是‘否，一种产出，数量6’，如果要支持多种产出后续有需求再说。”本阶段不扩展联产品、不同物料套裁产出及其成本分摊。

## 两种填写方式：用户确认的例子

70×180mm是用户随口举的假设规格，不能据此建立实际物料；也没有验证实际排版能出6片。

| 位置 | 大料直接使用 | 小片作为独立层级 |
|---|---|---|
| 成品BOM物料规格 | 450×225mm | 70×180mm（假设） |
| 成品BOM模数/基数 | 6模、1基数 | 1模、1基数 |
| 含义 | 每个成品理论使用1/6张大料 | 每个成品使用1片小片 |
| 小片制造BOM | 不强制增加小片层级 | 方案投入450×225mm大料，6模、1基数，即1张大料出6片小片 |

小片方式：成品用小片1片 → 小片制造BOM用大料1/6张。不能在上层再除以6，造成重复折算。“张/片”是业务解释，不能未经确认直接覆盖系统现有单位。

组装示意：成品 → 组装半成品A → 基材片C、背胶片D、固定件；C可继续关联大料裁切BOM，D可继续关联卷材裁切BOM。此示意不代表已确认真实背胶与离型纸的组装关系。
