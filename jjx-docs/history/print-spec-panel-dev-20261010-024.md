## 已确认的业务口径

- 上方印刷规范表，下方印刷指导图，在线预览与打印顺序一致。
- 面板、上线、下线的印序、印刷名称、色号、油墨编号、网框编号引用工艺路线，只读，不在此新增、修改、删除或排序工序。
- 备注只按整组维护：面板一份、上线一份、下线一份，可留空；不引用或编辑单道工序备注。
- 所有指导图统一在工程图集上传和维护。本tab只引用“印刷指导图”类别当前已发布版本，不提供上传入口。
- 备注修改使用现有sys_oper_log，不为每个模块新建历史表；全局日志架构和保留策略后续讨论。

## 实现

- 新增ProductPrintSpecPanel：纸张预览、整组备注编辑、修改记录前后对比和游标分页。维护与历史查询复用product:edit权限；关闭编辑器、离开路由和关闭浏览器页面处理未保存提醒，保存中禁止离开。
- 新增PrintSpecPaper，与文档集和独立打印页共用。右侧备注单元格按组纵向合并；不再把单道remark/description填到整组备注中。
- 印刷字段直接显示路线填写值，表头改为油墨编号、网框编号。有填写菲林时增显菲林列。保持既有路线顺序，超出容量续页，未分类印刷保留只读展示，避免遗漏。
- 长字段与长备注复用实际DOM溢出检测，仅实际裁切时标记“续见附页”并输出完整内容，续页重复整组备注只生成一次附页内容。预览与打印等待布局测量及附件加载完成。
- 指导图沿用受控图纸当前已发布版选择逻辑：同版优先预览打印件，没有打印件时允许可预览原稿。图片及PDF各页接在印刷表和必要附页后，不在工程图集打印章节重复出现；无图不生成空白指导图页。现行版本判断复用图纸枚举。
- 纸张模式显示指导图展开失败的具体文件，不允许带失败附件直接打印。切换回印刷tab重新读取数据，反映路线或工程图集的最新已保存内容。

## 保存与日志

- PUT /product/{productId}/work-spec/print-remarks只接受revision和三组remarks，组码用ProcessCategoryEnum校验，每组最多1000字。
- 当前值保存在已有product.work_spec_json.printRemarks，不建表、不加列、不需要迁移。专用更新保留其他规范字段；原作业规范保存服务保留printRemarks，防止旧客户端或其他编辑入口覆盖。
- 沿用行锁与revision并发校验；修改后清除原工程确认，需重新确认。没有变化时不写业务数据、不新增日志。
- 备注和sys_oper_log在同一个数据库事务内保存，日志失败则回滚。复用OperLogDetailBuilder的detail.changes，同时保存结构化fields（字段、名称、before、after）。不经异步日志通道，不额外记录重复的保存操作日志。
- 日志按product业务对象及“修改印刷规范整组备注”动作查询，只返回操作人、时间、前后值，不返回请求参数/IP等无关信息。每次最多50条，支持更早记录。
- GET /product/{productId}/work-spec/print-remarks/history用于该tab查看历史。本轮不扩展作业规范“引用已批准版本工程变更”的来源范围；正式打印变更说明仍由工程在既有变更tab整理和选择。
