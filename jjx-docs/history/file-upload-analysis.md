## 一、现状盘点：系统已有 12+ 个上传点

### ✅ 真实可用的附件上传（走 sys_attachment 表）
| 位置 | 用途 | bizType | 链路 |
|---|---|---|---|
| 报价单流程弹窗 | 报价确认/审核附件 | quotation | trace_id |

### ✅ 导入类上传（Excel 解析，不走附件表）
客户/物料/供应商/库存导入（5 个，已修复完成）

### ⚠️ 半成品/假实现
- **产品图纸模块**（views/product/drawing/index.vue）：整页 mock 假数据（代码注释"暂时使用模拟数据"），无后端接口、无数据表、无菜单挂载——最接近"产品文件库"需求但完全是空壳
- **工程部文件**（客供稿/承认书/模具/确认图/菲林/规范）：系统无任何入口

### 基础设施（现成可复用）
- `sys_attachment` 表：biz_type/biz_id/trace_id/file_name/file_path/file_size（已有）
- `SysAttachmentController`：upload / batch-upload / list / by-trace / download / delete（已有）
- 存储：`upload/{bizType}/{yyyy-MM-dd}/{uuid}.{ext}`（file.upload.path 配置）
- `TraceTimeline` 链路组件：按 trace_id 平铺各模块操作日志，**但不显示附件**

## 三、ERP 查看体验方案（让用户在业务页面看文件）

1. **统一附件查看器组件**：列表（文件名/大小/上传人/时间）+ 图片/PDF 内嵌预览 + 拖拽上传，全业务复用
2. **产品档案页「文件库」Tab**：按类别（客供稿/承认书/模具/确认图/菲林/规范/图纸）分组，文件卡片网格 + 版本标注
3. **TraceTimeline 挂附件**：操作节点下显示 📎 附件行，可预览/下载；产品全流程一条链路看全
4. **业务单据页附件区**：报价/订单/询价详情页统一展示（已有雏形补全）
5. **全局「最近文件」入口**（可选）：首页卡片/侧边栏最近上传，点即达
