# ERP 模块职责与菜单分配方案

> 基于薄膜开关制造业务梳理
> 2026-07-24

---

## 1️⃣ 销售管理

**职责：** 客户开发、报价、订单管理、订单跟踪

```
📂 销售管理
├── 📄 客户管理      — 客户信息维护、分级、联系记录
├── 📄 报价管理      — 报价单制作、审核、转订单
├── 📄 销售订单      — 标准单/样品单录入、编辑、删除
├── 📄 订单跟踪      — 订单全生命周期状态追踪
└── 📄 操作日志      — 销售模块操作审计日志 🆕
```

**变动：** 新增操作日志菜单（已做）

---

## 2️⃣ 工程管理（在产品管理下）

**职责：** 产品工程设计 — BOM、工艺路线、图纸、标准工序、技术文档

```
📂 产品管理
├── 📄 产品列表
├── 📄 产品分类
├── 📄 产品实例
└── 📂 工程管理
    ├── 📄 BOM管理       — 物料清单（材料定额）
    ├── 📄 工艺路线      — 生产工序流程定义
    ├── 📄 技术图纸      — 工程图纸上传/版本管理
    ├── 📄 标准工序      — 工序工时、参数标准
    ├── 📄 设计任务      — 新产品设计任务分派 🆕
    ├── 📄 薄膜管理      — 膜片规格管理（薄膜开关专用）🆕
    └── 📄 产品配置模型  — 产品参数化配置模板 🆕
```

**变动：** BOM/工艺/图纸/标准工序从产品管理移入工程管理，工程管理归产品管理下

## 6️⃣ 生产管理

**职责：** 工单管理、生产执行、质量控制、追溯

```
📂 生产管理
├── 📄 生产看板      — 总体生产进度概览（管理视角）
├── 📄 生产订单      — 生产工单创建/下发/关闭
├── 📄 生产执行      — 工序执行记录（每道工序报工）
├── 📄 生产操作      — 操作记录/操作日志
├── 📄 质量检验      — 来料/过程/出货检验 ← 合并原"质量管理"
├── 📄 车间看板      — 车间实时看板（现场视角）
├── 📄 生产追溯      — 批次追溯
├── 📄 设备管理      — 设备台账/维保
├── 📄 生产报表      — 产量/效率/质量报表
└── 📄 成本核算      — 工单成本计算
```

**变动：**
| 操作 | 说明 |
|------|------|
| 🔴 删质量检验(59) | 与质量管理重复，保留质量管理改名质量检验 |
| 🔴 删报价审核(89) | 完全重复 |
| 🟡 生产追溯排序 | order 0→7，放到设备管理前 |
| 💡 是否合并看板？ | 生产看板(概览)和车间看板(现场)功能不同，建议都保留 |
