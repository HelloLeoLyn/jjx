# 工单生产数量对账口径

## 口径

- 工序层：按标准工艺路线逐道显示计划投入（`input_quantity`，不是实测投料）和已审批报工产出（合格+不良）。返工执行不混入正常生产路线。
- 工单报工量：各标准工序已审批产出的最大值，不把串行工序重复相加；末道工序产出单独列出。
- 补产报工：按补料单来源分组，在同一补料单的多个工序间取最大已审批产出，再合计不同补料单，避免一批补产经过多道工序被重复累计。
- FQC良品：按有效FQC批次谱系汇总合格量，是原有工单完工判据；报废按有效 NCR 下已完成 SCRAP 数量汇总。
- 返工在制：NCR返工处置处于待执行/执行中的数量。待检以有效FQC尚未判定的批次数展示，不与件数混用。
- 普通工序实物在制：现有数据没有逐工序实际投入/转序/剩余量的可靠记录，故不展示估算值；原“报工减FQC检验量”字段已移除，不再称作在制。
- 补料（物料出库）仍单独展示，不能与补产成品数量混为一项。计划与FQC良品差数是完工缺口提示，不是库存或实物平衡式。

## 实施

对账接口增加正常工序分层数量、末道产出和按补料单去重的补产报工；弹窗明确显示“计划投入/已审批产出”、末道产出、有效FQC良品、已报废、补产报工、返工在制和待检批次数，并移除误导性的实物在制差额。
