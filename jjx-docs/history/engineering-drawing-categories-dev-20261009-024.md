# 工程图纸名称与上传图种分类统一（dev-20261009-024）

日期：2026-10-09

用户在讨论图纸管理和“产品图集”含义后明确“按业内标准来”。本次按行业常见用词结合现有业务调整入口、集合名称和上传图种，不制定全仓权限规范，不扩展工程变更/图纸审批模型。

## 依据

金蝶官方文档管理以产品图纸、技术资料等为管理对象，并支持与物料/BOM关联；SAP产品设计文档使用“工程图纸”。本次名称为业务分类选择，不宣称存在规定这些中文图种名称的统一强制标准。

- 金蝶官方：https://help.open.kingdee.com/dokuwiki/doku.php?id=文档管理
- SAP官方：https://help.sap.com/docs/SAP_BUSINESS_BYDESIGN/2754875d2d2a403f95e58a41a9c7d6de/2cc8ef54722d10149d77f5d3231c06a1.html?locale=zh-CN&version=2602

## 改动

- 工程管理入口和页面标题由“图纸管理”统一为“工程图纸”，菜单前端辅助名称同步；路由、权限串和数据来源保持现有值。
- 作业规范页签、文档目录和纸张预览/打印使用“工程图集”，表达图纸的集合，不作为单个文件的上传类别。
- 工程图种：结构图、外形尺寸图、面板图、线路图、组装图、包装图、印刷指导图、确认图、菲林、模具、其他工程图。分类定义集中共享，工程图纸及作业规范使用相同列表。
- 图纸页面原有客供稿仍保留。其他文件类别（承认书、规范、样品照片、客户确认样品、分色检查表）继续沿用，未改归档业务。
- 原附件类别值“产品图集”不做数据订正、不改附件文件路径；文件库分组与文档纸张标题兼容显示为“其他工程图（历史资料）”，继续可见、可预览、可打印。新上传选项排除此旧类别。
- 公共文件库默认类别根据当前可选项确定，并遵循调用页类别顺序；工程图纸/工程图集首选结构图，印刷指导图等单类别页面选择自身类别。字典异步变化时不保留已失效类别，提交前再次核对类别可选性，避免把工程图误传成客供稿。
- 新增253_engineering_drawing_categories.sql：单个已有菜单改名，幂等新增6个具体图种字典项。已应用台账与目录最大均252，故编号253。无表结构变更、无角色授权变化、不修改既有附件数据、不禁用旧字典项。
