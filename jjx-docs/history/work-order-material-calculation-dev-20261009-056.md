# 工单用料计算与历史方案复用需求方案

## 业务背景与用户要求

BOM中的材料工程规格与库存材料的采购规格可能不同，生产时需要根据实际库存选择其他规格并计算用量。规格变化频繁，无法依赖工程预先定义固定的替代料名单。

用户提出由用料计算员在中间界面选择材料、计算本次用料；操作结果保存为历史，下次可复用。领料界面同时展示一个原始规格和一个当前选择规格。

## 方案方向

1. 按工单进行用料计算，保留该工单绑定的BOM版本及原始工程需求；本次选择不回写BOM或库存材料档案。
2. 原始规格来自BOM，当前选择规格来自实际库存材料档案。选择库存材料时不覆盖原始规格，库存档案规格只读。
3. 不以预定义替代料名单为操作前提。计算员按实际情况选择库存材料，并记录本次模数、损耗、换算依据与选择原因。
4. 确认本次方案后再生成领料单；仓库依据方案发料，领料界面和打印同时展示原始规格与实际材料规格。
5. 同一项BOM需求可分配给多种实际材料，分别计算、合计满足需求。材料和单位不同不能直接把领料数量相加作为已满足需求。
6. 历史方案可复用材料组合、计算参数及依据；复用后必须按本次工单数量、剩余需求和当前可用库存重新计算。

## 操作流程与界面

工单 → 用料计算 → 确认本次方案 → 生成领料单 → 仓库发料。

入口建议在生产管理中从工单进入，复用现有领料预览链路。计算员需要集中处理时，再细化待计算工单列表及入口；不在多个页面建立独立的计算逻辑。

| 原始需求，只读 | 本次用料，计算员操作 |
|---|---|
| BOM版本、明细及项目 | 实际库存材料、当前规格 |
| 原始材料名称、工程规格 | 本次选择原因、关键条件差异 |
| 原始基数、模数与损耗 | 本次模数、损耗、换算依据 |
| 工单数量、剩余需求 | 本次需领数量、可用库存、缺口 |

同项需求使用多种材料时，以该BOM明细为父项，分别展示各实际材料的规格、参数、数量及其满足的需求。材质、厚度等关键条件变化需突出显示，由计算员明确确认并留依据；额外审批流程尚未确定，不提前引入。

## 历史方案与版本

- 保存工单、产品、BOM版本及原明细关联，原始工程规格和实际选择材料的快照，计量单位、计算参数、依据、计算人及时间。
- 历史方案按产品、原始规格及实际用料条件供用户检索、选择，不能因曾经使用就自动套用到所有产品。
- 复用历史方案只带入可参考的材料组合及计算参数，不照搬旧工单数量、已领量、库存余额或最终领料量；BOM版本或规格变化应提示重新核对。
- 确认后的方案调整需保留版本，已发料记录对应实际执行版本；不覆盖原发料数量与批次。
- 保留计算方案与实际发料结果的关联，能够查询最终用了哪些材料、批次和数量。

## 领料、库存与需求抵扣

- 库存按实际发出的材料、基本计量单位和批次扣减，沿用既有库存流水唯一入口及不可改规则。
- 实际发料明细必须关联原BOM需求和本次计算方案，保存当次换算依据；其他规格材料发出后，也能正确抵扣对应的原需求。
- 分批、追加、混用和退料均按同一原需求累计；区分待发料占用和已确认发料，取消、红冲或退料后按实际状态恢复对应需求与占用，不重复抵扣。
- 领料单展示原始规格和当前选择规格，历史打印采用当次快照，避免材料档案后续修改改变历史单据。
- 数量换算依实际产出能力、计量单位及损耗确定，不采用材料价格比例换算。

## 当前系统基础与缺口

- BomItemEditor选料时会将库存材料specification赋给BOM行，需拆清工程规格与库存规格含义。
- 后端已有substituteJson与替代料领料逻辑，可作为重构参考，但不应把固定名单作为新方案前提。
- jjx-web/src/views/production/order/components/PickPreviewDialog.vue已有领料预览入口，可衔接计算方案。
- 当前已领数量按实际materialId汇总，尚未形成替代材料对原BOM明细需求的可靠抵扣关系；不能只做前端选择框即认为完整落地。
- 本文未确定数据库结构、迁移脚本或新增表；实施设计时先评估复用，必要的字段变化另行评审。

## 实施前逐项细化

1. 计算口径：板材、卷材及不同计量单位的模数/换算、损耗、取整与最低投料量，明确自动计算与人工确认边界。
2. 确认方式：计算员权限、确认后调整、关键规格变化的确认规则；不默认增加额外审批。
3. 方案范围：同一工单多次领料如何沿用或调整方案，以及跨产品/不同BOM版本的历史方案可参考范围。
4. 数据关联：方案、原BOM明细、实际领料明细、批次及红冲/退料的追溯与幂等抵扣。

## 后续验收重点

原始规格不被选料覆盖；不同规格和混用材料分别计算；历史复用按本次数据重算；实际库存按发出材料扣减；替代材料正确抵扣原需求；追加领料不重复领；退料/红冲正确恢复；历史方案和打印能追溯当次规格、参数与批次。
