## 变更内容

- 变更与发行中支持手工新增、历史补录、日期、变更说明、颜色、选填原因及逐条打印勾选。
- 新记录默认不打印；已有无print字段的历史记录维持原打印行为，避免升级后原有内容全部消失。
- 未勾选记录仍完整保存在变更tab；纸张预览与独立打印页只使用勾选且有文字的记录，日期升序排列。原因和来源元数据不印到主表。
- 引用工程变更入口按产品查询已批准BOM/工艺路线版本的成功修改流水。使用现有审批枚举、日志成功枚举和动作常量，拒绝草稿、失败日志和其他产品的记录。
- 多条来源可以合并为一条工程说明，再由工程整理打印文字。每条最多引用100条来源；打印说明仍限1000字，原始来源文字独立保留。
- GET /product/{id}/work-spec/change-sources提供游标分页，每页50条。仅返回日志ID、日期、版本标识和字段差异，不返回请求参数、IP等日志信息。
- 保存时服务端重新核验新引用的所属产品和版本审批状态，再保存来源摘要；已保存来源从服务端历史内容继承，不信任客户端自填的来源元数据。
- 仍使用product.work_spec_json，Change扩展print、reason、sourceLogIds及服务端生成的sources。无需DDL、迁移或业务数据批量订正。

## 工程内容附页

- 删除主表材料字数、变更固定6行、加工要求固定7行等估算触发条件。
- 主表先按实际内容布局，等待字体加载后测量有裁切的单元格和文本区域scroll/client尺寸，仅实际溢出时收集对应完整内容。
- 覆盖材料名称、规格及模数、无图标项目名称、工序图标下标/备注、加工要求及已选打印变更。
- 主表溢出位置标记“续见附页”；无溢出不生成附页。续张重复的加工要求/变更仅保留一份附页内容，材料及工序按各页分别判断。
- 纸张在线与打印使用一致的物理宽高；页面内容变化、尺寸变化和字体加载后重新测量；打印按钮等待测量完成，独立打印前再次刷新布局与页数。
- 附页正文保留全文及变更文字颜色，按原附页版式续页。
