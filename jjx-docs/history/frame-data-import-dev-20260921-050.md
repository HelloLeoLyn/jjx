## 口径与映射（与后端「网版导入」功能一致）
- 编号 = 单元格里匹配 `^[A-Za-z]\d{3,4}$` 的值（`G0001`）→ `frame_no`（大写）
- sheet 名首字母 → `frame_type`（G/H/B/C/A/F，用户确认存单字母）
- 有内容 → 网框 `PLATED` + 当前版面 `ACTIVE`（`plate_no`=网框编号，`content`=原文，最长 129 字）
- 无内容 → 网框 `EMPTY`
- 内容摘要（前 200 字）→ `frame.remark`（用户确认要写，便于搜索）
- `mesh`（目数）／`location`（位置）／`plated_time`：源文件没有 → 留空（不臆造时间）
