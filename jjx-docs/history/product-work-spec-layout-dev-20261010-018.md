# 产品作业规范材料口径与纸张网格排版修复

- 任务：dev-20261010-018
- 日期：2026-10-10
- 来源：用户逐项指出版式偏差，确认材料按最新BOM展示后要求实现修复。
- 范围：产品作业规范前端主表、共用显示函数、工程录入入口文案。

## 本轮确认与实现

1. 刀模位置按材料区的14行网格显示。工程仍独立维护多行文本，不绑定BOM行或材料ID；空行保留，长内容折行，超过14行继续下一张规范纸。
2. 材料名称和顺序引用当前BOM。宽、长均为有效正数时组合尺寸；宽长为0或未填时使用BOM已有规格文字，避免出现0*0mm覆盖真实规格。规格后接真实模数，不根据参考图猜业务数值。
3. 无规格、无有效尺寸、单位为PCS/个且模数为1时，复用BOM基数除以模数的计算函数，显示1个/PCS或2个/PCS；不使用含损耗应用料、实发数量，不在字段缺失时默认补1。主表与材料完整内容附页共用格式化函数。
4. 原工程要求按钮和编辑页签改名为“凹凸条件与加工要求”。六项凹凸条件仍选填，沿用原数值和单位输入、保存接口及权限。
5. 上部材料和凹凸条件合为一张整宽表；三组流程和结构图合为一张整宽表。两表共用整张纸的三分之一列边界，材料右边线与面板耗时右边线对齐；相邻单元格只画一条边线。
6. 结构图位于中间表头下方并跨7行，上线流程表头占第8行，其下6行与左右面板/下线的行格共用横线，避免独立表格高度造成分叉。
7. 三组流程行保留图标和组合加号，不再回退显示工序名称；数字下标和显式作业说明缩小到对应图标右下角，备注放在该流程单元格右侧，耗时独立列。工时计算仍引用整份路线。
