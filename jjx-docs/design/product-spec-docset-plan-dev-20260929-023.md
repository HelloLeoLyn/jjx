## 0. 主页面 / 菜单 / 权限

- 菜单：**工程管理(menu 90) → 新增「产品作业规范」**；`path=spec`、`component=views/engineering/product-spec/index.vue`、`type=C`。

### 1.1 附件载体的关键决定（二选一，**待拍板**）
- **(a) 复用"产品文件库"**：`sys_attachment` `bizType='product'`、`bizId=productId`、`category` 区分（现有类别：客供稿/承认书/模具/确认图/菲林/规范；**新增**：结构图/印刷指导图/产品图集/样品照片/客户确认样品/分色检查表）。→ **最省，复用现有页面与接口**（`/system/attachment/upload-product`、`/product/{productCode}`）。
- **(b) 新开 `bizType='product_spec'`**：更干净、与产品文件库隔离，但要新页面/新接口。
- **建议 (a)**。

### 1.2 引用类数据的"当前版本"口径
- BOM → `product.current_bom_id`；工艺路线 → `product.current_route_id`；刀模 → 资源↔产品关联（`is_active=1`）。**只读引用，规范里不复制。**

## 3. 导出 / 打印（文档集）

- **一个动作**：`[生成文档集]` → 弹**预览清单**（7 项 + 每项下的文件/数据，带勾选框）→ 用户勾要哪些 → 生成**打印视图**（`spec-docset-print.vue`）→ **打印 / 导出 PDF**。
- 后端接口（新增，薄）：`GET /engineering/spec/{productId}/docset-preview` 返回可选清单（引用数据摘要 + 附件列表）。
- 打印底座：复用现有**打印中心 / 质量记录模板打印组件**的做法（不新造打印框架）。

## 4. 打样领料单改造（复用生产领料）

- 现状：领料单**只认生产工单**（`setSourceType("work_order")` + `OutboundTypeEnum.PRODUCTION`，单号 `PICK-{工单号}-{序号}`）。
- 改造：**放开源单** → `sourceType='sample'`、`sourceId=sampleOrderId`；打样单号 `PICK-{样品单号}-{序号}`（或 `SPICK-…`）。
- BOM 依据：`sales_sample_bom`（按**当前打样轮次**）；**允许手工增/改行**（打样试错），留原因。
- 库存：**照旧走"确认发料"扣库存 + 写流水**（不新增旁路）。
- 打印：**QR-031 模板，抬头按 sourceType 显示「打样领料单」**。
