# 业务流程

薄膜开关定制制造：先接单 → 根据订单定义产品 → 生产执行 → 完工入库

## 核心流程
```
客户需求 → 销售接单 → 产品定义(BOM/工艺) → 采购备料 → 生产执行 → 质检入库
```

## 六大模块
1. 销售管理：客户 → 报价 → 订单 → 跟踪
2. 产品管理：BOM → 工艺路线 → 图纸 → 实例
3. 采购管理：供应商 → 采购单 → 收货 → 付款
4. 生产管理：工单 → 工序执行 → 质检 → 入库
5. 库存管理：物料 → 仓库 → 出入库 → 盘点
6. 系统管理：用户 → 角色 → 菜单 → 字典
