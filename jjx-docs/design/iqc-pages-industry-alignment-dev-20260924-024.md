## 2. 现状清点（证据）

### 2.1 来料不合格处置 `/inventory/iqc-quarantine`（`views/inventory/iqc-quarantine/index.vue`）

| 区块 | 内容 | 定位 |
|---|---|---|
| ① `el-alert` | "本页只处理来料检验产生的隔离品…" + 跳产品不良台账 | 说明性文字占整条 |
| ② `el-card` | 筛选表单（入库单号/物料/批次/供应商/隔离状态） | **一整张卡片只放筛选** |
| ③ `el-card` | **批次谱系**（批次/父批次/类型/数量/状态） | **常驻**，未选中任何行时也占位 |
| ④ `el-card` | 隔离台账（待处置明细） | 主业务表 |
| ⑤ `el-card` | 处置单历史（本页每次处置） | 与 ④ **并列**，业务主线被切成两块 |
| 弹窗 | `IqcQuarantineDialog`（处置） | — |

**问题**：三份不同业务数据集（待处置 / 已处置 / 谱系）**并列摊在一屏**，用户先要判断"看哪块"——这是"复杂"的真实来源（不是难，是要多想一步）。

### 2.2 来料检验 `/inventory/iqc`（`views/inventory/iqc/index.vue`）

```
上：来料检验单据（列表 + 分页）
下：材料检验处理（卡片：描述4项 + 告警 + 汇总条 + 两排批量按钮 + 材料表 + 提交按钮）
```

- **两套分页同屏**，选单才出明细 → 上下滚动、位置感丢失
- 卡片头部同时挂：说明 alert、汇总条、批量操作（5 个平级按钮）、阶段信息

### 2.3 术语混用（界面出现的词）

「来料检验」「隔离台账」「批次谱系」「IQC处置建议」「处置单」「隔离状态」「剩余数量」——业内对应的只有三个业务词：**检验单 / 不合格品处理单（NCR）/ 处置单**。「隔离台账」「批次谱系」是**内部实现概念**，不应作为界面语言。

## 3. 业内形态（金蝶 / 用友 / SAP）

```
列表页   = 一条筛选工具条（非卡片） + 一张主表          → 点行进入单据
单据详情 = 单头信息条 + 明细表 + 动作按钮
                        关联内容 = Tab（明细 / 关联单据 / 历史 / 溯源）
```

- 本业务对应**两张单据**：**来料检验单**（单头 + 检验项目明细）、**不合格品处理单**（单头 + 待处理明细 + 处置动作）；处置历史是该单据的**子表/子页签**
- **批次谱系**属溯源信息，业内（如 SAP batch genealogy / where-used）放在**单据详情的 Tab 或弹窗**，**不常驻列表页**
- 筛选条件放**表格上方一行**，不单独占卡片

## 4. 目标形态

### 4.1 来料不合格处置页：4 卡片 → 1 表 + 1 工具条

```
改造前                              改造后
┌ alert 说明 ─────────────┐   ┌ [?] 一行提示（hover 展开） ──────────────┐
├ card 筛选表单 ──────────┤   ├ 筛选：单号｜物料｜批次｜供应商｜状态 [查询][重置] ┤
├ card 批次谱系 ──────────┤   ├───────────────────────────────────────┤
├ card 隔离台账 ──────────┤   │ [ 待处置 ] [ 已处置 ]   ← Tab            │
├ card 处置单历史 ────────┘   │ ┌───────────────────────────────────┐ │
                              │ │ 一张主表（… 操作：处置 / 谱系）      │ │
                              │ └───────────────────────────────────┘ │
                              └───────────────────────────────────────┘
```

| # | 改动 | 效果 |
|---|---|---|
| 1 | 筛选表单并入表格上方**一行工具条** | 少一张卡片，少一次视觉跳转 |
| 2 | **批次谱系**改为行内「谱系」按钮 → **抽屉（Drawer）** | 只在需要时看；主表回归业务主线 |
| 3 | 隔离台账 + 处置单历史合并为**一张表 + Tab（待处置 / 已处置）** | 业务主线收成一条 |
| 4 | alert 说明 → **一行小字 + 问号图标**（hover 展开全文） | 不再抢占首屏 |
| 5 | 术语替换（见 4.3） | 界面语言 = 业务语言 |

### 4.2 来料检验页：两级面板 → 列表 + 单据详情

```
改造前：上列表 / 下材料卡片（两套分页同屏）
改造后：
   列表页：筛选工具条 + 一张表（单据号/供应商/到货/材料数/进度/状态/操作）
           → 点「处理」进入单据
   单据详情（抽屉或子页）：
       单头信息条（单号/供应商/到货日期/来料批量/状态）
       + 阶段条（录入 → 提交 → 复核 → 入库）   ← 复用 InspectionStageBar
       + 材料表（只读）+ 行内「录入」按钮（打开统一「检测项目」弹窗）
       + 底部：提交检验（含缺失清单提示）
```
