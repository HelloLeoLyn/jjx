## 2. 交付方式（落地要求）

1. 初始化 SQL（DDL + 19 表子集快照）**不含任何明文口令/密钥**；敏感项一律在部署时注入。
2. 注入渠道二选一（生产优先第一种）：
   - 环境变量（`JJX_UPLOAD_ROOT`、`DB_PASSWORD`、`REDIS_PASSWORD`、`JWT_SECRET` … 与 `application-prod.yml` 一致）；
   - 受限权限的 secrets 文件（`chmod 600`，不进 git）。
3. `hr.idcard.key` 的注入值必须与原环境**一致**，否则 52 条身份证解不开；若生产确实要换密钥，必须先在新旧环境都能解密的前提下"解密→再加密"（**另立任务**，不在本次范围）。
4. 交付包里不放 `jjx-docs/accounts/`；如需给运维保留一份，放仓库外并限权。
