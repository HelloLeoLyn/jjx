## 4. 执行规则（序列怎么用）

1. **按序列位推进**：接手先看看板上最小未完成的「序列 #N」，同波内可并行
2. **前置未完成不开工**：前置没落地就动下游，等于返工（本序列的依赖是真依赖，不是建议）
3. **每卡做完**：`remark` 记改动 + 提交号 + 验证 + 遗留；状态置 2（待审核）；序列位不变、不重排
4. **流程变化**：只有"新卡插入/前置换人"这类结构性变化才动本序列，并在本文档 §5 记一行
5. **新发现的缺陷**：走 T1 轨道（登记为独立卡），不改主链顺序
