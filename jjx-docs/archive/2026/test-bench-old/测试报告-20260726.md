**编码规则验证：**
```
格式：客户简称(3位) + 流水号(3位) + 面板类型(1位)+面板特征(1位) + 线路类型(1位)+线路特征(1位)
面板类型: M=有面板有线路 / S=仅有线路 / P=仅有面板
面板特征: E=凹凸 / W=窗口 / H=窗口凹凸 / O=无
线路类型: O=印银平key / M=金属弹片 / P=线路凹凸
线路特征: O=无 / L=发光二极体 / C=连接器 / H=连接器+发光二极体
```

**根因：** 后端创建产品 API 统一返回"系统繁忙"，非前端/测试问题。
