## [正向主流程] TC-501: 样品单全流程 → 就绪检查全绿 → 转量产

### 测试步骤
1. 新建样品单（销售）：明细选 **FK-1001**（已发布产品），数量 10 → 提交审核 → 通过 → 接单 → 打样 → 完成 → 送样 → 客户确认（状态=6）

3. 核对清单：产品建档 ✅ / BOM ✅ / 工艺路线 ✅ / 菲林 ✅ / 资料转移（信息项）
4. 顶部提示"资料齐全，可以转量产"，底部「确认转量产」**可点**
5. 确认 → 转量产成功

### 验证点
#### ✅ 数据验证

- [ ] 样品单→已转量产(7)，convertedOrderId 回写
- [ ] 流水：转量产记录（biz_status=7，traceId 同链）

#### ✅ 截图
- [ ] 就绪检查弹窗（全绿）1 张；标准订单明细 1 张
