# JJX ERP 销售模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：销售员 / 销售内勤 / 销售主管 / 财务对账
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「销售管理」

---

## 一、模块总览

### 1.1 这个模块是干嘛的

销售模块管的是**"从客户询价到收钱、开票、对账"**这一整条主线的业务单据与跟踪，包括：

- 客户档案（谁在下单、怎么结算）
- 询价单（客户问价）
- 报价单（我们报多少）
- 样品单（要先打样确认的单）
- 销售订单（正式接单）
- 订单跟踪（生产到哪了、发没发货）
- 发货管理（出库、签收、拒收）
- 收款单 / 销售发票（钱和票）
- 退货管理（退回、入库、退款）
- 业务对账（和客户核对应收）
- 销售报表

### 1.2 谁用

| 角色 | 主要用到的部分 |
|---|---|
| 销售员 | 客户 / 询价 / 报价 / 样品单 / 销售订单 / 订单跟踪 |
| 销售内勤 | 报价发送、订单录入、发货跟进、收款开票登记 |
| 销售主管 | 报价审核、订单审核、退货审核、销售报表 |
| 财务 | 收款单、销售发票、业务对账 |

> 具体能看到哪些菜单，取决于管理员在「系统管理 → 角色管理 → 分配权限」里给角色勾了哪些。看不到某个菜单 = 没授权，找管理员开。

### 1.3 业务全流程一张图

```
客户询价 → 询价单 →（转）→ 报价单 →（审核/发送/客户确认）
      ↓（需要打样时）
      样品单 → 工程打样 → 送样 → 客户确认 → 转量产
      ↓
      销售订单 → 提交审核 → 审核通过 → 客户确认 → 提交生产
      ↓
      生产 → 发货管理（OQC→出库→签收） → 收款单 → 销售发票
      ↓
      业务对账（核对应收）  /  退货管理（有退货时）
```

要点：**起点是询价单，终点是收款/对账**。报价单既是询价的出口，也是订单/样品单的入口（"转订单""转样品单"）。

### 1.4 进入路径与常见按钮含义

- 路径：左侧菜单 **销售管理**（`/sales`）→ 选子菜单
- 通用按钮：
  - **搜索 / 重置**：按条件过滤列表
  - **新增**：新建单据
  - **修改 / 删除**：勾选一行后操作（部分按钮勾选多行）
  - **导出 / 导出Excel**：导出当前列表
  - **详情**：点单号蓝色链接打开查看

## 二、客户管理

**用途**：维护客户档案。所有单据（询价/报价/订单/发货）都要选客户。

**路径**：销售管理 → 客户管理

**列表列**：客户编码、客户名称、客户类型、客户状态、联系人、电话等。

**操作步骤**

1. **新增客户**：点「新增」→ 填写客户名称、客户类型、结算方式、联系人、电话、地址 → 保存。
2. **修改客户**：勾选一行 → 点「修改」。
3. **删除客户**：勾选一行 → 点「删除」（有单据关联的客户一般不允许删）。
4. **导入客户**：点「导入」→ 下载模板 → 填好上传（首次批量建档用）。
5. **导出客户**：点「导出」。
6. **查看客户信息**：点客户名/「客户信息」查看详情。

**关键字段说明**

| 字段 | 取值 | 说明 |
|---|---|---|
| 客户状态 | 潜在客户 / 正式客户 / 暂停合作 / 终止合作 | 正式客户才能正常下单 |
| 客户类型 | 终端客户 / 代理商 / 经销商 | 用于分类统计 |
| 客户等级 | A / B / C | 用于管理优先级 |
| 结算方式 | 预付 / 货到付款 / 月结30天 / 月结60天 | 影响对账到期计算 |

**注意**：客户简称/编码是后续做单、对账时识别客户的关键，尽量规范填写。

## 三、询价管理

**用途**：记录客户的询价需求，是整条业务线的起点。

**路径**：销售管理 → 询价管理

**操作步骤**

1. **新增询价**：点「新增」→ 选择客户 → 系统带出联系人/电话 → 填询价日期、预估数量、产品（可选已有产品，也可手填产品名称/规格）、技术要求/备注 → 确定。
2. **编辑 / 删除**：勾选行后操作。
3. **转报价**：勾选行 → 点「转报价」→ 系统自动带出产品/数量/技术要求到报价单（单价空白，待定价）。
4. **导出**：点「导出」。

**状态说明**

| 状态 | 含义 |
|---|---|
| 草稿 | 刚建、未提交 |
| 待处理 | 已建待跟进 |
| 已发送 | 已给客户回应 |
| 已转报价 | 已生成报价单 |
| 已确认 / 已拒绝 | 客户反馈结果 |
| 已过期 | 长期未处理系统自动置过期 |

**注意**：询价单打印件标题为「**询价单**」，用于给客户/工程确认需求。（原「样品需求单」命名已屏蔽，业务核查后再实现）

## 四、报价管理

**用途**：给客户的报价单，支持审核 → 发送 → 客户确认 → 转订单/转样品单的完整闭环。

**路径**：销售管理 → 报价管理

**列表列**：报价单号、来源询价单、客户名称、报价日期、有效期至、报价状态、订单类型（是否已转单）、币种、总金额、销售员。

**操作步骤**

1. **新增报价**：点「新增」→ 选客户/产品/价格/数量 → 保存为**草稿**。
2. **提交审核**：草稿 → 点「提交审核」→ 进入**待审核**状态（走操作预览器，弹窗确认跳转+表单+证据+事件预告）。
3. **审核**（主管）：待审核 → 点「审核」→ 通过=**已审核**；驳回=**已拒绝**。
4. **发送报价**：仅**已审核**可发送 → 点「发送」→ 弹窗展示完整报价表单 → 可打印/导出 PDF/Excel → 确认发送 → 状态变**已发送**。
5. **客户确认**：已发送 → 点「客户确认」→ 状态变**已确认**。
6. **转订单**：已确认 → 点「转订单」→ 生成销售订单（继承金额/税率/税额/折扣，双向关联）。
7. **转样品单**：已确认 → 点「转样品单」。
8. **其他**：复制、改单（已完成→改单重新流转）、重新报价（拒绝/过期→复制新草稿）、附件、导出 PDF/Excel。

**状态说明**

| 状态 | 含义 |
|---|---|
| 草稿 | 未提交 |
| 待审核 | 已提交待主管审核 |
| 已审核 | 审核通过，可发送 |
| 已发送 | 已发给客户 |
| 已确认 | 客户确认，可转单 |
| 已拒绝 / 已过期 | 客户拒绝 / 超有效期 |
| 改单 | 已完成后再修改 |
| 已完成 | 流程结束 |

**注意**
- 报价单有**有效期（valid_until）**，过期系统每天定时置为「已过期」。
- 列表支持按**来源询价单号**搜索，便于追溯。

## 五、样品单管理

**用途**：客户需要先打样的单子，从建单 → 工程接单 → 打样 → 送样 → 客户确认 → 转量产。

**路径**：销售管理 → 样品单管理

**列表列**：样品单号、客户简称、样品状态、工程接单、当前工序、迭代轮次、打样数量、快递单号、送样日期、确认人、工程备注。

**操作步骤**

1. **新增样品单**：点「新增样品单」→ 选客户 → 选打样产品（可从单产品报价单带出客户和产品）→ 填打样数量、交期、工程打样要求（材质/工艺/颜色/按键数/连接器等，会传给打样工作台）→ 保存。
2. **工程接单**：工程侧在样品单页点「工程接单」→ 接单后到「工程管理 → 打样平台」操作（工序/材料/工艺/完成）。
3. **送样管理**：样品做好后登记送样（快递单号、送样日期）。
4. **样品确认**：客户确认后登记确认人/结果。
5. **转量产**：样品确认 → 走「资料转移」（产品/BOM/路线建档）→ 校验产品已发布 → 转量产。

**状态说明**

| 状态 | 含义 |
|---|---|
| 草稿 | 刚建 |
| 待打样 | 已提交待工程接单 |
| 工程打样中 | 工程已在打样 |
| 样品待送样 | 打完待寄 |
| 已送样待确认 | 已寄出待客户确认 |
| 样品确认 | 客户认可 |
| 已转量产 | 进入量产 |
| 客户退回 | 客户退回，需重新打样 |
| 已关闭 / 已取消 | 结束 |

**注意**
- 材料**必须从物料档案选择**（没有的先建档）。
- 样品完成**只能在打样平台操作**（单入口）。

## 六、销售订单

**用途**：正式接单。这是销售模块最核心的单据。

**路径**：销售管理 → 销售订单（新增页 `/sales/order/add`，编辑页 `/sales/order/edit/:id`）

**列表操作**：新增、修改、删除、导出、导出Excel、复制（勾选一行复制成新单）。

**操作步骤**

1. **新增订单**：点「新增」→
   - 选**客户**、填**运输方式**（字典 `sales_delivery_method`，含"送货上门"）
   - 选产品、数量、单价、交期、币种
   - 填收货信息
   - 保存为**草稿**
   > 校验：所选产品的产品状态必须是 **RELEASED（已发布）**，否则不能下单。
2. **提交审核**：草稿 → 点「提交审核」→ 校验客户/日期/金额 → **待审核**。
3. **审核**（主管）：**待审核 → 审核中 → 通过=已审核 / 驳回=退回修改（回草稿）**。审核通过会写操作日志、发消息通知、派任务。
4. **客户确认**：审核后录入客户确认（确认人/方式/时间/备注）→ **已确认**。确认时会自动做 **BOM 齐套检查**（缺料预警）。
5. **提交生产**：点「提交生产」→ 校验 **BOM 已审批 + 工艺路线已审批** → 创建生产工单 → 订单变**生产中**。
6. **发货 / 完成**：仓库发货后订单转**已发货**，客户收货后**已完成**。
7. **取消**：非终态可取消；已确认的订单取消会**联动取消关联生产工单**（跳过已完成工序，并记录取消/跳过数量）。

**订单状态一览**

| 状态 | 含义 |
|---|---|
| 草稿 | 未提交 |
| 待审核 / 审核中 | 审核流程中 |
| 已审核 | 审核通过 |
| 已驳回 | 退回修改 |
| 已确认 | 客户确认 |
| 生产中 | 已下生产 |
| 已发货 | 已出库 |
| 已完成 | 客户已收货、结束 |
| 已取消 | 取消 |

**订单类型**：标准订单 / 样品订单。

**订单金额口径**（重要）
- 订单金额 = 明细金额合计 + 税率/税额 − 折扣等，具体以「单据金额口径规范」为准。
- 折扣**金额**和折扣**率**是两个字段，别填错（曾出现「填金额被当成折扣率」的 bug，已修）。

**打印**：订单评审表打印、销售订单确认书打印。

## 七、订单跟踪

**用途**：一张表看订单"生产到哪、发没发货"，不用分别去生产和仓库问。

**路径**：销售管理 → 订单跟踪

**列表列**：订单号、客户名称、订单日期、交货日期、订单状态、总金额、生产状态、发货状态。

**操作**：搜索（订单号/客户/状态/创建时间）→ 点订单号打开「订单跟踪详情」，含 4 个页签：

1. **基本信息**：订单号/客户/日期/状态/金额/销售负责人/交货地址/备注
2. **生产进度**：关联生产单（计划数量、完成数量、生产状态、计划起止）
3. **发货跟踪**：发货单号、发货日期、状态、数量、物流单号（可导出送货单 PDF）
4. **订单明细**

**生产状态**：无生产 / 部分生产中 / 全部生产中 / 生产完成。

## 八、发货管理

**用途**：安排出库、登记签收、处理拒收。

**路径**：销售管理 → 发货管理

**列表列**：单号、OQC/出库、客户、交货方式、发货日期、发货状态、本次数量、签收人、签收时间。

**流程**：待发货单 → **先完成 OQC（出货检验）→ 仓库确认出库 → 记为已发货 → 客户收货后登记签收**。

**操作步骤**

1. **查看发货单详情**：点单号打开右侧抽屉。
2. **上传回签件**：客户签回后上传回签单（一步内联上传）。
3. **登记签收**：点「签收」→ 填纸质送货单上的签字日期 + 上传回签件 → 确认 → 状态变**已签收**。
4. **登记客户拒收**：拒收登记后系统自动：①生成「拒收回库单」回冲成品库存 ②订单回到"生产中"以便重新发货 ③通知销售跟进。
5. **打印送货单**：按 QR-026 原模板打印（含可编辑 Excel 导出）。

**发货状态**

| 状态 | 含义 |
|---|---|
| 待发货 | 未出库 |
| 已发货 | 仓库已出库 |
| 已签收 | 客户已收货 |
| 已拒收 | 客户拒收 |
| 已作废 | 作废 |

**注意**：支持**多张销售订单合并发货**（合并送货车/一张送货单）。

## 九、收款单管理

**用途**：登记收到的货款。

**路径**：销售管理 → 收款单管理

**操作步骤**

1. **新增收款**：点「新增收款」→ 输入订单号或客户名搜索 → 选订单 → 填收款金额、收款类型、收款方式、日期 → 提交。
2. **查看详情**：点单号查看。
3. **打印**：收款单打印。

**字段**
- 收款类型：定金 / 进度款 / 尾款
- 收款方式：银行转账 / 现金 / 承兑汇票

## 十、销售发票

**用途**：登记开给客户的发票。

**路径**：销售管理 → 销售发票

**操作**：按发票号/客户/日期/状态查询 → 点开查看详情 → 打印（销售发票打印）。

**状态**：作废 / 正常。

## 十一、退货管理

**用途**：客户退货的处理链：申请 → 审核 → 收货入库 → 退款。

**路径**：销售管理 → 退货管理

**操作步骤**

1. **新增退货**：点「新增退货」→ 输入订单号/客户搜索 → 选订单 → 填退货明细、退货类型、原因 → 提交退货申请（状态=**申请中**）。
2. **退货审核**（主管）：点「审核」→ 通过=**已审核** / 驳回。
3. **收货确认**：仓库收到退货 → 点「收货确认并入库」→ 联动退货入库 → 状态=**已收货**。
4. **退款**：点「退款」→ 记录退款人/金额 → 状态=**已退款** → 结束（已完成）。

**状态**：申请中 / 已审核 / 已收货 / 已退款 / 已完成 / 已取消。
**退货类型**：质量问题 / 规格不符 / 数量错误 / 客户取消 / 其他。

---

## 十二、业务对账

**用途**：按客户 + 签收期间，把已签收的送货明细拉出来，和客户核对金额与到期。

**路径**：销售管理 → 业务对账

**操作步骤**

1. 选**客户**（支持按名称/编码搜索）+ 选**签收期间** + 到期状态 → 点「**查询对账**」。
2. 系统列出该客户在期间内已签收的送货明细（送货单号、料号、品名规格、数量、单价、金额、订单号）。
3. 点「**打印对账单**」出对账单。

**到期状态**：已预付 / 未到期 / 今日到期 / 已逾期（附逾期天数）。

> 提示：若查询无结果，说明该客户在所选签收期间内**没有已签收的送货单**。

---

## 十三、销售报表

**用途**：订单 / 客户 / 报价三类统计。

**路径**：销售管理 → 销售报表

**操作步骤**

1. 选**报表类型**：销售订单统计 / 客户统计 / 报价统计
2. 选**日期范围**（含近7天/近30天/近90天快捷）
3. 点「查询」→ 点「刷新数据」→ 点「**导出报表**」

**列（随类型不同）**
- 订单：订单编号、客户、订单金额、订单日期、订单状态
- 客户：客户、等级、联系人、电话、订单数、总金额
- 报价：报价单号、客户、报价金额、报价日期、状态

## 十四、单据打印清单（销售模块）

| 打印件 | 用在哪 |
|---|---|
| 询价单 | 询价单打印，给客户/工程确认需求 |

## 十五、关键口径与概念（销售必读）

1. **产品 vs 材料**：客户下单的是**产品**（产品档案/BOM/工艺）；库存采用**统一库存**，成品以 PRODUCT 身份入库、材料以 MATERIAL 身份入库。销售看产品维度，仓库看库存项（材料/产品），别混。
2. **产品状态**：只有 **RELEASED（已发布）** 的产品才能下单。
3. **下单前要看 BOM / 工艺路线是否已审批**：提交生产时会校验，没审批会被拦。
4. **金额口径统一**：报价、订单、样品金额按同一套口径（税率/税额/折扣），转单时金额继承。
5. **报价有效期**：过期自动置「已过期」，需要重新报价。
6. **运输方式/交货方式**：统一读字典 `sales_delivery_method`。

## 十六、常见问题 FAQ

**Q1：看不到某个菜单？**
没被授权。找管理员在「系统管理 → 角色管理 → 分配权限」给对应角色勾上。**菜单建了不等于授权了**。

**Q2：报价单为什么不能发送？**
只有「已审核」的报价单才能发送。先走「提交审核 → 审核通过」。

**Q3：订单提交生产失败？**
校验没通过：① 产品未发布（非 RELEASED）② BOM 未审批 ③ 工艺路线未审批。逐个补齐。

**Q4：订单取消后生产那边还在做？**
正常——取消会联动取消关联生产工单，但**已完成的工序会跳过**，只取消未完成部分。

**Q5：客户退货怎么走？**
退货管理 → 新增退货 → 审核 → 收货确认（自动入库）→ 退款。

**Q6：送货单/对账单在哪里打？**
发货管理（送货单）、业务对账（对账单）；两者都支持打印。
