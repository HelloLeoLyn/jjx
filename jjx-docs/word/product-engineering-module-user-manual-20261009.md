# JJX ERP 产品 + 工程模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：产品工程师 / 设计工程师 / 工艺工程师 / 工程主管 / 打样接单人
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「产品管理」「工程管理」
> 说明：产品与工程**咬得紧**（产品档案 ↔ BOM/工艺路线/菲林/作业规范），故合为一本。产品偏"档案与状态"，工程偏"设计实现（BOM/路线/菲林/资源）"。

## 一、模块总览

### 1.1 库存口径（2026-10-09 更新）：统一库存——材料与产品都进库存

- **产品（product）**：产品档案，是概念实体，管 BOM、工艺路线、销售/设计/生产维度（档案层）。
- **材料/物料（material）**：实体物料档案（原材料/辅料等，实物维度）。
- **库存采用统一库存**：库存项 `inventory_item` 分 **MATERIAL（材料）** / **PRODUCT（产品）** 两类身份；**成品（产品）以 PRODUCT 身份入库**（`material_id` 留空），材料以 MATERIAL 身份入库 → **材料与产品都会进库存**。
- 全库**没有 F 类成品物料**（`inventory_material.material_type` 只有 R/A）；旧口径"产品不入库 / 成品=F 物料"**已废**。
- 沟通口径：聊原材料/辅料说"**材料/物料**"，聊成品库存/可售/预留说"**产品**"。

### 1.2 两个模块分别管什么

| 模块 | 管什么 |
|---|---|
| **产品管理** | 产品档案（列表/分类/实例）、产品价格、产品配置模型、产品作业规范入口 |
| **工程管理** | BOM、工艺路线、标准工序、菲林、工艺资源（网版/刀模）、打样平台、产品作业规范、历史档案录入 |

### 1.3 全流程一张图

```
产品管理：创建产品 → 提交审核 → 审核通过（自动派工程任务）
                                   │
工程管理：   ├─ BOM：建 → 提交审核 → 批准 → ⭐设为默认BOM（绑定产品）
（并行设计）  └─ 路线：建 → 提交审核 → 批准 → ⭐设为当前版本（绑定产品）
                                   │
                        产品发布（校验 BOM 批准 + 路线批准）→ RELEASED
                                   │
打样闭环：样品单工程接单 → 打样平台录工序 → 样品完成 → 资料转移
          （产品建档待审 + BOM草稿 + 路线草稿）→ 提交审核 → 批准 → 转量产
                                   │
工程→生产：订单提交生产时校验 产品已发布 + BOM 已批准 + 路线已批准
```

**要点**：产品只有 **RELEASED（已发布）** 才能在销售订单里选中；生产下单还要 BOM、路线都已批准。

## 二、产品管理

### 2.1 产品列表

**用途**：产品档案的入口，新建/审核/发布/停用产品，并从这里跳 BOM、路线、作业规范。

**路径**：产品管理 → 产品列表

**列表列**：产品编码、产品名称、产品状态、单位、BOM（编码_版本）、工艺路线（编码_版本）、创建时间。

**操作步骤**

1. **新增产品**：点「新增」→ 选分类/客户/编码要素 → 填名称/规格/单位 → 保存为**开发中**。
2. **提交审核**：开发中 → 点「提交审核」→ **待审核**。
3. **审核**：**待审核 → 审核中 → 通过=已通过（自动派工程任务）/ 驳回=已驳回（退回修改）**。
4. **发布**：BOM、路线都已批准后 → 点「发布」→ **已发布（RELEASED）**。
   > 校验：BOM 已批准 + 路线已批准，缺一不可。
5. **停用/废弃**：点「停用」。
6. **BOM / 工艺路线**：列表里点 BOM 或路线编码可直接跳对应单据（也可点行尾编辑图标）。
7. **作业规范**：行操作里有「作业规范」入口，跳产品作业规范页。
8. **打印标签 / 导出**：批量操作。

**产品状态**

| 状态 | 含义 |
|---|---|
| 开发中(1) | 刚建 |
| 待审核(2) / 审核中(3) | 审核流程中 |
| 已通过(4) | 审核通过 |
| 已驳回(5) | 退回修改 |
| 已发布(6) | RELEASED，可下单 |
| 停产(7) / 取消(8) | 结束 |

**产品类型**：成品 / 样品。

### 2.2 产品分类

**用途**：维护产品分类树（树形结构）。

**路径**：产品管理 → 产品分类

**操作**：新增分类（填分类编码/名称/级别/排序）→ 刷新树。列：分类编码、分类名称、分类级别、排序、状态、创建时间。

### 2.3 产品实例

**用途**：给产品建"实物实例"（带序列号），跟踪单个实物的生命周期。

**路径**：产品管理 → 产品实例

**列表列**：实例编码、产品编码、产品名称、序列号、实例状态、生产日期、出厂日期、创建时间。

**操作**：新增、修改、删除、导出、激活、停用。

**实例状态**：按设计→客户确认→备料→生产→质检→发货→完成的九态生命周期。

### 2.4 产品价格维护

**用途**：给产品维护基础售价与标准成本，算参考毛利率。

**路径**：产品管理 → 产品价格维护

**操作步骤**

1. 查询/刷新产品价格列表。
2. 点某行「维护价格」→ 填基础售价、标准成本 → 保存。

**列**：基础售价（元）、标准成本（元）、参考毛利率（自动算）。
> 权限：维护价格需 `product:price:edit`。

### 2.5 产品配置模型

**用途**：给产品定义可配置项（如型号选项）。

**路径**：产品管理 → 产品配置模型

**操作**：新增模型 → 选所属产品 → 加选项 → 设默认 → 保存。列：所属产品、默认、状态。

## 三、工程管理

### 3.1 BOM 管理

**用途**：为产品设计物料清单（BOM）。产品能不能生产，看 BOM 批不批。

**路径**：工程管理 → BOM管理

**列表列**：BOM编码、BOM版本、产品编码、产品名称、审核状态、生效日期、失效日期、创建时间、备注。

**BOM 类型**：工程 BOM / 制造 BOM。
**BOM 层**：面板层 / 上层线路 / 间隔层 / 下层线路 / 背胶层。
**物料来源**：外购 / 自制。

**操作步骤**

1. **新增 BOM**：点「新增」→ 选产品 → 逐行加物料明细（物料、用量、层别、来源、位号/项目）→ 保存为**草稿**。
2. **提交审核**：草稿 → 提交 → **审核中**（提交前有**数据完整性校验**，含模数/基数≥1）。
3. **审核**（主管）：点「审核」→ 通过=**已批准** / 驳回=**已驳回**（通过时可免填审核意见）。
4. **设为默认 BOM**：批准后 → 设为默认 → **绑定产品**（产品发布要用）。
5. **复制 BOM / 导出**：批量工具。

**BOM 状态**

| 状态 | 含义 |
|---|---|
| 草稿(1) | 未提交 |
| 审核中(2) | 已提交待审 |
| 已批准(3) | 通过（可绑定） |
| 已驳回(4) | 退回修改 |
| 已作废(5) | 作废 |

**注意**
- 明细有「**项目**」列（复用工序分类字典 `process_category`）。
- 删除明细行要看清返回结果（历史上有"提示删除成功但行还在"的坑，已修）。

### 3.2 工艺路线

**用途**：为产品设计加工工序顺序（走哪些工序、各多少工时）。也是产品发布的必备条件。

**路径**：工程管理 → 工艺路线

**列表列**：路线编码、路线名称、产品编码、产品名称、版本、工序数、总人工工时、总机器工时、当前版本。

**操作步骤**

1. **新增工艺路线**：点「新增工艺路线」→ 选产品 → 加工序（每道工序含工序类型、工时、参数）→ 保存为**草稿**。
2. **提交审核** → **审核中** → **审核通过=已批准**。
3. **设为当前版本**：批准后设为当前 → 绑定产品。
4. **复制版本**：改工艺时复制旧版本再改。

**路线状态**：草稿(1) / 审核中(2) / 已批准(3) / 已驳回(4)。

**工序类型**（标准字典）：印刷、冲孔、冲型、贴合、裁切、垫片、保护膜、隔片、清洁、贴膜、撕膜、电阻、连接器、品检、面板、上线、下线、其他。
**工序分类**：面板 / 上线 / 下线 / 其他。
**末工序**：路线末道工序需正确置 `is_final_process`（否则生产侧口径会偏——历史遗留点，改时注意）。

### 3.3 标准工序

**用途**：维护可复用的标准工序库，路线里直接引用。

**路径**：工程管理 → 标准工序

**操作**：新增标准工序 / 导入（下载模板批量导入）。

### 3.4 菲林管理

**用途**：管理产品菲林（印刷用底片）的设计、审批、下发生产、版本。

**路径**：工程管理 → 菲林管理

**列表列**：菲林编码、产品、菲林名称、类型、版本、尺寸、厚度、图纸、审批状态、下发生产、设计师、创建时间。

**菲林类型**：面板菲林 / 上层线路菲林 / 间隔菲林 / 下层线路菲林 / 背胶菲林。

**操作步骤**

1. **新增菲林**：填产品、名称、类型、版本、尺寸、厚度、上传图纸 → 保存为**草稿**。
2. **提交审批** → **待审批**。
3. **审批**：点「审批通过」=**已批准** / 「审批驳回」=**已驳回**。
4. **设为当前版本**：把某版本标记为当前版本（历史版本自动降级）。
5. **新版本**：在某菲林上建新版本。
6. **下发生产**：批准后下发 → **已下发**。

**状态**：审批 草稿(1)/待审批(2)/已批准(3)/已驳回(4)；下发 未下发(0)/已下发(1)；当前版本 否(0)/是(1)。

### 3.5 工艺资源（网版 / 刀模）

**用途**：管理生产用的工装：**网框/网版** 和 **刀模**，并可关联到产品。

**路径**：工程管理 → 工艺资源 → 网版管理 / 刀模管理

#### 网版管理
- **新增网框**、**下载导入模板**、**导入网版**、**制版**。
- **网框状态**：空框 / 已制版 / 维护中 / 已报废。
- **维护**（下拉）：送修 / 恢复使用 / 报废。
- 可**关联产品**（多选搜索产品）。

#### 刀模管理
- **新增刀模**、**导入刀模**（下载模板）、编辑。
- **刀模状态**：可用 / 维护中 / 停用 / 已重做 / 已报废。
- **维护**（下拉）：送修 / 恢复可用 / 停用 / 重做（重做需填新刀模编号） / 报废。
- 可**关联产品**；有**维护履历**（时间/动作/原状态/新状态/操作人/说明）。
- **刀模位置 = 库位**：产品作业规范里引用刀模时显示库位。

### 3.6 打样平台

**用途**：工程侧接样品单、录打样工序、标记完成（**样品完成的唯一入口**）。

**路径**：工程管理 → 打样平台

**列表列**：样品单号、客户、轮次、状态、转移标志、当前工序、工序数、工时(h)、材料成本(¥)、接单人、最近操作。
**分组**：待接单 / 打样中。

**操作步骤**

1. 销售侧样品单点「工程接单」→ 打样平台出现该单（待接单）。
2. 进单录工序（**材料必须从物料档案选择，没有的先建档**）。
3. 工序逐道推进 → 标记**样品完成**。

### 3.7 产品作业规范

**用途**：一个产品一份"作业规范电子文档集"，7 个页签归集/录入。

**路径**：工程管理 → 产品作业规范（也做了产品侧入口，共用同一页）

**7 个页签**：①客供资料 ②产品作业规范 ③印刷规范 ④产品图集 ⑤分色检查表 ⑥样品 ⑦打样领料单。
**导出/打印**：顶部「生成文档集」→ 预览勾选 → 打印版式。

> 现状：① ② ④ ⑥ ⑦ 及"生成文档集"已落地；③ 印刷规范（油墨调配表）、⑤ 分色检查表 字段待样张确认后再补。

### 3.8 历史档案录入（含 AI）

**用途**：把**历史纸质档案**扫描上传，识别成结构化的工序/资料草稿。

**路径**：工程管理 → 历史档案录入（普通识别）/ 历史档案录入（AI）

**操作步骤**

1. 上传档案 → 点「上传并识别」（AI 版点「上传并 AI 识别」）。
2. 系统识别 → 进识别工作台：分组、工序格（识别原文→标准工序映射、跳类型、作业说明）。
3. **确认工序图标**（待确认/已确认/已忽略）→ 逐条「确认」或「修改后确认」→「确认全部分组」。
4. **保存草稿** / 「下一阶段」生成草稿。

**识别状态**：待识别(0) / 识别中(1) / 待确认(2) / 已生成草稿(3) / 识别失败(4)。
**内容形态**：空白 / 纯文本 / 纯图标 / 图文混合 / 待判断。
**工序结构**：空白 / 单工序 / 复合工序 / 跨组依赖 / 待判断。

## 四、资料转移（打样 → 量产的关键环节）

**在哪**：样品单（已确认）→ 工程侧「资料转移」。

**它做什么**：样品确认后，一键把打样成果转成正式档案：
- **产品建档**（待审核）
- **BOM 草稿**
- **路线草稿**（聚合最新轮次的工序）

然后**通知 + 派任务**给工程完善 → 工程把 BOM/路线提交审核 → 批准 → **转量产**（校验产品已发布）。

## 六、关键口径与概念

1. **产品 ≠ 物料**（见 1.1，最高优先级红线）。
2. **发布的三个条件**：产品发布需 **BOM 已批准 + 路线已批准**；订单提交生产还需**产品已发布**。
3. **两处"当前/默认"**：BOM 用"**默认 BOM**（is_current）"、路线用"**当前版本**（is_current）"绑定产品，别设错。
4. **菲林"当前版本"**：同产品同类型只能有一个当前版本。
5. **打样材料**必须从物料档案选（无则建档），**样品完成只能在打样平台**操作。
6. **产品作业规范**引用 BOM/路线/刀模时是**只读引用当前版本**，规范里不复制。

## 七、常见问题 FAQ

**Q1：产品发布按钮点了没反应/报错？**
检查 BOM、工艺路线是否都已"已批准"。两者缺一不能发布。

**Q2：订单里选不到某产品？**
产品不是 **RELEASED（已发布）**。先走完 建→审→发布。

**Q3：BOM/路线提交审核被拦？**
提交前有数据完整性校验（明细、模数/基数≥1、必填项）。按提示补齐。

**Q4：菲林改了怎么做新版本？**
菲林管理里点「新版本」建新版本 → 提交审批 → 批准 → 「设为当前版本」。

**Q5：打样做完怎么转量产？**
样品确认 → 资料转移（生成产品/BOM/路线草稿）→ 工程提交审核并批准 → 转量产（校验产品已发布）。

**Q6：刀模/网版报废了还能用吗？**
报废后不再可用于关联/生产；维护动作（送修/停用/重做/报废）都有履历可查。

**Q7：产品能不能物理删除？**
正式产品档案**只做状态流转（如停用/取消），不物理删行**。例外：可回收的纯占号草稿（报价/编码生成、开发中、未被引用、超时）允许物理删除以释放编码号。
