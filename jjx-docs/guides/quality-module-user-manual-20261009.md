# JJX ERP 质量模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：IQC/FQC/OQC 检验员 / 品质工程师 / 品质主管
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「质量管理」

---

## 一、模块总览

### 1.1 这个模块是干嘛的

质量模块管**检验与不良处置**这条线：来料检验(IQC)、完工检验(FQC)、出货检验(OQC)、来料不合格处置（隔离）、产品不良台账(NCR)、成品报废、CAPA 纠正预防措施、抽样方案。

### 1.2 谁用

| 角色 | 主要用到的部分 |
|---|---|
| IQC 检验员 | 来料检验（录入/判定） |
| FQC/OQC 检验员 | 成品检验 / 出货检验 |
| 品质工程师 | 不良台账处置、返工/特采/报废/退货 |
| 品质主管 | 报废审批（超阈值）、CAPA |
| 工程/采购 | 配合处置（退货/返工） |

### 1.3 全流程

```
来料(采购到货) → IQC 来料检验（录入 → 判定）
                      ├ 合格 → 放行入库
                      └ 不合格 → 来料不合格处置（隔离：让步接收/退货/返工/报废）
      ↓
生产完工 → FQC 完工检验 → 合格入库
      ↓
出货 → OQC 出货检验 → 合格出库发货
      ↓
任何检验判不合格 → 生成【不良单 NCR】→ 处置（返工/特采/报废/退货）
      ↓（重缺陷）→ CAPA 纠正预防措施（待分析→执行→验证→关闭）
```

**一句话**：三关检验（来料/完工/出货），判不合格就进不良台账处置，严重的挂 CAPA 跟踪闭环。

## 二、检验批的通用概念

四类检验都是**"检验批（Lot）"**模型，状态机统一：

| 检验批状态 | 含义 |
|---|---|
| 待检 (PENDING) | 待录入 |
| 检验中 / 待判定 (INSPECTING) | 已录入、待判定 |
| 已判定 (JUDGED) | 已出结论 |
| 已关闭 (CLOSED) | 结束 |

**检验类型**：IQC 来料检验 / IPQC 过程检验 / FQC 完工检验 / OQC 出货检验。
**检验结果**：待检 / 合格 / 不合格。
**判定维度**：按 **CR（致命）/ MA（严重）/ MI（轻微）** 分级记录。

## 三、来料检验（IQC）

**路径**：质量管理 → 来料检验（列表页 `/inventory/iqc`，另有"来料检验批"视图 `/quality/lot/iqc`）

**列表列**：来料批次、采购单号、供应商、到货时间、整批收货量、材料数、状态、待办、检验进度、FAIL 行。

**操作**

1. **查询**：按流程状态筛选（待检 / 待判定（已录入） / 已判定 / 已关闭）。
2. **处理**：点某批「处理」→ 进检验工作台。
3. **跨批次待处置**：点右上「跨批次待处置」→ 跳来料不合格处置页（隔离台账）。

**其他入口**：来料检验批（`/quality/lot/iqc`）用统一检验工作台。

---

## 四、成品检验（FQC） / 出货检验（OQC）

**路径**：
- 质量管理 → 成品检验（`/quality/lot/fqc`）
- 质量管理 → 出货检验（`/quality/lot/oqc`）

**说明**：FQC/OQC 与 IQC 共用同一套"检验工作台"（LotWorkbench），只是检验批类型不同。FQC 明细多一个"**类别**"列。

**列表列**：检验批号、业务来源、物料/产品、批次、本批检验批量、整批已检、待检、整批合格、整批不良、已入库、待处置、状态、判定、检验员。

---

## 五、检验工作台操作（录入 / 判定 / 复检 / 重开）

在检验批列表，每行按状态提供这些操作：

| 操作 | 作用 | 权限 |
|---|---|---|
| **录入** | 打开检验录入弹窗，逐项填实测值 | `quality:lot:inspect` |
| **判定** | 给出合格/不合格结论 | `quality:lot:judge` |
| **复检** | 重开复检 | — |
| **重开** | 重新打开已关闭的批 | — |
| **打印** | 打印检验报告 | — |
| **历史** | 看该批操作历史 | — |

**检验录入弹窗字段**（逐项）：检验项目、检验规范、方法、设备、**逐件实测（`|` 分隔多个值）**、CR/MA/MI 判定、结论（合格/不合格）、备注。
- 非 FQC 可「新增检验项」。

**判定**：填结论 + 判定人 → 提交。

## 六、来料不合格处置（隔离）

**路径**：质量管理 → 来料不合格处置（`/inventory/iqc-quarantine`），或由来料检验页「跨批次待处置」进入。

**用途**：对 IQC 判不合格的来料做隔离处置。

**处置方式**（与不良台账动作一致）：
- **让步接收（特采）** —— 放行使用
- **退货** —— 退回供应商
- **返工** —— 返工后复检
- **报废** —— 直接报废

> 处置后可能联动：生成让步接收入库单 / 退货出库 / 返工子批次 / 报废单等（按动作）。

---

## 七、产品不良台账（NCR）

**用途**：所有检验判不合格形成的**不良单**，在这里统一处置与跟踪。

**路径**：质量管理 → 产品不良台账（`/quality/ncr`）

**列表列**：不良单号、类型（IQC/FQC）、工单/来源、物料/产品、批次、不良数量、CR/MA/MI、已处置、待处置、状态、原因/补充说明。

**不良单状态**：待处置 / 处置中 / 已结 / 已作废（随批或撤销）。

**操作步骤（处置）**

1. 点不良单「**处置**」→ 弹处置窗口（显示不良单号、待处置数量）。
2. 选**处置方式**：返工 / 让步接收（特采） / 报废 / 退货。
3. 填**处置数量** + 备注。
   - 选**返工** → 还要选**返工工序**（+返工要求）。
   - 选**让步接收** → 填**客户已确认**。
4. 提交。

**特殊规则**

- **报废超阈值需审批**：报废数量**超过阈值（缺省 5 件）**时，提交后进入**待审批**，需**品质主管审批通过**才计入台账与件级；**审批人不得是提交人**。
- **随批作废**（`quality:ncr:void-superseded`）：同一批已被新处置取代时，旧不良单作废。
- **不良处置撤销**（`quality:ncr:revoke`）：撤销已提交的处置。
- **返工退料**：返工场景可退料，口径 **可退 = 补料 − 已退（净耗）**；批次默认回原发料批次；提交即生成退料入库单（`RTN-工单-NCR-序号`）并**自动过账回冲库存**。

**处置动作状态**：待执行 / 执行中 / 待审批 / 已完成 / 已作废。

## 八、抽样方案

**用途**：维护 AQL 抽样方案，供检验取样本量/判定阈值。

**路径**：质量管理 → 抽样方案

**列**：适用（类型）、批量区间、样本量、AC（合格判定数）、RE（不合格判定数）、启用。

**操作**：新增方案 / 修改 / 删除。字段：方案名、适用类型、AQL 值、检验水平、批量区间、样本量、AC/RE、是否启用。

## 九、成品报废单

**用途**：成品报废的成本损失记录（从不良处置的报废动作生成/归集）。

**路径**：质量管理 → 成品报废单

**状态**：已生效 / 已作废。
**操作**：查询 / 刷新 / 详情。

## 十、CAPA 台账（纠正预防措施）

**用途**：对（重缺陷/重复）不良做纠正与预防措施，闭环跟踪。

**路径**：质量管理 → CAPA台账

**闭环**：**待分析 → 措施执行中 → 待验证 → 已关闭**。

**操作**
1. **新建 CAPA**：填不良单 ID、责任人、期限 → 创建。
2. **推进**：点「推进」按闭环逐级推进（如措施执行完成 → 待验证）。
3. 关闭。

**约束**：**存在未关闭 CAPA 时，关联的不良单不能结案**。

**状态**：待分析 / 措施执行中 / 待验证 / 已关闭。

## 十二、关键口径与概念

1. **物料 ≠ 产品**：检验对象可以是物料（来料）或产品/工单产出（完工）；记录里以实际检验对象为准，但库存受影响的仍走**物料**（库存红线）。
2. **录入 ≠ 判定**：先把检验项实测录完（录入），再出结论（判定）——两步分离，分别有权限。
3. **报废阈值得审批**：报废超阈值（缺省 5 件）走主管审批；**审批人 ≠ 提交人**。
4. **不良单不能随便结案**：有未关闭 CAPA 时，关联不良单不能结案。
5. **返工退料净耗口径**：可退 = 补料 − 已退；退料自动回冲库存。
6. **来料不合格必须处置**：IQC 判不合格的来料不能直接入库，先隔离处置。

## 十三、常见问题 FAQ

**Q1：IQC 判不合格后料去哪了？**
进"来料不合格处置（隔离）"，按让步接收/退货/返工/报废处置，不支持直接入库。

**Q2：报废了为什么还没生效？**
报废超阈值（缺省 5 件）需品质主管审批，通过后才生效；且审批人不能是提交人。

**Q3：不良单结不了案？**
检查是否有未关闭的 CAPA 关联它——要先把 CAPA 推到"已关闭"。

**Q4：返工退料怎么算？**
可退 = 补料 − 已退（净耗）；提交即生成退料入库单并自动回冲库存。

**Q5：抽样样本量怎么定？**
在"抽样方案"里按批量区间维护（AQL/检验水平/样本量/AC/RE），检验时引用。
