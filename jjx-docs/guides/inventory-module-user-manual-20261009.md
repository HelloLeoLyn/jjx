# JJX ERP 库存模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：仓管员 / 库管主管 / 收货员 / 生产领料人
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「库存管理」

---

## 一、模块总览

### 1.1 这个模块是干嘛的

库存模块管**实物物料的进、出、存、盘、调**：仓库/库位基础设置、物料档案、即时库存、入出库作业、盘点、调拨、库存预警、收发明细流水。

### 1.2 先记一条红线：库存里只有物料，没有产品

- **物料（material）**：库存里的实物，类型 = 成品(F) / 半成品(S) / 原材料(R) / 油墨(I) / 辅助材料(A)。
- **产品（product）**：产品档案，是概念实体（有 BOM/工艺路线），**产品永远不入库**。
- 库存表（`inventory_stock`）就是**物料维度**的（`material_id`）——出/入/预留/盘点全是物料。
- 客户下单的是**产品**，出入库的是**物料**；看一个产品有多少可卖，是通过它专用的成品物料(F)间接看。
- 沟通口径：聊库存一律说"**物料**"。

### 1.3 谁用

| 角色 | 主要用到的部分 |
|---|---|
| 仓管员 | 即时库存、入库作业、出库作业、盘点、调拨 |
| 库管主管 | 入库/出库/盘点/调拨 审批确认 |
| 收货员 | 采购收货 → 入库 |
| 生产领料人 | 生产领料出库（PICK 单） |
| 采购/计划 | 库存预警、缺料 → 采购 |

### 1.4 全流程

```
基础设置：建仓库 → 建库位
      ↓
采购入库 / 完工入库 / 退货入库 / 调拨入库 / 盘盈入库
      ↓（出库）生产领料 / 打样领料 / 销售发货出库 / 报废 / 盘亏 / 调拨出库
      ↓
即时库存（总库存 / 预留 / 可用）
      ↓
盘点（差异调整） · 调拨（库间转移） · 预警（上下限/缺料） · 收发明细（每笔流水）
```

**核心口径（重要）**：审批（草稿→已批准）**只流转状态、不动库存**；库存真正增减统一发生在**【确认入库】/【确认出库】**时（1 或 2 状态均可确认 → 已完成 10）。

## 二、基础设置：仓库与库位

**路径**：库存管理 → 仓库与库位（仓库列表 / 仓库位置）

### 2.1 仓库列表

**列表列**：仓库编码、仓库名称、仓库类型、仓库位置、负责人、联系电话、排序、状态、创建时间。

**操作**：新增仓库（编码/名称/类型/位置/负责人/电话）、编辑、删除、**库位管理**。

**仓库类型**：普通仓库 / 质检仓库 / 成品仓库 / 废品仓库。
**常用仓库**（字典）：原料仓 / 半成品仓 / 成品仓 / 不良品仓。
**状态**：正常 / 停用。

### 2.2 仓库位置（库位）

**列表列**：库位编码、库位名称、库位类型、容量、已用容量、剩余容量、尺寸(W×H×D)、排序、状态。

**操作**：新增/编辑/删除库位（编码如 `A-01-01`）。

---

## 三、物料档案

### 3.1 物料列表

**用途**：库存物料的主数据（出入库都要选物料）。

**路径**：库存管理 → 物料列表

**列表列**：物料编码、物料名称、机种、物料类型、物料标签、规格型号、单位、安全库存、标准单价、状态、供应商。

**操作**：新增材料、编辑、删除、导入、详情。

**关键字段**

| 字段 | 取值 | 说明 |
|---|---|---|
| 物料类型 | 成品(F) / 半成品(S) / 原材料(R) / 油墨(I) / 辅助材料(A) | 决定物料用途 |
| 状态 | 启用(1) / 停用(0) / 废弃(2) | |
| 批次控制 | 启用 / 禁用 | 启用则出入库要带批次号 |
| 安全库存 | 数值 | 低于它会触发安全库存预警 |
| 标准单价 | 数值 | 成本口径 |

### 3.2 物料详情

**路径**：物料列表 → 点「详情」（或物料详情菜单）

**用途**：查看某物料的完整档案与其库存/流水关联。

---

## 四、即时库存

**用途**：所有物料的库存总览（总库存 / 预留 / 可用）。

**路径**：库存管理 → 即时库存

**筛选**：库存类型、物料编码、物料名称、仓库、库位、批次、数量区间（最小/最大）、日期。

**列表列**：库存类型、物料编码、物料名称、规格型号、单位、**总库存**、**预留数量**、**可用数量**、最早库位、最早有效期、状态。

**操作**：
- 「批次库存」：看该物料的批次明细。
- 「收发明细」：跳该物料的收发明细流水。
- 「导入库存」：批量导入。

**库存状态**：正常 / 冻结 / 过期 / 报废。
**可用计算**：可用数量 = 总库存 − 预留数量。

> 口径提示：表里的实物库存是**物料维度**的（含物料编码/料号）；"预留"来自订单占用。

---

## 五、收发明细（库存流水）

**用途**：每一笔库存变动的明细账，对账/追溯用。

**路径**：库存管理 → 收发明细

**筛选**：日期范围、物料编码/名称、仓库、批次号、类型、来源、单号。

**列表列**：业务时间、物料编码、仓库、库位、批次、类型、收入、发出、变动前、变动后、来源单号、业务来源、经办人、备注。

**类型**：入库 / 出库 / 调拨入库 / 调拨出库 / 盘盈盘亏。
**业务来源**：采购入库 / 生产工单 / 销售订单 / 盘点单 / 调拨单。

---

## 六、入库作业

**路径**：库存管理 → 入库作业（+ 新建入库单）

**列表列**：入库单号、入库类型、业务来源、仓库、供应商、来源批次数量、本单数量、本单已入库、来源批不合格、状态、创建人、创建时间。

**入库类型**：采购入库 / 生产入库 / 退货入库 / 调拨入库 / 盘盈入库 / 让步接收入库 / 返工复检入库 / 成品让步特采入库。
**检验结果**：待检 / 合格 / 不合格 / 部分合格 / 复检中。

**操作步骤**

1. **新建入库单**：选入库类型 → 选仓库 → 选供应商（采购类）→ 选来源类型、来源单号 → 加物料明细（物料、批次号、数量、单价、库位、生产日期、到期日期）→ 保存为**草稿**。
2. **（可选）提交审批 → 已批准**：此步**不动库存**。
3. **确认入库**：点「确认入库」→ **库存增加 + 写流水** → 状态变**已入库/已完成**。
   - 支持**批量确认入库**（勾选多张）。

**入库单状态**：草稿(0) / 待审批(1) / 已批准(2) / 已驳回(3) / 处理中(4) / 已确认(5) / 已出库(6) / 已入库(7) / 已关闭(8) / 已取消(9) / 已完成(10)。

**其他操作**：流水（看该单的库存流水）、打印。

---

## 七、出库作业

**路径**：库存管理 → 出库作业（+ 新建出库单）

**列表列**：出库单号、出库类型、仓库、来源、总数量、总金额、状态、创建人、创建时间。

**出库类型**：生产领料 / 打样领料 / 销售出库 / 销售发货出库 / 退货出库 / 报废出库 / 调拨出库 / 盘亏出库。

**操作步骤**

1. **新建出库单**：选出库类型 → 选仓库 → 选来源类型/来源单号 → 加物料明细（物品、批次号、数量、库位）→ 保存为**草稿**。
2. **确认出库**：点「确认出库」→ **库存扣减 + 写流水**。
   - **生产领料单**的按钮显示为「**确认发料**」。
   - 领料前系统做**库存预检**，不足会拦下。

**出库单状态**：草稿 / 已确认 / 已关闭 / 已取消。

**关联**
- **生产领料**：工单开工自动生成领料单，走"生产领料"独立入口（只显示 PICK 单）。
- **返工补料 / 返工退料**：返工场景专用（有独立权限）。
- 打印：出库单标题「出库单」，生产领料单标题「领料单」。

---

## 八、盘点作业

**用途**：核对账实、处理差异（盘盈/盘亏）。

**路径**：库存管理 → 盘点作业

**列表列**：盘点单号、类型、仓库、物料数、差异数、差异金额、状态、创建人、创建时间。

**盘点类型**：全盘 / 抽盘 / 循环盘点。

**操作步骤（按状态按钮流）**

1. **新建盘点单**：选仓库、盘点人、备注 → 保存（**草稿**）。
2. **开始盘点** → **盘点中**。
3. **录入实盘**：录每项实盘数量。
4. **确认结果**（主管）→ 生成差异。
5. **处理差异**：差异转盘盈入库 / 盘亏出库 → 调整库存。
6. **关闭**：结束盘点。

**盘点单状态**：草稿 / 盘点中 / 已关闭 / 已取消。
**差异处理状态**：待处理 / 已处理 / 已跳过。

---

## 九、调拨作业

**用途**：仓库之间的物料转移（出库扣 → 入库增）。

**路径**：库存管理 → 调拨作业

**列表列**：调拨单号、调拨类型、源仓库、目标仓库、总数量、总金额、状态、创建人、创建时间。

**调拨类型**：普通调拨 / 紧急调拨。

**操作步骤**

1. **新建调拨单**：选源仓库、目标仓库 → 加物料明细（物料、数量、库位）→ 保存（**草稿**）。
2. **提交审批** → **审批** → **已批准**。
3. **确认调出**（源仓）→ **已出库**（源仓库存扣减）。
4. **确认调入**（目标仓）→ **已入库**（目标仓库存增加）。
5. 关闭 / 取消。

**调拨单状态**：草稿 / 已批准 / 已出库 / 已入库 / 已关闭 / 已取消。

## 十、库存预警

**用途**：库存过低/过高、临期、呆滞、订单缺料的提醒，并可直接衔接采购。

**路径**：库存管理 → 库存预警

**操作**：查询/重置；「检查预警」（手动触发检查）；「批量已读」。

**预警类型**：安全库存 / 最高库存 / 保质期 / 呆滞料 / 订单缺料。
**预警级别**：提示 / 警告 / 紧急。
**处理状态**：新预警 / 已读 / 已处理 / 已忽略。

**列表列**：预警类型、预警级别、物料编码、物料名称、关联订单、当前库存、预警内容、预警时间、处理状态、处理人、处理时间、关联采购订单。

**订单占用总览**：弹窗看全厂有效订单的占用情况（加急/订单量/已占现货/待生产/还差/在制工单），用于判断缺料去向。

> 衔接：**订单缺料预警** → 通知仓管 → 生成**采购建议**（采购计划吃这个数据）。

## 十二、关键口径与概念

1. **物料 ≠ 产品**：库存里只有物料；产品不入库（红线，见 1.2）。
2. **审批 ≠ 动库存**：入库/出库的审批只流转状态；**库存变动只在"确认入库/确认出库"时发生**。
3. **可用 = 总库存 − 预留**：预留来自订单占用。
4. **批次**：启用批次控制的物料，出入库必须带批次号，库存按批次追踪。
5. **生产领料**：工单开工自动生成领料单，走独立入口；领料前有库存预检。
6. **盘盈 → 入库 / 盘亏 → 出库**：盘点差异最终通过这两类单据落地。

## 十三、常见问题 FAQ

**Q1：审批通过了，为什么库存没变？**
正常。审批只改状态，要在**确认入库/确认出库**后才动库存。

**Q2：出库提示库存不足？**
系统在确认出库前做库存预检。检查该物料该库位的可用量（总库存−预留）是否够。

**Q3：盘点差出来的数量怎么处理？**
「处理差异」把差异转成盘盈入库/盘亏出库，库存才真正调整。

**Q4：调拨要几步？**
4 步：建单 → 审批 → 确认调出（源仓减）→ 确认调入（目标仓加）。

**Q5：安全库存预警怎么来的？**
物料档案设了"安全库存"，当前库存低于它会触发；缺料还有"订单缺料"预警，可衔接采购。

**Q6：怎么看某笔库存变动是哪来的？**
收发明细里按"来源单号/业务来源"查（采购入库/生产工单/销售订单/盘点单/调拨单）。
