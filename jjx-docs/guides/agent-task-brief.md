# Agent 任务书：短任务卡与按需补充

任务码：dev-20261012-045。2026-10-12 用户确认采用“规定必须传达的信息，不规定必须写多少行”。本指南是任务书模板的唯一真源；仓库规范及 agent 技能笔记只引用这里。

## 使用规则

遵循仓库根目录 AGENTS.md 与 jjx-docs/standards/CONVENTIONS.md；任务书不复制整套通用规则，只写本次关键约束和明确例外。仅登记任务不等于授权实施；执行者应按用户请求类型判断权限。

默认用短任务卡。目标复杂、涉及数据库变更、跨模块依赖或接收者缺少背景时，按需增加补充内容；不要求凑够 12～15 行或固定填满八段。绝对路径用于必读文件及交付物；代码行号只是定位线索，以当前源码为准。

一个目标通常在同一任务内完成代码、验证与报告。独立功能、不同授权或明确的依赖边界才拆任务；拆分后写清前置交付与完成判据。

## 短任务卡（可复制）

```text
任务码：<dev-YYYYMMDD-NNN；包内编号可选>
1）目标：<触发条件、当前行为、期望行为，一句话>
2）范围：<允许修改的绝对路径；必读文件与关键定位>
3）约束：<必须保留的行为、已有枚举/接口；本次禁做及例外>
4）验收：<用户可观察的结果与必要反例；最小验证命令、期望结果>
5）交付：<代码/文档精确路径；提交推送遵循仓库规则或本次明确例外>
   回写：<自己的任务状态与备注要求；聊天使用仓库六行报告>
6）阻塞：<依赖未满足、同文件他人改动无法隔离、验证失败等具体条件>
   处理：<保留证据，说明受阻范围、可继续的工作、解除条件；不扩大范围>
```

验收先写行为，再写证明行为的命令。类型检查通过不等于业务问题修复；未经浏览器或运行态验证的结果必须写“未验证”。不要套用全量测试，选择与改动风险相关的最小验证，并遵守仓库对相关变更的必跑检查。

## 详细参考（八段，可按需取用）

```text
任务码：<dev-YYYYMMDD-NNN；包内编号可选>
1）目标与背景：<问题触发条件、已确认边界、期望行为>
2）必读：<绝对路径；已有接口/枚举/规则的位置，不猜实现>
3）前置核查：<git status、源码检查；涉库时只读查账本/结构等具体命令>
4）范围与约束：<改动白名单、依赖关系、必须保留的行为、禁做与明确例外>
5）交付物：<精确路径；文档登记要求；聊天使用仓库六行报告>
6）验收与验证：<正常/异常行为、边界或反例；最小命令、期望输出、未验证项>
7）提交与回写：<遵循仓库规则；本次明确不commit/不push时写明>
   <只暂存本任务内容；自己的任务status=2，备注含改动/哈希或未提交原因/验证/遗留>
8）阻塞与交接：<具体停止条件；证据、受阻范围、可继续工作、解除条件>
```

按需补充：

1）数据库变更：目标库、迁移编号依据、只读前查、数据影响、验证与恢复方式；备份遵循现行用户规则，不自动生成备份。
2）跨模块依赖：已有接口、输入输出、先后顺序、前置任务与满足判据。
3）陌生 agent 接手：必要背景、现状证据及绝对路径，不粘贴无关历史。
4）行为容易误判：增加一个明确反例，说明“看似通过但实际错误”的结果。

## 阻塞与共享文件

工作区存在无关改动不构成整任务阻塞。需要修改的文件存在他人在制改动时，遵守 CONVENTIONS §11 的同文件协作规则：不覆盖、不还原、不自行解除暂存；独立工作可继续。不能安全隔离或取得该文件协作许可时，暂停依赖该文件的工作，报告具体路径和证据。

模板允许表达分块协作，不授予并发修改同一文件的权限，也不改变原有文件锁与归属规则。某个公共索引不可编辑时，可继续无依赖的代码核查，但报告登记仍须等待解除冲突；不能因此宣称整任务完成。

```text
阻塞：<命令与真实输出；具体路径或依赖>
影响：<哪些交付或验证受阻>
已完成/可继续：<不依赖阻塞的工作>
解除条件：<需要谁完成什么或提供什么>
```

## 例子：发布版本预览打印

```text
任务码：dev-20261012-016
1）目标：选择V1.0后预览与打印读取V1.0快照，工作态新增内容不混入。
2）范围：/home/administrator/jjx/jjx-web/src/components/product/ProductSpecDrawer.vue；/home/administrator/jjx/jjx-web/src/views/engineering/product-spec/components/ProductSpecPreview.vue。
3）约束：沿用现有版本加载接口与打印页；不修改历史快照或工作态业务数据。
4）验收：V1.0不含发布后新增变更；工作态仍含该变更；新窗口携带同一versionId；版本失败不回退工作态。最小验证：组件回归与npx vue-tsc --noEmit，均退出0；实际打印未验则注明。
5）交付：两处版本参数传递修复；遵循仓库提交规则与当次明确例外；任务回写及聊天六行报告。
6）阻塞：目标文件被其他任务占用或版本接口不支持快照时，停相关部分并交回证据；其余只读核查继续。
```

## 提交口径

通用模板不把“不 push 除非批准”设为默认。现行仓库规则为完成后自动 commit＋push；用户当次明确不提交/不推送时优先。任务045明确不commit、不push，仅交付可审阅文件与任务记录。本指南不改变服务生命周期授权规则。
