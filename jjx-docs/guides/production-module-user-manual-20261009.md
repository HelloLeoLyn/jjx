# JJX ERP 生产模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：生产计划员 / 车间主管 / 班组长 / 操作工 / 设备管理
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「生产管理」

---

## 一、模块总览

### 1.1 这个模块是干嘛的

生产模块管**"把订单做成实物"**这条线：生产订单（工单）→ 排产 → 派工 → 工序执行/报工 → 完工 → 质检 → 完工入库 → 关单，另带设备管理、生产追溯、报表、成本、质量记录模板。

### 1.2 谁用

| 角色 | 主要用到的部分 |
|---|---|
| 生产计划员 | 生产订单、排产、计划转工单 |
| 车间主管/班组长 | 派工管理（分配/收回/退回任务） |
| 操作工 | 工序执行、报工 |
| 设备管理 | 设备管理、维护计划 |
| 管理/财务 | 生产报表、成本 |

### 1.3 全流程

```
销售订单已确认
      ↓ 校验：BOM 已审批 + 工艺路线已审批 + 库存足够
提交生产 → 创建生产工单（记录 BOM/路线 ID + 快照，供追溯）
      ↓
工单排产（计划开始/结束）→ 已计划 → 待开始
      ↓
开始生产 → 进行中（首道工序激活）
      ↓
工序执行（录完工数量/工时，下一道工序激活）↻
      ↓
生产完工 → 已完成 → 触发质检
      ↓ 合格
完工入库（确认入库 → 成品库存增加 + 流水）
      ↓
工单关闭（已关闭，不可再操作）
```

**要点**：订单提交生产时校验 **BOM 已批准 + 路线已批准 + 库存足够**；**质检合格才能入库**；入库后成品可用于销售发货。

## 二、生产订单（工单）

**用途**：生产的主单据，一行一张工单，跟踪排产、进度、状态。

**路径**：生产管理 → 生产订单

**操作**：新增工单、编辑、删除、导出、**打印指令单**、**计划转工单（可拆分）**、生产随工单（打印随工单）、**工单补料**。

**列表/详情内容**：工单号、产品、数量、状态、物料状态、计划起止时间、关联 BOM/路线（编码+ID，含快照）。

**操作步骤**

1. **建工单**：一般由**销售订单"提交生产"**自动生成；也可「新增工单」手建 → 保存为**草稿**。
2. **排产**：填计划开始/结束时间 → 状态转**已计划/待开始**。
3. **开始生产** → **进行中**（首道工序激活）。
4. **计划转工单（可拆分）**：把一个计划按数量/时间**拆成多张工单**（弹窗里可加减拆分行、设优先级）。
5. **工单补料**：生产中缺料时补料（走 `inventory:outbound:supplement`）。
6. **关单**：完工入库后**关闭工单**。

**工单状态**

| 状态 | 含义 |
|---|---|
| 草稿(0) | 刚建 |
| 待审核(1) / 已审核(2) | 审核 |
| 已驳回(3) | 退回 |
| 已计划(4) | 已排产 |
| 待开始(5) | 待开工 |
| 进行中(6) | 生产中 |
| 已暂停(7) | 暂停 |
| 已完成(8) | 完工 |
| 已取消(9) / 已关闭(10) | 结束 |
| 已超期(11) | 超期 |

**物料状态**：未领料(0) / 待发料(1) / 已领料(2)。

## 三、派工管理

**用途**：把工序任务分配给具体执行人，是"谁做哪道工序"的落点。

**路径**：生产管理 → 派工管理

**列表列**：工序单号、工序、执行人、任务数量、已完成、待审批、已分配、剩余、状态。

**操作**

| 操作 | 作用 | 权限 |
|---|---|---|
| **分配** | 把工序任务分给执行人 | `production:task:assign` |
| **退回** | 退回任务 | `production:task:return` |
| **收回** | 收回已分配任务 | `production:task:recall` |
| **流水** | 看该任务的操作流水 | `production:task:view` |
| 任务管理 | 任务管理入口 | `production:task:admin` |

**筛选**：可按工单过滤任务（精细到返工工序可精准定位）。
**任务状态**：未分配 / 进行中 / 已完成 / 已取消。
**任务类型**：普通 / 补产。
**完成明细**：点开看报工人、执行人、报工数量、合格、不良、报工时间、审批人/时间。

## 四、工序执行 & 报工

**用途**：操作工在工序上开工、报工（填完工数量/工时/合格数/不良数）。

**路径**：生产管理 → 工序执行

**入口按钮**：「我的报工」（`work-report:view`）、「待我审批」（`work-report:approve`）。

**操作步骤**

1. 在工序执行列表找到自己的工序 → 点「**开始工序**」→ 弹"选择开工设备"（没有可用设备可按"无设备工序"继续）→ 确认开工。
2. 干活 → **报工**：填合格 / 不良 / 完成数量 / 报工时间。
3. 工序完成 → 下一道工序激活。
4. 点「完成明细」看任务的完成明细。
5. **打印**：生产日报、首件检查表。

**报工相关操作/权限**
- 报工 `production:work-report:add`
- 撤销报工 `production:work-report:cancel`
- 报工查询 `production:work-report:view`
- 报工审批 `production:work-report:approve`
- 代报工 `production:work-report:proxy`（替别人报）

**报工状态**：待审批 / 已通过 / 已驳回 / 已撤销。

**工序执行状态**：待执行(0) / 准备中(1) / 执行中(2) / 已暂停(3) / 已完成(4) / 已跳过(5) / 已取消(6) / 已超期(7) / 异常中(8) / 待确认(9)。

**执行类型**：正常工序 / 返工工序。

**执行记录类型**（工序日志）：开始 / 暂停 / 恢复 / 完成 / 质量 / 问题 / 参数 / 状态 / 操作 / 数据记录。

## 五、生产追溯

**用途**：按批次/工单正反追溯（从原料追到成品，或从成品追回原料/工序）。

**路径**：生产管理 → 生产追溯

**操作**：「**正追溯 →**」（沿生产方向追）、「**反追溯 ←**」（逆方向追）；查询/重置。

**列表列**：追溯编码、类型、操作、批次号、工单ID、操作人、操作时间、详情。

**追溯类型**（涉及）：原料入库 / 生产领料 / 工序执行 / 完工入库 / 销售发货 等链路。

## 六、设备管理

**用途**：维护生产设备档案、状态与维护计划。

**路径**：生产管理 → 设备管理

**操作**：新增设备、编辑、删除、**维护计划**、详情。

**列表列**：设备编码/名称/类型、状态、上次维护、下次维护。

**设备状态**：待机中(0) / 运行中(1) / 维护中(2) / 故障中(3)。

**衔接**：开工时可选择**开工设备**（无可用设备可按"无设备工序"继续）。

## 七、质量记录模板

**用途**：维护生产用的质量记录表单模板（JJX-QR 编号，含保存年限、打印实现程度、模板文件），是检验/报告打印的底座。

**路径**：生产管理（质量记录模板入口）

**操作**：新增、编辑、**上传模板**、**换版**、**生效**、**停用**、删除。

**列表列**：模板编号、名称、保存期限（年）、类别、打印实现程度、状态、模板文件。

**状态**：草稿 / 生效 / 停用。
**类别**：空白表 / 数据联动。

## 十二、关键口径与概念

1. **统一库存**：生产消耗物料（MATERIAL）、产出成品以**产品(PRODUCT)库存身份**入库（`material_id` 留空）——材料与产品都会进库存（见库存手册 §1.2）。
2. **提交生产的前置校验**：BOM 已批准 + 路线已批准 + 库存足够。
3. **工单带 BOM/路线 ID + 快照**：创建工单时记录当时的 BOM/路线，供后续追溯（防档案改动后对不上）。
4. **质检合格才能入库**：完工 → 质检（PASS）→ 完工入库；FAIL → 返修 → 复检。
5. **派工与报工分工**：派工管理负责"派给谁"，工序执行负责"做+报"；报工可选审批。
6. **返工工序**：返工走"返工工序"类型，与正常工序区分。

## 十三、常见问题 FAQ

**Q1：销售订单点"提交生产"报错？**
校验没通过：① BOM 未批准 ② 工艺路线未批准 ③ 库存不足。逐个补齐。

**Q2：工单能不能拆？**
能。用「计划转工单（可拆分）」按数量/时间拆成多张。

**Q3：开工时提示没有设备？**
选"无设备工序"继续，或先在设备管理里把设备置为可用。

**Q4：报工填错了怎么办？**
走「撤销报工」（需权限 `production:work-report:cancel`）再重报；或由审批人处理。

**Q5：怎么查一批货是哪批料做的？**
生产追溯 → 反追溯（从成品往回追原料/工序），或正追溯（从原料追成品）。

**Q6：完工后没入库？**
要先过质检（合格）才能完工入库；不合格走返修复检。
