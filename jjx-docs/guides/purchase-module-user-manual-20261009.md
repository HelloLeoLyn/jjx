# JJX ERP 采购模块 · 用户使用手册

> 版本：v1.0（初稿）
> 日期：2026-10-09
> 适用：采购员 / 采购主管 / 仓库收货员 / 财务（付款/发票）
> 系统入口：浏览器打开 ERP 地址 → 登录 → 左侧菜单「采购管理」

---

## 一、模块总览

### 1.1 这个模块是干嘛的

采购模块管**"买东西"**这条线：从"缺料预警 → 采购计划 → 采购订单 → 到货收货入库 → 发票 → 付款"的全过程，还带供应商档案与采购报表。

其中**采购计划**是特色：直接从库存预警/订单缺料缺口生成要买什么，不用凭脑子想。

### 1.2 谁用

| 角色 | 主要用到的部分 |
|---|---|
| 采购员 | 采购计划、供应商、采购订单、到货跟进 |
| 采购主管 | 采购订单审批、付款审批 |
| 仓库收货员 | 采购收货、收货票据上传 |
| 财务 | 采购发票、采购付款 |

> 看不到菜单 = 没被授权，找管理员在「角色管理 → 分配权限」勾。

### 1.3 业务全流程

```
库存预警 / 订单缺料
      ↓
采购计划（从预警加载 / 手动加物料）→ 确认计划选供应商 → 生成采购订单
      ↓
采购订单 → 提交审批 → 审批通过
      ↓
到货登记 → 采购收货（部分收货 / 已收货）→ 采购入库（库存增加，写库存流水）
      ↓
采购发票（按文件批量开票 → 核销 → 归档）
      ↓
采购付款（申请 → 审批 → 确认付款）
      ↓
（有退货时）采购退货 → 库存扣减 + 退货记录
```

**一句话**：计划 → 订单 → 收货 → 发票 → 付款；到货后库存更新，退货后库存扣减。

## 二、供应商管理

**用途**：维护供应商档案。所有采购单据都要选供应商。

**路径**：采购管理 → 供应商管理

**列表列**：供应商编码、供应商名称、供应商类型、标签、联系人、联系电话、邮箱、评估总分、状态、创建时间。

**操作步骤**

1. **新增供应商**：点「新增」→ 填编码/名称/类型、联系人、电话、邮箱、标签（可多个，如"塑料制品/薄膜"）、结算条款 → 保存。
2. **修改 / 删除**：勾选行后操作。
3. **导入 / 导出**：批量建档或导出。
4. **评估**：点「评估」给供应商打分（评估总分）。

**关键字段**

| 字段 | 取值 | 说明 |
|---|---|---|
| 供应商类型 | 原材料(R) / 辅助材料(A) / 油墨(I) / 成品(F) / 设备(E) / 其他(O) | 分类，便于按料找供应商 |
| 状态 | 正常(1) / 停用(0) | 停用后一般不可再下单 |
| 标签 | 自由多标签 | 如"塑料制品/薄膜"，用于快速筛选 |

## 三、采购计划

**用途**：把"该买什么"列成清单。数据可**自动从预警加载**（安全库存 max_stock − 当前库存 / 订单缺料缺口），也可**手动添加物料**（不限有没有缺库存）。

**路径**：采购管理 → 采购计划

**列表列**：物料编码、供应商、当前库存、建议量、采购数量、单位、来源、优先级。

**操作步骤**

1. **加载计划**：系统按库存预警/订单缺口自动列出建议采购的物料（带"来源""优先级"）。
2. **添加物料**：点「添加物料」→ 搜索物料编码/名称 → 加入计划（适合临时补的）。
3. **调整采购数量**：直接在行里改"采购数量"。
4. **清空**：点「清空」重置计划。
5. **导出 / 打印**：点「导出 Excel」「打印计划」。
6. **确认计划 → 生成采购订单**：点确认计划 → **选择供应商** → 生成采购订单。

**说明**
- 计划单不是独立表，是 `purchase_order` 的**前置草拟态**（`plan_status=1`）——确认后即转成正式采购订单。

## 四、采购订单

**用途**：正式下给供应商的采购单。

**路径**：采购管理 → 采购订单

**列表操作**：新增、修改、导出、**提交审批**、**审批**、**收货**、**申请付款**、复制。

**列表列**：订单号、供应商名称、订单日期、交货日期、采购审批、收货状态、付款状态、币种、总金额、紧急、创建时间。

**操作步骤**

1. **新增采购订单**：点「新增」→ 选供应商 → 加物料明细（物料、数量、单价、交期、交货方式）→ 保存为**草稿**。
   - 也可从「采购计划」确认后自动生成。
2. **提交审批**：草稿 → 点「提交审批」→ **待审批**。
3. **审批**（主管）：点「审批」→ 通过=**已批准** / 拒绝=**已拒绝**。
4. **收货**：到货后点「收货」→ 进收货流程（见第五节）。
5. **申请付款**：点「申请付款」→ 生成付款申请（见第七节）。
6. **复制**：重复采购时复制旧单。

**订单类型**：正常 / 紧急 / 补单 / 退货单 / 样品单。
**紧急标志**：正常 / 紧急。

**采购审批状态**

| 状态 | 含义 |
|---|---|
| 草稿(1) | 未提交 |
| 待审批(2) | 已提交待审 |
| 已批准(3) | 通过 |
| 已拒绝(4) | 退回 |
| 已取消(5) | 取消 |

**订单状态**：草稿0 / 询价中1 / 比价中2 / 已提交3 / 已批准4 / 执行中5 / 已完成6 / 已关闭7 / 已取消8。

**交货方式**：自提 / 供应商送货 / 物流配送 / 快递 / 空运 / 海运 / 铁路。

**详情**：采购订单详情内可看**凭证三页签**（采购 / 入库 / 付款）。

## 五、采购收货

**用途**：登记到货数量、做来料检验、上传收货票据，驱动入库。

**路径**：采购管理 → 采购收货

**列表列**：订单号、供应商、订购数量、已收数量、未收、收货状态、检验结果、（汇总）订单金额、收货进度。

**操作步骤**

1. 查询订单（按订单号/供应商）。
2. 点「收货」→ 弹收货对话框 → 录入**本次实收数量**（支持分批，多收/少收按实际填）。
3. 录**检验结果**（合格 / 不合格）。
4. 提交 → 收货状态更新（部分收货 / 已收货）。
5. **收货票据**：查看 / 上传 / 删除（发票、收据、送货单等凭证）。

**收货状态**：待收货(0) / 部分收货(1) / 已收货(2)。
**检验结果**：合格(passed) / 不合格(failed)。

**后续**：收货确认后**采购入库**——库存增加并写库存流水；到货后进入应付账款（阶段五）。

## 六、采购发票

**用途**：登记供应商开来的发票，支持按文件批量开票与核销。

**路径**：采购管理 → 采购发票

**操作步骤**

1. **新增发票**：点「新增发票」→ 选**已收货**的采购订单 → 上传发票文件（可多张）→ 确认生成发票（按文件批量开票）。
2. **核销**：点「核销」→ 填核销人 → 确认核销 → 状态变**已核验**。
3. **查看 / 下载附件**：点下载。
4. **批量删除**：勾选后批量删除。

**发票类型**：增值税发票 / 普通发票 / 专用发票 / 电子发票。
**发票状态**：待处理(0) / 已核验(1) / 已归档(2)。

**文档类型**（凭证）：发票 / 收据 / 合同 / 报价单 / 送货单 / 其他。

## 七、采购付款

**用途**：向供应商付款的申请、审批与登记。

**路径**：采购管理 → 采购付款

**操作步骤**

1. **新增申请**：点「新增申请」→ 选采购订单 → 填付款单号、付款方式、金额、币种、付款条款 → 保存。
2. **审批**（主管）：点「审批」→ 通过=**已批准** / 驳回=**已拒绝**。
   > 审批人由**登录身份**自动获取（不用手填）。
3. **确认付款**：审批通过后点「确认付款」→ 填银行流水号/回单号 + 上传回单 → 确认。

**付款状态**：待付款(0) / 部分付款(1) / 已付款(2)。
**付款审批状态**：待审批 / 已批准 / 已拒绝。
**付款方式**：银行转账 / 现金 / 支票。
**币种**：人民币 / 美元 / 欧元 / 日元 / 港币。

**付款条款**：维护在 `PaymentTerm` 字典（如见票、月结等，按字典取值）。

## 十、关键口径与概念

1. **物料 ≠ 产品**：采购买的是**物料**，库存里也只有物料；产品不入库（见产品/工程手册红线）。
2. **供应商类型与物料对应**：油墨供应商类型 = I（油墨物料）、原材料 = R 等，选供应商时按类型匹配。
3. **采购计划不新增表**：计划 = 采购订单的前置草拟态（`plan_status=1`），确认后转正式订单。
4. **收货 → 入库 → 应付**：收货确认才真正入库（涨库存）；付款链路独立于收货，可先收货后付款。
5. **金额口径统一**：采购/销售/报价/样品金额按同一套口径（见「单据金额口径规范」）。
6. **付款审批人 = 登录身份**（不手填）。

## 十一、常见问题 FAQ

**Q1：采购计划里的"建议量"怎么来的？**
来自库存预警（安全库存 max_stock − 当前库存）和订单缺料缺口，自动算出来；也可手动加物料。

**Q2：订单提交审批后能不能改？**
待审批状态一般要先被审批（通过/拒绝）再处理；被拒绝的退回修改。

**Q3：一次没到齐怎么办？**
用「部分收货」分批登记，未收数量会累计，收齐后变「已收货」。

**Q4：发票能批量开吗？**
能。新增发票时选已收货订单 → 一次上传多个文件 → 按文件批量生成发票。

**Q5：付款审批人是谁？**
由**当前登录人**自动带入，不用手填。

**Q6：退货怎么走？**
采购订单类型里有"退货单"，或走采购退货（填退货数量/原因）→ 库存扣减 + 退货记录。
