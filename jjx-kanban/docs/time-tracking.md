# 工序耗时与报工系统

## 1. 工序耗时跟踪

### 1.1 计时策略

每张工单进入一道工序时，系统自动记录 `started_at`；工序完成时记录 `completed_at`，并计算耗时。

```
工序开始                         工序完成
  │                                │
  ▼                                ▼
┌──────────────────────────────────────┐
│  work_order_process_item            │
│  ├─ process_name: "印刷"            │
│  ├─ started_at: "2026-07-15 08:30"  │
│  ├─ completed_at: "2026-07-15 10:15"│
│  └─ duration_minutes: 105           │
└──────────────────────────────────────┘
```

### 1.2 计时触发时机

| 事件 | 触发时间记录 |
|------|------------|
| 工单创建 | 第一道工序 `started_at = now` |
| 移入新工序 | 新工序 `started_at = now` |
| 确认完成 | 当前工序 `completed_at = now` |
| 跳过工序 | 跳过的工序 `completed_at = now`，`remark = "跳过"` |

### 1.3 前端展示

在卡片上显示当前工序停留时长：

```
┌──────────────────────┐
│  WO-001  MK12        │
│  冲切 ● 2h15m       │ ← 当前工序耗时
│  张三  2026-07-25    │
└──────────────────────┘
```

颜色标识停留时长：

| 停留时间 | 颜色 | 含义 |
|---------|------|------|
| < 4h | 默认 | 正常 |
| 4h - 8h | 🟡 黄色 | 注意 |
| 8h - 24h | 🟠 橙色 | 需跟进 |
| > 24h | 🔴 红色 | 异常 |

### 1.4 瓶颈分析 SQL

```sql
-- 查询各工序平均停留时间（最近 30 天）
SELECT
    pi.process_name,
    COUNT(*) AS total_tasks,
    AVG(pi.duration_minutes) AS avg_duration,
    MAX(pi.duration_minutes) AS max_duration,
    COUNT(CASE WHEN pi.duration_minutes > 480 THEN 1 END) AS long_stay_count
FROM work_order_process_item pi
WHERE pi.completed_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY pi.process_name
ORDER BY avg_duration DESC;
```

## 2. 报工系统

### 2.1 报工流程

```
工人完成一道工序
      │
      ▼
点击卡片 → 「报工」按钮
      │
      ▼
填写报工表单：
  ├── 完成数量 (必填)
  ├── 不良数量 (选填)
  ├── 不良原因 (选填, 多选)
  └── 备注 (选填)
      │
      ▼
点击提交
  ├── 写入 work_report 表
  ├── 更新工序 completed_at
  ├── 推进到下一道工序（自动或手动）
  └── 更新工单进度
```

### 2.2 报工表单

```
┌────────────────────────────────┐
│  报工 — WO-001                │
│  工序：冲切                    │
│                                │
│  完成数量：[  4980  ]  pcs     │
│  不良数量：[    20  ]  pcs     │
│                                │
│  不良原因（可多选）：            │
│  ☐ 印刷偏位                    │
│  ☑ 尺寸偏大                    │
│  ☐ 贴合气泡                    │
│  ☐ 线路断路                    │
│  ☐ 其他: [__________]          │
│                                │
│  备注：                        │
│  [ 已调机纠正，后续正常   ]     │
│                                │
│     [取消]        [提交并继续] │
└────────────────────────────────┘
```

### 2.3 不良原因字典

根据薄膜开关制造常见不良分类：

| 分类 | 不良原因 | 涉及工序 |
|------|---------|---------|
| 印刷不良 | 印刷偏位、墨层不均、漏印、丝印堵网 | 印刷 |
| 冲切不良 | 尺寸偏大/偏小、毛边、切口不平 | 冲切 |
| 贴合不良 | 气泡、错位、起皱 | 贴合 |
| 电气不良 | 线路断路、短路、接触不良 | SMT、测试 |
| 外观不良 | 划伤、污渍、变色 | 装配、包装 |

### 2.4 良率统计

```
工序良率 = (完成数量 - 不良数量) / 完成数量 × 100%

示例：
  冲切完成 4980 pcs，不良 20 pcs
  良率 = (4980 - 20) / 4980 = 99.6%
```

### 2.5 统计看板（纯看板拓展）

在卡片详情弹窗内新增「报工记录」Tab：

```
┌────────────────────────────────┐
│  工序详情  │  报工记录  │  备注  │
├────────────────────────────────┤
│  工序     │ 完成  │ 不良 │ 良率  │
│  印刷     │ 5000  │ 12   │ 99.8% │
│  冲切     │ 4980  │ 20   │ 99.6% │
│  贴合     │ 4960  │ 8    │ 99.8% │
│  ...       │       │      │       │
│  总计     │ 19940 │ 40   │ 99.8% │
└────────────────────────────────┘
```

## 3. 日报/周报

### 3.1 日报内容

| 板块 | 内容 |
|------|------|
| 概况 | 今日完工数、进行中数、逾期数、开工人数 |
| 产出统计 | 各工序完成数量 + 图形 |
| 良率趋势 | 近 7 天良率折线图 |
| 不良 TOP5 | 不良原因排名 |
| 异常工单 | 逾期/阻塞工单明细 |
| 个人产出 | 按操作人汇总当日完工数 |

### 3.2 日报接口

```
GET /api/v1/reports/daily?date=2026-07-18
```

### 3.3 日报推送

- 每日 17:30 自动生成
- 推送到班组长/计划员的工作消息
- 可选打印或导出 Excel

## 4. 工单停留预警

### 4.1 规则配置

| 规则 | 阈值 | 预警动作 |
|------|------|---------|
| 工序停留 < 4h | 无操作 | — |
| 工序停留 ≥ 4h | 黄色标记 | 卡片显示 🟡，列表标记 |
| 工序停留 ≥ 8h | 橙色标记 | 班组长收到通知 |
| 工序停留 ≥ 24h | 红色标记 + 异常标记 | 计划员介入 |
| 工序停留 ≥ 48h | 紧急上报 | 管理员 + 语音播报 |

### 4.2 前端展示

在列头上方增加停留状态指示：

```
┌──────────────────────┐
│  冲切                │
│  [ 🟢 正常 🟡 3 🟠 1 ]  │  ← 本工序各停留级别的卡片数
│  8 张卡片             │
└──────────────────────┘
```
