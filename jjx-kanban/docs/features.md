## 2. 实施路线图

### Phase 1 — 看板核心（当前）

```
目标：前端跑通，Mock 数据驱动，展示核心能力

任务：
  ├── F-001 ~ F-010  前端基础功能
  ├── 文档编写        架构/数据/API/部署
  └── 演示/验收

工期：1-2 周（单人）
```

### Phase 2 — 大屏模式 + 工序统计

```
目标：投到车间电视，让老板/班长一眼看到车间状态

任务：
  ├── F-101 大屏模式    全屏 + 大字 + 自动刷新
  ├── F-102 大屏壁纸    氛围色 + 状态摘要
  ├── F-104 工序耗时    卡片上显示停留时间
  └── F-105 逾期判断    自动标红汇总

工期：1 周
```

### Phase 3 — 后端对接

```
目标：替代 Mock，连接真实数据

任务：
  ├── F-106 Spring Boot    服务启动 + 接口实现
  ├── F-107 ERP 对接       工单/产品数据同步
  ├── MySQL 建表           看板专用库
  └── F-204 操作日志       记录所有变更

工期：2-3 周
```

### Phase 4 — 权限 + 报工

```
目标：多人可用，生产数据闭环

任务：
  ├── F-201 权限体系    RBAC + JWT
  ├── F-202 登录/登出   前后端联调
  ├── F-301 报工        工序完成时记录数量/不良
  ├── F-306 报表        日报/周报
  └── F-205 WebSocket   实时推送

工期：2-3 周
```

### Phase 5 — 移动 + 播报

```
目标：车间现场全场景覆盖

任务：
  ├── F-302 移动端      PDA 适配
  ├── F-303 扫码        工单二维码
  ├── F-304 TTS 播报    异常级语音
  └── F-305 定时播报    定时任务

工期：2 周
```
