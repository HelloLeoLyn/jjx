### 架构决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | Vue 3 + TypeScript | 团队技术栈一致，组合式 API 天然契合看板状态管理 |
| UI 组件库 | Element Plus | 成熟稳定，中后台场景验证充分 |
| 状态管理 | Pinia | Vue 3 官方推荐，TypeScript 支持完善 |
| 看板拖拽 | Vuedraggable | 基于 SortableJS，跨列拖拽开箱即用 |
| 后端框架 | Spring Boot | 与现有 ERP 技术栈一致，复用认证/ORM/基建 |
| 服务间通信 | FeignClient | Spring Cloud 生态，声明式 HTTP 调用，低侵入 |
| 数据库 | MySQL | 与现有 ERP 保持一致，降低运维复杂度 |
| 构建工具 | Vite 8 | 极速 HMR，TypeScript 原生支持 |
| 语音播报 | Web Speech API | 零依赖，浏览器原生，适合车间 TTS 场景 |

## 2. 模块划分

### 2.1 看板引擎模块 (Kanban Engine)

看板系统的核心，负责模板管理、视图渲染、卡片生命周期管理。

```
┌───────────────────── Kanban Engine ─────────────────────┐
│                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌───────────────┐   │
│  │ Template    │  │ View        │  │ Card           │   │
│  │ Manager     │  │ Renderer    │  │ Controller     │   │
│  ├─────────────┤  ├─────────────┤  ├───────────────┤   │
│  │ 模板 CRUD    │  │ 分组逻辑     │  │ 增删改查       │   │
│  │ 工序配置     │  │ 列定义解析   │  │ 拖拽处理       │   │
│  │ 多模板管理   │  │ 筛选过滤    │  │ 状态流转      │   │
│  └─────────────┘  └─────────────┘  └───────────────┘   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 权限模块 (Auth & RBAC)

基于角色的访问控制，管理不同用户在系统中的操作权限。

| 角色 | 代码标识 | 操作范围 |
|------|---------|---------|
| 操作工 | `operator` | 查看本人工单、拖拽更新工序、标记完成 |
| 班组长 | `team_lead` | 查看全组、插单/改优先级、标阻塞 |
| 质检员 | `inspector` | 查看全部、标记不良/退返、查看不良统计 |
| 计划员 | `planner` | 建工单、调整工序模板、查看整体进度 |
| 管理员 | `admin` | 全部权限、系统配置 |

### 2.3 数据同步模块 (Data Sync)

负责看板服务与 ERP 主系统之间的数据同步。

```
┌──────────────────┐         ┌──────────────────┐
│   ERP System     │  ───►  │   Kanban System  │
│  (工单/产品/客户) │  定时   │  (工序进度/报工)   │
│                  │  Pull   │                   │
│  工单表           │  ───►  │  work_order_      │
│  产品表           │  同步   │  process          │
│  客户表           │         │  report           │
└──────────────────┘         └──────────────────┘
```

**同步策略：**
- **全量同步**：每日凌晨 02:00 同步基础数据
- **增量同步**：每 5 分钟轮询 ERP 工单变更
- **实时同步**：工单工序变动即时通知（待实现，消息队列）

### 2.4 播报模块 (Broadcast)

异常驱动的语音播报系统。

```
┌────────────────────────────────────┐
│         Broadcast Engine           │
├────────────────────────────────────┤
│                                    │
│  定时触发器 ──── 晨会/整点 ────►   │
│  事件触发器 ──── 阻塞/逾期 ────►   │
│  阈值触发器 ──── 积压/停留 ────►   │
│                                    │
│  调度队列 → TTS 引擎 → 音频输出    │
│                                    │
└────────────────────────────────────┘
```

## 3. 数据流

### 3.1 用户拖拽卡片

```
用户拖拽卡片到新列
      │
      ▼
Vuedraggable @change 事件触发
      │
      ▼
Pinia Store.handleDrag()
  ├── 前端：即时更新本地 columns 数据 (乐观更新)
  │
  ▼
Mock API / Real API → PATCH /api/board/cards/{id}/move
  ├── 后端：更新 work_order_process.current_step
  │
  ▼
重新加载看板数据
      │
      ▼
Broadcast Engine 检查是否需要播报
  ├── 正常流转 → 忽略
  ├── 阻塞标记 → 播报
  └── 工序完成 → 记录耗时
```

### 3.2 新建卡片

```
用户点击列头 "+"
      │
      ▼
AddCardDialog 弹窗 → 填写表单
      │
      ▼
Store.addCard()
  ├── Mock API → POST /api/board/cards
  │
  ▼
重新加载看板
      │
      ▼
Broadcast Engine
  ├── 普通任务 → 不播报
  └── 紧急任务 → 播报
```

## 4. 技术债务与风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| Web Speech API 语音质量 | 中文发音不自然 | 提供音量/语速调节，预留 TTS API 接入点 |
| 拖拽并发冲突 | 两人同时拖同一张卡 | 后端乐观锁（version 字段），前端错误提示 |
| ERP 接口不可用 | 看板无法获取数据 | 缓存最近 1 小时数据，显示"数据可能延迟"提示 |
| 浏览器兼容性 | IE 不支持 SpeechSynthesis | 仅支持 Chromium/Edge/Safari 现代浏览器 |
