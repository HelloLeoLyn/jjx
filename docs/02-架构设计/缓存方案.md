## 二、需要缓存的数据分类

| 分类           | 数据                                            | 特点                 | 变更频率 | 缓存位置             |
| -------------- | ----------------------------------------------- | -------------------- | -------- | -------------------- |
| **字典数据**   | 系统字典项（`/system/dict/code/{code}`）        | 全局共享，多页面复用 | 低       | Redis + localStorage |
| **枚举常量**   | 仓库类型、订单状态、物料类型等（`enums/` 目录） | 前端硬编码，无需请求 | 不变     | 代码静态常量         |
| **选择器数据** | 仓库、供应商、客户、物料、产品等下拉选项        | 多页面复用，数据量小 | 低       | Redis + 内存         |
| **业务列表**   | 各模块分页列表数据                              | 页面私有，数据量大   | 高       | 不缓存或短TTL        |
| **系统配置**   | 部门树、角色列表、菜单树                        | 全局共享             | 低       | Redis + Store        |
| **用户信息**   | 用户信息、权限、角色                            | 会话级               | 极低     | Pinia Store          |
| **序列号**     | 订单号、客户编码等                              | 原子递增             | 高       | Redis 原子操作       |

### 3.6 分布式锁（防止缓存击穿）

```java
@Component
@RequiredArgsConstructor
public class RedisLockUtil {

    private final RedisTemplate<String, Object> redisTemplate;

    public boolean tryLock(String key, long timeout, TimeUnit unit) {
        return Boolean.TRUE.equals(
            redisTemplate.opsForValue().setIfAbsent(key, "locked", timeout, unit));
    }

    public void unlock(String key) {
        redisTemplate.delete(key);
    }

    public <T> T loadWithLock(String cacheKey, String lockKey,
                               long lockTimeout, Supplier<T> loader) {
        // 1. 先查缓存
        T data = (T) redisTemplate.opsForValue().get(cacheKey);
        if (data != null) return data;

        // 2. 尝试获取锁
        if (tryLock(lockKey, lockTimeout, TimeUnit.SECONDS)) {
            try {
                // 双重检查
                data = (T) redisTemplate.opsForValue().get(cacheKey);
                if (data != null) return data;

                // 3. 加载数据
                data = loader.get();
                if (data != null) {
                    redisTemplate.opsForValue().set(cacheKey, data, 30, TimeUnit.MINUTES);
                }
                return data;
            } finally {
                unlock(lockKey);
            }
        } else {
            Thread.sleep(100);
            return loadWithLock(cacheKey, lockKey, lockTimeout, loader);
        }
    }
}
```

## 四、前端缓存方案

### 4.1 缓存层级

| 层级 | 存储位置                | 生命周期 | 适用场景                     |
| ---- | ----------------------- | -------- | ---------------------------- |
| L1   | Pinia Store（内存）     | 页面会话 | 用户信息、权限、当前页面数据 |
| L2   | composables（内存 Map） | 页面会话 | 字典、选项等跨组件共享数据   |
| L3   | localStorage            | 持久化   | 字典、Token、用户偏好        |
| L4   | Axios 拦截器（内存）    | 请求级   | 短时间重复请求去重           |

### 4.2 字典缓存 composable

```typescript
// src/composables/useDictCache.ts
import { ref } from 'vue'
import { dictApi } from '@/api/system/dict'
import type { SysDictItem } from '@/types/system/dict'

// 全局字典缓存（Map 单例，跨组件共享）
const dictCache = new Map<
  string,
  {
    items: SysDictItem[]
    timestamp: number
  }
>()

const CACHE_TTL = 30 * 60 * 1000 // 30分钟
const STORAGE_KEY = 'app:dicts'

// 从 localStorage 恢复缓存
const initFromStorage = () => {
  try {
    const stored = localStorage.getItem(STORAGE_KEY)
    if (stored) {
      const parsed = JSON.parse(stored)
      Object.entries(parsed).forEach(([key, value]: [string, any]) => {
        dictCache.set(key, value)
      })
    }
  } catch {
    /* ignore */
  }
}
initFromStorage()

// 持久化到 localStorage
const persistToStorage = () => {
  const obj: Record<string, any> = {}
  dictCache.forEach((value, key) => {
    obj[key] = value
  })
  localStorage.setItem(STORAGE_KEY, JSON.stringify(obj))
}

export function useDictCache() {
  const loading = ref(false)

  const getDict = async (dictCode: string, forceRefresh = false) => {
    const cached = dictCache.get(dictCode)
    const now = Date.now()
    if (!forceRefresh && cached && now - cached.timestamp < CACHE_TTL) {
      return cached.items
    }
    loading.value = true
    try {
      const res = await dictApi.getItems(dictCode)
      const items = res.data || []
      dictCache.set(dictCode, { items, timestamp: now })
      persistToStorage()
      return items
    } finally {
      loading.value = false
    }
  }

  const getLabel = (dictCode: string, value: string) => {
    const cached = dictCache.get(dictCode)
    if (!cached) return value
    const item = cached.items.find((i) => i.itemKey === value)
    return item?.itemValue || value
  }

  const clearCache = (dictCode?: string) => {
    if (dictCode) dictCache.delete(dictCode)
    else dictCache.clear()
    persistToStorage()
  }

  return { loading, getDict, getLabel, clearCache }
}
```

### 4.3 选项数据缓存 composable

```typescript
// src/composables/useOptionsCache.ts
import { ref } from 'vue'
import { warehouseApi } from '@/api/inventory/warehouse'
import { supplierApi } from '@/api/purchase/supplier'
import { customerApi } from '@/api/sales/customer'

type CacheKey = 'warehouse' | 'supplier' | 'customer' | 'material' | 'product'

interface CacheEntry {
  data: any[]
  timestamp: number
}

const CACHE_TTL = 10 * 60 * 1000 // 10分钟
const cache = new Map<CacheKey, CacheEntry>()

export function useOptionsCache() {
  const loading = ref(false)

  const getOrFetch = async <T>(
    key: CacheKey,
    fetcher: () => Promise<T[]>,
    forceRefresh = false,
  ): Promise<T[]> => {
    const cached = cache.get(key)
    if (!forceRefresh && cached && Date.now() - cached.timestamp < CACHE_TTL) {
      return cached.data as T[]
    }
    loading.value = true
    try {
      const data = await fetcher()
      cache.set(key, { data, timestamp: Date.now() })
      return data
    } finally {
      loading.value = false
    }
  }

  const loadWarehouses = (force = false) =>
    getOrFetch(
      'warehouse',
      async () => {
        const res = await warehouseApi.getAllEnabled()
        return (res as any).data || []
      },
      force,
    )

  const clearCache = (key?: CacheKey) => {
    if (key) cache.delete(key)
    else cache.clear()
  }

  return { loading, loadWarehouses, clearCache }
}
```

### 4.4 应用级 Store

```typescript
// src/store/modules/app.ts
import { defineStore } from 'pinia'
import { dictApi } from '@/api/system/dict'
import { deptApi } from '@/api/system/dept'

export const useAppStore = defineStore('app', {
  state: () => ({
    dicts: {} as Record<string, any[]>,
    deptTree: [] as any[],
    loaded: false,
    loading: false,
  }),

  getters: {
    getDictItems: (state) => (dictCode: string) => state.dicts[dictCode] || [],
    getDictLabel: (state) => (dictCode: string, value: string) => {
      const items = state.dicts[dictCode] || []
      return items.find((i) => i.itemKey === value)?.itemValue || value
    },
  },

  actions: {
    async initAppData() {
      if (this.loaded || this.loading) return
      this.loading = true
      try {
        await Promise.all([this.loadAllDicts(), this.loadDeptTree()])
        this.loaded = true
      } finally {
        this.loading = false
      }
    },

    async loadAllDicts() {
      const res = await dictApi.getAll()
      const dicts = res.data || []
      dicts.forEach((dict) => {
        if (dict.dictCode && dict.items) {
          this.dicts[dict.dictCode] = dict.items
        }
      })
    },

    async loadDeptTree() {
      const res = await deptApi.tree()
      this.deptTree = res.data || []
    },

    async refreshDict(dictCode: string) {
      const res = await dictApi.getItems(dictCode)
      this.dicts[dictCode] = res.data || []
    },

    reset() {
      this.dicts = {}
      this.deptTree = []
      this.loaded = false
    },
  },
})
```

### 4.5 Axios 缓存拦截器

```typescript
// src/utils/cachePlugin.ts
import type { AxiosInstance, AxiosRequestConfig } from 'axios'

interface CacheConfig {
  enable?: boolean
  ttl?: number
}

const cache = new Map<string, { data: any; timestamp: number }>()
const DEFAULT_TTL = 60 * 1000 // 1分钟

const getCacheKey = (config: AxiosRequestConfig) =>
  `${config.method}:${config.url}:${JSON.stringify(config.params || {})}`

export function setupCachePlugin(instance: AxiosInstance) {
  instance.interceptors.request.use((config) => {
    const cacheCfg = (config as any).cache as CacheConfig | undefined
    if (cacheCfg?.enable === false) return config
    if (config.method?.toLowerCase() !== 'get') return config

    const key = getCacheKey(config)
    const entry = cache.get(key)
    if (
      entry &&
      Date.now() - entry.timestamp < (cacheCfg?.ttl || DEFAULT_TTL)
    ) {
      ;(config as any).__cachedResponse = entry.data
      ;(config as any).__fromCache = true
    }
    return config
  })

  instance.interceptors.response.use((response) => {
    if ((response.config as any).__fromCache) {
      return Promise.resolve((response.config as any).__cachedResponse)
    }
    const config = response.config
    if (config.method?.toLowerCase() === 'get') {
      const key = getCacheKey(config)
      cache.set(key, { data: response.data, timestamp: Date.now() })
    }
    return response
  })
}
```

## 五、缓存失效策略

### 5.1 后端缓存失效

| 触发操作                  | 清除范围              | 实现方式                                             |
| ------------------------- | --------------------- | ---------------------------------------------------- |
| 字典项增删改              | 清除所有字典缓存      | `@CacheEvict(value = "dicts", allEntries = true)`    |
| 仓库/供应商等基础数据变更 | 清除所有 options 缓存 | `@CacheEvict(value = "options", allEntries = true)`  |
| 业务数据变更（入库/出库） | 清除相关业务缓存      | `@CacheEvict(value = "business", allEntries = true)` |
| 定时过期                  | 按 TTL 自动过期       | Redis 自动过期机制                                   |

### 5.2 前端缓存失效

| 触发操作         | 清除范围          | 实现方式                            |
| ---------------- | ----------------- | ----------------------------------- |
| 用户登出         | 清除所有缓存      | `appStore.reset()` + `clearCache()` |
| 字典管理页面修改 | 刷新单个字典      | `refreshDict(dictCode)`             |
| 基础数据页面修改 | 刷新 options 缓存 | `clearCache('warehouse')`           |
| 页面刷新         | 内存缓存丢失      | localStorage 持久化保留             |
| 定时过期         | 按 TTL 自动失效   | composable 中的时间戳判断           |

## 六、缓存穿透/击穿/雪崩防护

| 问题                              | 后端方案                                  | 前端方案                         |
| --------------------------------- | ----------------------------------------- | -------------------------------- |
| **缓存穿透**（查不存在的数据）    | `disableCachingNullValues()` + 布隆过滤器 | 空值缓存短时间                   |
| **缓存击穿**（热点 key 过期）     | 分布式锁 `RedisLockUtil`                  | 请求合并（同一时间只发一个请求） |
| **缓存雪崩**（大量 key 同时过期） | 随机 TTL + 本地缓存 Caffeine              | 多级缓存，降级策略               |

## 八、注意事项

1. **缓存粒度**：字典、选项等低频变化数据使用粗粒度缓存（整个列表），业务数据使用细粒度缓存（按 ID 或查询条件）
2. **缓存穿透**：查询不存在的数据时，缓存空值并设置短 TTL（1-2分钟），防止恶意攻击
3. **缓存雪崩**：不同缓存设置不同的 TTL，并添加随机偏移量
4. **缓存一致性**：写操作时先更新数据库，再清除缓存（Cache-Aside 模式）
5. **监控告警**：通过 Redis 监控缓存命中率，低于阈值时告警
6. **本地缓存**：Caffeine 作为一级缓存，Redis 作为二级缓存，减少网络开销
