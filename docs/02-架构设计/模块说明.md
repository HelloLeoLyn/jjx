## 模块依赖关系

本系统为**薄膜开关定制制造**场景设计，业务流程为：先接单 → 再根据订单定义产品 → 然后生产。

```
系统管理（基础权限）
    │
    ▼
销售管理（客户/报价/订单） ←── 第一步：先接单
    │
    ▼
产品管理（产品/BOM/工艺路线） ←── 第二步：根据订单定义产品
    │
    ├──→ 采购管理（采购原材料）
    │
    └──→ 生产管理（工单/工序执行） ←── 第三步：生产
              │
              ▼
          库存管理（入库/出库） ←── 第四步：入库
```
