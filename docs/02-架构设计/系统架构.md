# 系统架构

## 系统架构图

```
┌─────────────────────────────────────────────────┐
│                   前端 (Vue 3)                    │
│  Element Plus UI → Pinia 状态管理 → Axios HTTP   │
└──────────────────────┬──────────────────────────┘
                       │ RESTful API (JSON)
┌──────────────────────▼──────────────────────────┐
│              后端 (Spring Boot 3.4)               │
│  Controller → Service → Mapper (MyBatis-Plus)    │
│  安全: Sa-Token + JWT  缓存: Redis               │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              数据库 (MySQL 8.4)                   │
└─────────────────────────────────────────────────┘
```

## 后端模块结构

每个业务模块遵循统一的分层结构：

```
com.jjx.{module}/
├── controller/     # RESTful API 控制器
├── service/        # 业务逻辑接口 + impl 实现
├── mapper/         # MyBatis-Plus 数据访问
├── domain/         # 实体(Entity)、DTO、VO
├── converter/      # MapStruct 对象转换
└── enums/          # 业务枚举
```

## 前端模块结构

```
src/views/{module}/
├── index.vue                 # 主页面
├── components/               # 子组件
├── composables/              # 组合式函数
└── utils/                    # 工具函数

src/api/{module}/             # API 接口定义
src/enums/{module}/           # 枚举定义
src/types/{module}/           # TypeScript 类型
```
