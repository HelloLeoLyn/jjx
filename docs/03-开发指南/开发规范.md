# 开发规范

## 依赖注入

- 使用构造器注入，配合 Lombok `@RequiredArgsConstructor`
- 禁止使用 `@Autowired` 或 `@Resource` 字段注入

## 对象转换

- Entity → VO 使用 MapStruct
- Converter 接口放在 `.converter` 包下
- 配置: `@Mapper(componentModel = "spring")`

## 包结构

```
com.jjx.{module}/
├── controller/
├── service/
│   └── impl/
├── mapper/
├── domain/
│   ├── entity/     # 数据库实体
│   ├── dto/        # 传输对象
│   ├── vo/         # 视图对象
│   └── query/      # 查询参数
└── converter/
```

## API 规范

### RESTful 命名

- 资源集合使用**复数名词**: `/users`、`/orders`
- HTTP 方法:
  - `GET /resources` — 查询列表
  - `GET /resources/{id}` — 查询详情
  - `POST /resources` — 新增
  - `PUT /resources/{id}` — 全量更新
  - `DELETE /resources/{id}` — 删除
- 子资源嵌套: `GET /users/{userId}/roles`
- 自定义操作: `POST /users:batchDelete`

### Controller 代码模板

```java
@RestController
@RequestMapping("/users")
@RequiredArgsConstructor
public class UserController {

    @GetMapping
    public R<PageResult<User>> getUsers(...) { }

    @GetMapping("/{id}")
    public R<User> getUser(@PathVariable Long id) { }

    @PostMapping
    public R<Void> addUser(@RequestBody UserDTO data) { }

    @PutMapping("/{id}")
    public R<Void> updateUser(@PathVariable Long id, @RequestBody UserDTO data) { }

    @DeleteMapping("/{id}")
    public R<Void> deleteUser(@PathVariable Long id) { }
}
```

### 统一返回格式

- 成功: `Result.success(data)`
- 分页: `Result.success(getDataTable(list))`
- 失败: `Result.error(msg)` 或抛出 `BusinessException`

## 权限编码规范

### 权限标识命名

```
格式：模块:功能:操作（全小写英文，冒号分隔）
示例：system:user:add
```

| 操作     | 权限标识示例         | 说明                         |
| -------- | -------------------- | ---------------------------- |
| `view`   | `system:user:view`   | 查看（包含列表、详情、查询） |
| `add`    | `system:user:add`    | 新增                         |
| `edit`   | `system:user:edit`   | 编辑                         |
| `delete` | `system:user:delete` | 删除                         |
| `export` | `system:user:export` | 导出                         |

### 后端权限

- 所有写操作（POST/PUT/DELETE）必须添加 `@SaCheckPermission`
- `@SaCheckPermission` 放在 `@Log` 之后、方法返回类型之前

```java
@PostMapping
@Log(module = "用户管理", businessType = BusinessType.INSERT)
@SaCheckPermission("system:user:add")
public Result<Void> add(@Validated @RequestBody SysUserDTO dto) {
    return toAjax(userService.insertUser(dto));
}
```

### 前端权限

- 模板中统一用 `v-hasPermi` / `v-hasRole` 指令
- script 中统一用 `usePermission()` composable
- 权限标识使用枚举 `Permissions`，避免硬编码字符串

## 禁止事项

1. 禁止字段注入（`@Autowired`、`@Resource` 在字段上）
2. 禁止手写 Entity → VO 转换代码（使用 MapStruct）
3. 禁止 Controller 中写业务逻辑
4. 禁止在循环中操作数据库
5. 禁止在 Controller 中返回 `Result.error()`（应抛出 `BusinessException`）
6. 禁止保留未使用的变量、函数、导入
7. 禁止本地重复定义 `parseTime` 等工具函数

## Git 规范

### 分支命名

- `main` — 生产分支
- `develop` — 开发分支
- `feature/{name}` — 功能分支
- `fix/{name}` — 修复分支

### 提交信息格式

```
<type>(<scope>): <subject>

feat:    新功能
fix:     修复
refactor:重构
docs:    文档
style:   格式
test:    测试
chore:   构建/工具
```

mvn test                     # 运行测试
pnpm dev                     # 启动前端
