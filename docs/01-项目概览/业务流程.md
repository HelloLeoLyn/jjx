# 业务流程

## 业务背景

本系统为**薄膜开关定制制造**企业设计。薄膜开关是一种将按键、线路、面板集成于一体的薄膜型开关，广泛应用于家电、医疗、工业控制等领域。

**核心业务特点：** 薄膜开关属于**定制化产品**，每个客户的需求不同（尺寸、按键数、电路设计、颜色等），因此业务流程是：

```
客户提出需求 → 销售接单 → 根据订单定义产品 → 生产执行 → 完工入库
```

## 各模块详细流程

### 1. 销售管理流程

```
客户询盘
    │
    ▼
录入客户信息（新客户）或选择已有客户
    │
    ▼
创建销售报价单
    ├── 选择产品（如产品已定义）
    ├── 填写数量、价格、交期
    └── 提交报价给客户
    │
    ▼
客户确认报价
    ├── 接受 → 创建销售订单
    └── 拒绝/修改 → 调整报价
    │
    ▼
销售订单管理
    ├── 订单审核（内部审批）
    ├── 订单跟踪（生产进度）
    └── 订单完成（发货/关闭）
```

### 2. 产品管理流程

```
根据销售订单需求
    │
    ▼
创建产品档案
    ├── 产品编码（自动生成）
    ├── 产品名称、规格
    ├── 尺寸、厚度、按键数
    └── 技术参数
    │
    ▼
配置BOM物料清单
    ├── 面层（PET膜、油墨等）
    ├── 隔离层（双面胶等）
    ├── 电路层（银浆、铜箔等）
    └── 背胶层
    │
    ▼
制定工艺路线
    ├── 选择标准工序
    ├── 设置工序顺序
    ├── 配置工艺参数
    └── 设定标准工时
    │
    ▼
产品审核
    ├── 审核通过 → 可用于生产
    └── 审核驳回 → 修改后重新提交
```

### 3. 生产管理流程

```
根据销售订单 + 产品定义
    │
    ▼
创建生产工单
    ├── 关联销售订单
    ├── 选择产品
    ├── 计划数量
    ├── 计划开始/结束日期
    └── 自动带出BOM和工艺路线
    │
    ▼
工单下达
    ├── 确认物料齐套
    ├── 确认产能可用
    └── 下发到车间
    │
    ▼
工序执行（按工艺路线顺序）
    ├── 第1道工序：开料
    │   ├── 开始执行
    │   ├── 记录产出（投入数、合格数、不良数）
    │   └── 完成工序
    │
    ├── 第2道工序：丝印
    │   ├── 开始执行
    │   ├── 记录产出
    │   └── 完成工序
    │
    ├── 第3道工序：冲压
    │   ├── 开始执行
    │   ├── 记录产出
    │   └── 完成工序
    │
    ├── 第4道工序：装配
    │   ├── 开始执行
    │   ├── 记录产出
    │   └── 完成工序
    │
    ├── 第5道工序：测试
    │   ├── 开始执行
    │   ├── 记录产出
    │   └── 完成工序
    │
    └── 第6道工序：包装
        ├── 开始执行
        ├── 记录产出
        └── 完成工序
    │
    ▼
所有工序完成 → 工单完成
    │
    ▼
质量检验
    ├── 过程检验（首检、巡检）
    └── 成品检验
    │
    ▼
完工入库
```

### 4. 采购管理流程

```
生产工单 / 库存预警
    │
    ▼
创建采购申请
    │
    ▼
选择供应商
    │
    ▼
创建采购订单
    ├── 采购物料、数量、价格
    ├── 交货日期
    └── 订单审核
    │
    ▼
采购收货
    ├── 来料检验
    ├── 合格 → 入库
    └── 不合格 → 退货/换货
    │
    ▼
采购付款
    └── 发票管理
```

### 5. 库存管理流程

```
入库管理
    ├── 采购入库（原材料）
    ├── 生产入库（成品）
    └── 其他入库（退货等）
    │
    ▼
库存管理
    ├── 库存查询
    ├── 库存调拨
    ├── 库存盘点
    └── 库存预警
    │
    ▼
出库管理
    ├── 销售出库（发货给客户）
    ├── 领料出库（生产领料）
    └── 其他出库
```

## 关键业务规则

### 1. 产品与订单的关系

| 场景         | 流程                                      |
| ------------ | ----------------------------------------- |
| **新产品**   | 销售订单 → 创建产品 → 配置BOM/工艺 → 生产 |
| **已有产品** | 销售订单 → 选择已有产品 → 生产            |
| **产品改版** | 销售订单 → 复制产品 → 修改BOM/工艺 → 生产 |

### 2. 工序执行规则

- 工序必须按工艺路线顺序执行
- 前一道工序未完成，后一道工序不能开始
- 每道工序可独立记录产出（投入数、合格数、不良数）
- 工序可暂停后继续，也可取消
- 所有工序完成后，工单自动完成

### 3. 数量流转规则

```
工单计划数量：1000个
    │
    ▼
工序1（开料）：投入1000 → 合格980 → 不良20
    │
    ▼
工序2（丝印）：投入980 → 合格970 → 不良10
    │
    ▼
工序3（冲压）：投入970 → 合格965 → 不良5
    │
    ▼
工序4（装配）：投入965 → 合格960 → 不良5
    │
    ▼
工序5（测试）：投入960 → 合格955 → 不良5
    │
    ▼
工序6（包装）：投入955 → 合格950 → 不良5
    │
    ▼
完工入库：950个（合格品）
```

### 4. 状态流转

**销售订单状态：**

```
草稿 → 待审核 → 已审核 → 生产中 → 已完成 → 已关闭
                          │
                          └→ 已取消
```

**生产工单状态：**

```
草稿 → 已下达 → 执行中 → 已完成 → 已入库
          │         │
          └→ 已取消  └→ 已暂停
```

**工序执行状态：**

```
待执行 → 执行中 → 已完成
            │         │
            ├→ 已暂停  └→ 已取消
            │
            └→ 继续执行
```
