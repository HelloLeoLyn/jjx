# 项目介绍

## 项目概述

为薄膜开关制造厂设计的 ERP 系统，包含内部管理和多语言门户。

## 技术栈

| 层       | 技术                              |
| -------- | --------------------------------- |
| 后端框架 | Spring Boot 3.4 + Java 21 + Maven |
| ORM      | MyBatis-Plus 3.5.6                |
| 数据库   | MySQL 8.4 + Redis 7.2             |
| 安全     | Sa-Token + JWT                    |
| 前端框架 | Vue 3.4 + TypeScript + Vite       |
| UI       | Element Plus + SCSS               |
| 状态管理 | Pinia + Vue Router                |

## 项目结构

```
jjx/
├── jjx-server/          # 后端 Spring Boot 项目
│   └── src/main/java/com/jjx/

```

## 模块功能

### 1. 系统管理模块 ✅

- 用户管理：登录、注册、个人信息
- 角色管理：增删改查、分配菜单
- 菜单管理：树形结构（目录/菜单/按钮）
- 部门管理：树形结构
- 字典管理：字典类型、字典数据

### 2. 销售管理模块 ✅

- 客户管理：客户信息维护
- 销售报价：报价单管理
- 销售订单：订单创建、审核、跟踪
- 订单验证：产品/BOM/工艺/产能/成本验证

### 3. 产品/BOM管理（薄膜开关专用）✅

- 产品定义：编码、名称、规格、按键数、尺寸、厚度
- 多层BOM：支持面层、隔离层、电路层分层结构
- BOM明细：材料、用量、单位、损耗率
- 工艺路线：定义生产工艺流程
- 标准工序：工序库管理（开料、丝印、冲压、装配、测试、包装）
- 技术图纸：上传、版本管理

### 4. 采购管理模块 ✅

- 供应商管理：供应商信息维护
- 采购订单：采购订单创建、审核
- 采购收货：收货管理
- 采购发票/付款：发票和付款管理

### 5. 库存管理模块 ✅

- 仓库管理：仓库、库位管理
- 物料管理：物料分类、物料档案
- 入库管理：采购入库、生产入库
- 出库管理：销售出库、领料出库
- 库存盘点：盘点管理
- 库存预警：库存上下限预警
- 库存报表：库存统计分析

### 6. 生产管理模块 🚧

- 生产工单：创建、下达、进度跟踪
- 工序执行：按工艺路线逐工序执行（开始→暂停→记录产出→完成）
- 质量管理：过程检验、成品检验
- 生产看板：生产数据可视化
- 批次追踪：正反向追溯
- 工时统计：实际工时 vs 标准工时

### 7. 多语言门户 ✅

- 语言支持：中/英/西/葡/法/德/意/日/韩/阿
- 页面管理：首页、关于我们、产品展示
- 内容管理：ERP后台维护各语言版本
- 产品展示：同步ERP产品库
- 在线询价：表单提交、转销售线索

## 核心业务流程

本系统为**薄膜开关定制制造**场景设计，核心业务流程如下：

```
客户需求 → 销售接单 → 产品定义 → 生产执行 → 完工入库
```

### 详细流程

```
① 销售接单（先有订单）
   ├── 客户提出需求（图纸/规格书）
   ├── 销售报价
   └── 创建销售订单

② 产品定义（根据订单需求）
   ├── 创建产品档案
   ├── 配置BOM物料清单
   └── 制定工艺路线

③ 生产执行
   ├── 创建生产工单（引用销售订单 + 产品工艺）
   ├── 按工序执行（开料→丝印→冲压→装配→测试→包装）
   │   └── 每道工序：开始→记录产出→完成
   └── 完工入库

④ 库存管理
   ├── 成品入库
   └── 发货出库
```

### 模块依赖关系

```
系统管理（基础权限）
    │
    ▼
销售管理（客户/报价/订单） ←── 第一步：先接单
    │
    ▼
产品管理（产品/BOM/工艺路线） ←── 第二步：根据订单定义产品
    │
    ├──→ 采购管理（采购原材料）
    │
    └──→ 生产管理（工单/工序执行） ←── 第三步：生产
              │
              ▼
          库存管理（入库/出库） ←── 第四步：入库
```

## 快速开始

### 1. 数据库初始化

```sql
mysql -u root -p < jjx-server/sql/jjx_erp_db.sql
```

### 2. 后端启动

```bash
cd jjx-server
mvn clean install
cd jjx-admin
mvn spring-boot:run
```

### 3. 前端启动

```bash
cd jjx-web
pnpm install
pnpm dev
```

### 4. 访问地址

- 后端API: http://localhost:8080
- 前端页面: http://localhost:3000
- API文档: http://localhost:8080/doc.html

## 项目特点

1. **定制化生产**: 先接单后定义产品，支持薄膜开关定制制造
2. **模块化设计**: 前后端分离，模块清晰
3. **权限控制**: 基于Sa-Token的细粒度权限控制
4. **多语言支持**: 支持10种语言的国际化门户
5. **批次追踪**: 完整的正反向追溯体系
6. **质量管理**: 全面的质量检验流程
